# P2：音频与字幕

## 读取时机

在 `status --workspace <节目目录> --episode <epNN> --stage p2` 返回 `stageId: p2` 时完整读取本文件；普通音频、字幕收口、恢复和候选接纳都使用本文件。P2 只读取当前工作单直接投递的正式 P1 口播，不默认加载其它阶段 reference。

## 普通流程与付费

- 已获阶段授权时，只在真实需要新合成的 TTS（文字转语音）节点自动携带 `--authorize-paid-tts`；没有阶段授权时不得自行补加付费参数。
- 取得本次所需授权后连续完成清洗与单次语音合成，默认MiniMax `speech-2.8-hd`并开启原生词级时间。正式文稿决定字幕文字和句界，时间按同一音频的实测词级证据绑定。
- TTS后进入`author-subtitles`：Codex准备同源时间证据，按包内方法直接完成字幕断句、复核及正式接纳。程序保留完整句子并按作者必要断点生成文字与时间，不手工改字或填写毫秒。只有具体疑难确需AGY的独立专业判断时才按该包Skill定点咨询。
- 原生时间缺失、无效或经核实与实际话语不符时，使用现有VideoCaptioner必剪云端词级识别；只读取当前音频，保留原始识别证据，按正式文字校正并逐项核对差异。有效成功结果只恢复，不重复提交。音频摘要、原生时间弃用原因与识别区间交由接纳和收口程序共同复核。
- 不以18字为目标，不见逗号就切；具体容量与阅读复核只由字幕包拥有。同屏换行与先后切换字幕分别处理。不翻译、不安装本地ASR模型、不重做配音取时间。原生时间直接读取工作单nativeTiming，raw-word.srt仅按需导出；云端分支仍保留raw-asr.srt，候选只有一份。

## 本集读音与实际时长

首次合成前，执行者先通读正式正文、理解语义，判断多音字、人名、地名及数值在本句的正确读法；语境不足时再查本次材料，不凭字面猜音。需要指定读音时，以完整词语填写MiniMax读音，例如`[{"text":"银行","reading":"(yin2)(hang2)"}]`，避免单字规则误伤其它语境；没有需要就不建词表。

将本集读音保存为临时JSON，运行`node packages/modules/synthesize-narration/run.mjs readings <节目目录> <epNN> <JSON绝对路径>`，由原模块保存tts-readings.json并转为MiniMax的`pronunciation_dict.tone`。正式正文不插拼音。读音变化属于合成输入变化，成功后修改不自动重投或新增付费。

TTS后及P2完成时查看status的durationFeedback：供应商先反馈正文时长，收口后采用交付音轨实测值；includesOpener=false，不能把正文时长当成总片长。给出有依据的上限余量／超出量，片头、转场及停顿仍需预留。超时报告实际差距，不自动删稿、加速或重做P1。

## 返工与停止

- 用户明确要求重做已完成P2的字幕时，运行`next --workspace <节目目录> --episode <epNN> --stage p2 --revise-subtitles`，随后继续普通`status → next → candidate → accept`循环。入口先检查P3／P4实际子工作单，协调完成后保留口播与配音；音频摘要与处理合同未变时收口复用原MP3，向唯一字幕工作单投递同源时间证据，由字幕包`prepare`恢复；不得删除旧成果或重投已有ASR。未完成P2直接恢复当前工作单，不另开返工。
- 字幕返工不得重新合成；不得为补取时间轴重调付费 TTS。P2 只依次由 TTS 程序、`author-subtitles` 和字幕收口程序完成。
- 成功TTS响应已保存但音频／回执落盘中断时，沿原next恢复同一响应与远端身份，不新增合成。只换音轨更新成片；字幕仅改时间时交受影响画面作者；分句改变时保留已有理解、由原理解与导演节点修正Cue引用及边界。
- P2的TTS/ASR任务发生真实付费失败或远端结果未知时，阶段授权不覆盖再次付费或重投；已有远端任务编号时只恢复、查询和下载同一任务，仍不能确认结果时停止并报告。文本作者的恢复与接手只按字幕包现有规则处理。
- 用户明确授权替换一次无编号未知TTS提交时，运行`next --workspace <节目目录> --episode <epNN> --stage p2 --replace-tts-task <原提交的fingerprint> --authorize-paid-tts`。保留原提交记录；重复同一命令只恢复这次替换，再次未知仍停止。已有远端编号或原音频时只恢复原对象。
- 阶段完成只表示当前音频与字幕交接完成，不自动进入 P3。工作单、候选稿、恢复缓存和派生渲染计划都不是真源。
