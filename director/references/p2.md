# P2：音频与字幕

## 读取时机

在 `status --workspace <节目目录> --episode <epNN> --stage p2` 返回 `stageId: p2` 时完整读取本文件；普通音频、字幕收口、恢复和候选接纳都使用本文件。P2 只读取当前工作单直接投递的正式 P1 口播，不默认加载其它阶段 reference。

## 普通流程与付费

- 已获阶段授权时，只在真实需要新合成的 TTS（文字转语音）节点自动携带 `--authorize-paid-tts`；没有阶段授权时不得自行补加付费参数。
- 取得本次所需授权后连续完成清洗与单次语音合成，默认MiniMax `speech-2.8-hd`并开启原生词级时间。正式文稿决定字幕文字和句界，时间按同一音频的实测词级证据绑定。
- TTS后进入`author-subtitles`：Codex准备同源时间证据，默认AGY按包内共用方法制作并复核唯一候选；AGY不可用或失败时，确认原调用不再写入后由Codex接手，同一质量要求不降低。程序保留完整句子并按作者必要断点生成文字与时间，不手工改字或填写毫秒；Codex验收并正式接纳，具体提示词、调用和接手条件只见该包Skill。
- 原生时间缺失、无效或经核实与实际话语不符时，使用现有VideoCaptioner必剪云端词级识别；只读取当前音频，保留原始识别证据，按正式文字校正并逐项核对差异。有效成功结果只恢复，不重复提交。音频摘要、原生时间弃用原因与识别区间交由接纳和收口程序共同复核。
- 不以18字为目标，不见逗号就切；具体容量与阅读复核只由字幕包拥有。同屏换行与先后切换字幕分别处理。不翻译、不安装本地ASR模型、不重做配音取时间。工作单内`raw-word.srt`或`raw-asr.srt`仅承载当前时间证据，候选仍只有一份。

## 返工与停止

- 用户明确要求重做已完成P2的字幕时，运行`next --workspace <节目目录> --episode <epNN> --stage p2 --revise-subtitles`，随后继续普通`status → next → candidate → accept`循环。入口保留口播与配音，向唯一字幕工作单投递同源时间证据，由字幕包`prepare`恢复；不得删除旧成果或重投已有ASR。未完成P2直接恢复当前工作单，不另开返工。
- 字幕返工不得重新合成；不得为补取时间轴重调付费 TTS。P2 只依次由 TTS 程序、`author-subtitles` 和字幕收口程序完成。
- P2的TTS/ASR任务发生真实付费失败或远端结果未知时，阶段授权不覆盖再次付费或重投；已有远端任务编号时只恢复、查询和下载同一任务，仍不能确认结果时停止并报告。文本作者的恢复与接手只按字幕包现有规则处理。
- 阶段完成只表示当前音频与字幕交接完成，不自动进入 P3。工作单、候选稿、恢复缓存和派生渲染计划都不是真源。
