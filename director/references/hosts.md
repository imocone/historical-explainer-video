# 宿主工具

第一次执行生产时按当前真实宿主读取本页。工作单、候选、作者职责、质量要求与阶段授权共用，不复制生产流程。现有方法中“Codex”承担的制作管理、设计、验收与主代理职责，在Claude Code中由当前Claude主代理或该单独立作者承担；实际工具身份及复核记录必须如实填写。

阶段与平台方法里的具体工具名按本页映射；工具语法以当前宿主实际说明为准，业务顺序、完成条件和副作用边界仍由原方法拥有。

| 能力 | Codex | Claude Code |
|---|---|---|
| 终端与文件 | 当前原生工具 | 当前Bash、Read、Write、Edit工具 |
| 独立作者 | `spawn_agent`，`fork_turns:none` | 原生Agent子代理的新上下文，不使用fork，不续用已结束章节作者 |
| 进度 | `update_plan` | 当前任务／待办工具；没有时简短汇报，不另写状态文件 |
| 图片 | `IMAGE_PROVIDER=builtin`走原imagegen | `.env`选`IMAGE_PROVIDER=openai`，按原图片入口返回值走API；无原生生图不冒充调用成功 |
| 浏览器 | 原CUA内置浏览器 | 项目`video-browser` Playwright MCP，用于Studio与素材预览；读取当前工具说明，开源版不执行平台发布 |

P3仍是一章一位全新作者，最多三章；P4默认只有片头新作者；用户明确启用剧情视频时才使用片头、视频两位新作者。Claude按本次可用Agent工具的真实字段派工，任务只交原工作单路径、范围、约束与许可，不附主聊天或其它作者结果；并发容量不足时减少在途数量。主代理仍串行接纳，不因宿主变化另造作者、节点或第二流程。

AGY仍按原方法承担P1正文和默认字幕创作，不因主代理换成Claude就替换作者。字幕接手与复核沿原方法，Claude实际完成时使用`claude:subtitle-review`。

图片方法按原消费点读取。API仅提供工具能力：密钥、配置、安装和维护授权都不是生产付费许可；首次API提交须有当前明确图片付费许可，`--authorize-paid-images`只传递已经取得的许可。完成调用复用原结果，未知不切服务或换目录重投。既有原生图片保持真实身份。

Claude首次启用项目MCP时按宿主实际信任提示处理。浏览器账号由用户登录，程序不读取凭据。缺少工具、权限或登录时报告具体缺项，不把本地接入通过当成生成质量或发布已经实测。

P4默认只有片头制作与最后压片；剧情视频仅在用户明确要求时启用（`next --stage p4 --video on`）。未启用时不派视频作者、不生成空方案、不调用视频服务。
