# P1：统一创作与封面制作

## 读取时机

在 `status --workspace <节目目录> --episode <epNN> --stage p1` 返回 `stageId: p1` 时完整读取本文件；普通口播、完整重跑、正文返工、片头返工、恢复和候选接纳都使用本文件。P1 不默认读取 P0、P2 或其它阶段 reference，只消费工作单投递的当前P0正式单集合同；综合解说按`episodeBrief.explainerType`采用通用或时政方法，类型由P0确定，P1不重新分类；六项单集内容合同保持。若节目规划提供 `maxDurationSeconds`，也从`episode-brief`读取当前原值。

## 普通流程与连续执行

按P0的programForm进入唯一作者包：历史解说使用[author-narration](../../packages/modules/author-narration/SKILL.md)，历史纪录片使用[author-documentary-narration](../../packages/modules/author-documentary-narration/SKILL.md)。作者包拥有取材、输入交接、创作、选择、事实核对与恢复方法；Director不复制其内部流程，也不代写或润色。

`status → next → 按所选作者包完成当前工作单 → accept → status → 同批自带生图完成produce-covers`

作者包报告无可选稿、技术失败或未知作者调用时，保留现场，按其停止或恢复要求处理；不能把内容不成立改判成技术失败，以此增加作者或绕过一次事实核对与纠错。参考节目与NLM的取材分支、无引用时同一免费Query的有限重提均归所选作者包；未知Query的整阶段替换只按下文办理，不能套到未知作者调用。

开始P1即连续完成当前作者工作单。文字接纳后，按[发布内容与封面方法](p1-publication.md)处理独立封面节点；横竖两张封面的首次必要自带生图包含在P1授权内，按原模块返回的双提示与参考同批制作；双图未交付不能报整个P1完成。单阶段全部交付后停止，不自动进入P2。

## 片头定点返工

用户明确要求修正现行 P1 片头时，使用一次：

```text
next --stage p1 --revise-opener
```

该工作单由原作者同时修订片头及受影响的正文开场与承接，其余内容保留；材料、会话、发布内容及接纳共用下文正文返工链。用户给出必须逐字采用的片头时，增加`--opener-text <原句>`，只锁定该句，仍由作者调整正文。原句不符合片头合同时报告，不能让作者改写用户原句。该入口不重新Query、不自动执行后续阶段，也不从普通“继续P1”推断。

## 正文定点返工

用户明确要求重写现行 P1 正文时，使用一次：

```text
next --stage p1 --revise-narration
```

用户要求逐字保留某句片头，或只改正文并保留现行片头时，增加 `--opener-text <原句>`；后者从当前正式片头读取原句。该句进入工作单成为不可改写的编辑输入，AGY 围绕它写新正文，Codex 不能改片头迁就正文。未锁定片头且本次范围允许修订时，本次作者按修订后的正文和已选片头方法判断，必要时同次修订。Engine 只按现行正式正文生产溯源中的 `materialExecutionId` 精确定位实际使用的主／补 Query、原文快照与 AGY 作者会话，解说还定位原材料尝试中保留的`author-task.md`。工作单投递这些路径、摘要、会话身份以及`currentScriptPackage / currentOpenerNarration`中的现行正式稿；不得扫描历史尝试或按时间和内容猜选。身份缺失、材料缺失或摘要不一致时停止；旧合同 P1 只能由用户明确要求 `--rerun-narration` 完整重做。

正文返工只消费工作单固定材料，按所选作者包完成正文、片头及受影响发布内容。历史解说用新的单路AGY会话重写，后续纠错和修订跟随本稿作者；接纳时原材料快照、本次任务与新作者一并保留，正文绑定本次材料尝试。纪录片仍续固定原作者。AGY 明确失败，或用户已经取得完整返回并明确放弃该未接纳稿后，只有用户再次明确要求重试，才可增加 `--replace-narration-revision` 重新签发；它只换返工身份和临时目录，沿用同一材料描述符及片头原句锁定条件，作者调用按对应包现行方法执行。已有候选时只替换与现行工作单和请求一致的完整候选，原单、候选及临时材料沿原工作保留机制保留。候选归属不符、结果未知、片头原句不一致、不是现行正文返工或没有新的用户重试授权时停止。旧正式文件保留；P2不递归检查P1返工状态。新P1接纳后只按实际正文变化标记口播依赖，片头变化标记片头设计依赖，未改文案与封面不因作者身份变化重做。该入口不从普通“继续 P1”推断，也不授权重做 P2。

## 完整重跑

已有作者调用与选择进度按所选作者包恢复。方法变化、单路失败或对稿件的偏好不构成重开理由；未知作者调用不能用重新取材掩盖重投。只有满足下述完整重跑或技术替换条件时才签发新尝试。

用户明确要求从取材开始完整重做现行 P1 时，使用一次：

```text
next --stage p1 --rerun-narration
```

它使用新`executionId / scratchPath`，从当前资料入口完整执行所选作者包。旧正式P1只在新候选接纳后替换，旧Query、作者输入和候选不得复用。该显式入口可以替换用户已经明确放弃且尚未接纳的片头或正文定点返工工作单。

已开始的完整重跑默认只恢复同一任务；本次实际使用的材料已按被选作者包方法收口后，如果后续 AGY 明确失败，或完整成稿已经返回，但其采用的对象、关系、边界或内容主体偏离当前P0，且不能在同一作者会话内恢复当前任务，执行者可直接增加 `--replace-full-rerun` 换新重跑身份和临时目录，不再请求无费用重试授权，也不要求先生成候选。使用NotebookLM时，材料收口须有可确认的主Query回执与会话身份；仅使用网页、本地正文或视频时不要求Query，不把未调用当成结果未知。NotebookLM Query 结果未知时先恢复同一会话；仍不能取得可确认结果，执行者可在现有 P1 授权内用同一替换入口放弃这次未知 Query 并开始新的无付费取材尝试，不再询问用户。新任务从当前资料入口重新取材，不读取或复用旧Query、大纲和候选；AGY 结果未知或工作单身份不一致时停止。替换尝试不授权改变P0；需要改变节目问题、范围或内容主体时，停止相关创作并说明所需业务决定。它不授权重做 P2。

首次P1没有正式正文与片头时，先按所选作者包处理当前错误。Codex封装错误直接修正；作者包明确要求停止的机械交付失败，不得改判为自动重跑资格。免费Query恢复失败、作者技术失败或用户明确放弃尝试，分别按本节既有条件处理，符合替换条件时使用`--rerun-narration --replace-full-rerun`。“尚未接纳”本身不是替换理由，替换不得用于绕过本次一审一修。Engine只在正式P1两份文件都不存在、当前工作单确属本集P1作者，且如存在候选则候选绑定同一工作单时，持久化`full`替换请求并签发新`executionId / scratchPath`；新任务从当前资料入口重新取材和新AGY会话开始，旧Query、旧大纲、旧作者会话和旧候选都不得复用。该入口只恢复当前P1，不授权P2。

## P1交接

正文真源是`epNN/制作/p1/script-package.yaml`，片头真源是同目录`opener-narration.yaml`。作者包的交接程序从原始返回与当前工作单完成封装，Engine按现有合同接纳；不另存第二份脚本、不把旧候选重新绑定到新单，也不把机械通过当成内容质量结论。接纳拒绝时按原包停止并报告回执，不以新增作者调用求通过。

## 发布内容与封面

P1作者接纳即导出`output/publication.txt`；正式内容在`制作/p1/release-main/publication.yaml`。只修发布文案或封面构思时，按[p1-publication.md](p1-publication.md)签发原作者单路修订，锁定正文与片头；不重取材、不扩成三路。图片由produce-covers装配当前提示与参考，Director同批调用自带生图并沿原模块恢复、交付或编辑；默认沿原生工具；已明确选择API且有当前图片付费许可时按同一封面方法执行。
