# 字体来源与许可

本目录原有的Noto Sans SC与思源宋体按SIL Open Font License 1.1随视觉包分发；所有字体原文件未经修改、子集化或转换。

| 文件 | 正式用途 | 官方来源与许可 |
| --- | --- | --- |
| `SourceHanSerifSC-Heavy.otf` | 刊名、系列标识、横竖封面主字，实际字重900 | [Adobe Source Han Serif SC](https://github.com/adobe-fonts/source-han-serif/tree/release/OTF/SimplifiedChinese)，[原许可](SourceHanSerif-LICENSE.txt) |
| `SourceHanSerifSC-SemiBold.otf` | 集标题、片头短句、回忆画流片头标题，实际字重600 | 同一官方来源及原许可 |
| `NotoSansSC-Medium.ttf` | 正文、标签、知识卡、地图，实际字重500 | [Google Fonts Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)，[许可](OFL-1.1.txt) |

字体角色、实际字重与摘要以`../tokens.json`为准。地图保留独立浏览器注册名称；本包内内容相同的字体共用原文件。封面继续使用思源宋体及其厚重印刷字形。展示字体不用于长段说明文字。

同一字体原件可被本包多个角色引用，来源及许可同上表；文件内容未修改。vox-explainer的字体由该模板自行持有。

## MiSans 字幕字体

本软件使用 MiSans 字体。`MiSans-Semibold.woff2`仅用于节目字幕，来自[小米官方 MiSans 字体包](https://hyperos.mi.com/font/zh/download/)内的`MiSans/woff2/MiSans-Semibold.woff2`（Version 4.009），原件未修改、转换或子集化。字体内部家族为MiSans、字形为Semibold，OS/2真实字重为520；浏览器按真实字重注册，不合成粗体。
