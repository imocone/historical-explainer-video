# 明治工笔数字浮世绘视觉包

用于日本历史题材。以精细工笔墨线、清晰哑光色面、两至三级冷暖块面和自然成年造型保持现代数字浮世绘气质。具体时代、衣冠、建筑与器物来自当前节目和画面设计，不由明治参考补写。无全局纸纹、木刻排线或做旧；画面中真实木、纸等对象仍保留可辨形体与材质差异。

## 字体与配套外观

| 用途 | 字体与实际字重 |
| --- | --- |
| 刊名、系列标识、横竖封面主字 | 思源宋体 SC Heavy 900，以清晰厚重的印刷字形承接数字浮世绘 |
| 集标题、片头短句、回忆画流片头标题 | 思源宋体 SC SemiBold 600，保留细横粗竖的层次 |
| 正文、地图兵牌与说明 | Noto Sans SC Medium 500，保持阅读清楚 |

地图地名独立使用站酷小薇400，兵牌保留原Noto Sans SC字形与强调方式；地图字体独立注册，不影响正文或字幕字体身份。

本包取思源宋体接近明朝体的印刷气质，使用覆盖简体中文的SC字库；日本历史题材仍按节目的实际中文文字绘制。旧Yuji Boku缺少“战、顺、对、马”等常用简体字，不再让同一标题逐字混入本机字体。展示宋体不扩散到长段文字。横竖封面都从本包取得字体，Cover控制文字层级、字号、色序、字面处理和布局；生图中的文字仍按实际成图核对。

字幕使用MiSans Semibold，近白字配细深色描边与柔和阴影；字号、行距与底部留白由共用字幕层提供。地图保留原手绘兵牌、引线及轻微纸面颗粒和折痕。线条、纸面与字体分别从现有令牌读取，不改变模板的空间关系、字号布局、几何或动作。
