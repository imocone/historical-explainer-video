# 中性科普二维手绘场景插画视觉包

用于科普、知识、科技、社会生活、近现代及当前事件。画法已由大刘明确选定：沿即梦夜市参考校准的v2样图，采用可辨的彩色线稿、分组明暗色面与选择性绘画笔触；人物、器物和环境共享二维手绘质感，保留自然成年比例与可信空间。

桌面、玻璃与前景按同等绘画质感完成。正式参考只登记下述v2图；旧样图与旧教材换色检查图不代表当前画法。

## 固定参考

[白天植物研究室](references/assets/modern-editorial-botanical-day-v2.png)为主参考，[城市黄昏](references/assets/modern-editorial-city-dusk-v2.png)为补充参考。两图由内置image_gen原创生成与修正，原始图保留；按用户授权仅缩放至现行1536×864规格。固定顺序与职责以清单为准。

[生成提示词记录](references/creation-prompts.md)保存这两张原创样图的创作过程；正式生产仍只消费清单、style.json与令牌。

继承画法、材质表达和人体自身比例，不继承植物、轨道、职业、人脸、族群、地理、时代、动作、光向、时段、构图或人物占画幅大小。明亮室内与黄昏只是参考覆盖，不要求所有场景暖光、夜景、橙蓝对比、灯笼或发光颗粒。原即梦夜市作品仅用于调研，未作为包资源分发。地图旁图保持同等绘制完成度，只绘制所需前景部件，不据整幅参考铺背景。

刊名、标题、正文、地图、封面及回忆画流片头使用Noto Sans SC Medium，从本包取字形；节目字幕独立使用MiSans Semibold；层级、字号、排版与语义强调归相应消费者。中文黑体保持中性和可读性，Cover控制文字材质、配色与布局。实际字体文件、字重与摘要以令牌为准，见[许可](render/fonts/LICENSES.md)。

## 真源与消费

字幕使用MiSans Semibold，近白字配细深色描边与柔和阴影；字号、行距与底部留白由共用字幕层提供，字体与配色从本包令牌读取。

- [visual-package.json](visual-package.json)登记身份、生产方案和固定参考组；[style.json](style.json)是绘画规则真源，由公共编译器生成画风提示。
- [render/tokens.json](render/tokens.json)提供字体、配色、手绘线条、浅色纸签和地图、阴影、片头外观。令牌服务界面可读性，不要求与参考像素逐项相等。
- P3拥有内容、构图、透视和叙事光照；作者交付静态SVG时绑定工作单提供的绘图参数。P3/P4作者生成实图时消费已定画面与本包画法；P1封面消费本包画法及字体。P2字幕测量与P4压片使用同一字体；正文、地图、片头片尾及转场按真实入口消费外观，模板保留语义、几何与运动。
- 当前两个原创参考是已选定画法的室内日景和城市黄昏样图；画法选定与包合同通过不代替具体新节目成图或连续观看验收。

空间与军事推演由vox-explainer统一拥有画法、字体和连续地形呈现，不消费本Visual的独立地图配置。
