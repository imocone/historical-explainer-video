# 当前作者的图片交付

本方法由所选 Template 在联合创作完成后调用。当前候选保存唯一图纸；程序直接装配其画面描述、节目 Visual 和合法来源，不另写一轮提示词创作。统一用Codex原生imagegen，不选择客户端或图片服务。

prepare前确认当前图纸已经包含实际采用的人物样貌、服装和场景基本特征；登记文档只提供依据，不会自动把正文送入生图。选用的本人画像／照片及必要环境原图，须已按原来源登记，`usageNotes`绑定人物、时期、可参考部位与不得沿用的衣装／背景；本图`sourceRefs`引用相应原图SA，程序把其PNG/JPEG/WebP实际加入参考，并标明序号与用途。作者查看原图，核对实际job中的对应关系；图纸按当前活动取舍，不能照搬画像礼服或异时期背景。修图仍保留适用来源原图，生成图不能成为唯一身份依据。

P4新画片头或视频首图时，沿当前工作单读取相关正文已定造型、本人原图与其SA依据，把适用面容、衣冠、环境和器物写进本图原设计字段并保留来源引用；改变构图不丢掉时代身份，不重审正文事实。发现依据缺口按当前模板原返回边界处理，不在P4另开补查路线。

## 取得实图

1. 将完整联合设计写入当前唯一候选；运行 `node packages/authored-images.mjs prepare <工作单> <候选>`。全画幅联合单一次返回各Beat的待办，身份仍为`Beat/AR编号`。读取待办、参考图路径和已有调用记录；完整实际`job`由begin返回，calling恢复沿原记录读取，不重装请求。返回已有`asset`时，按所选模板判断当前设计的实际影响；全画幅在原落镜步骤处理实图表达与取景的实际影响。已完成且仍符合当前设计的图片保留，不因文字、画风、方法或摘要变化自动重生。
2. 对实际待生成的 `单位/AR编号` 运行 `begin <工作单> <候选> <单位/AR编号>`，把返回的完整 `job` 原样交给Codex原生imagegen。首次引用本地参考图前查看真实图片，使用入口返回的准确路径。全画幅A在`continuesPreviousScene=true`时自动取得上一实图；跨场景的人物／道具复现及B图参考，由作者按本图需要显式选择。需要延续本图人物、场景或道具时，在原begin加 `--reference-image <单位/前图AR编号>`使用本单位或同一联合单更早Beat的已成前图，或加 `--reference-image previous`使用工作单投递的上一Beat末图。所选图须已取得并查看，参考范围沿用当前工作单；从前图继承所需身份与外观，本图设计决定主体、景别与环境。独立A/B及段内独立Beat图片按下节同时提交，逐项保存结果；实际依赖前图的图片在其导入并查看后提交。调用记录固定实际job，恢复沿原请求，独立调用的已成结果继续保留。其它模板沿各自参考合同。
3. 工具返回真实本地原图后直接运行 `import <工作单> <候选> <单位/AR编号> <原图绝对路径>`，不把逐张打开或审图作为导入前置。程序复制原图、读取真实尺寸、保存实际参数和 Visual 来源，并写回同一候选的 `asset`。不手填路径、尺寸、摘要或服务商。供后续生成调用的参考图仍遵守工具要求的首次查看；这不形成额外质量审查。

`calling` 表示原调用已开始，先恢复或找回其实际结果，不再次提交。`completed` 表示原结果已交回，直接复用。明确失败或未知后的再次调用须有本次许可；不删除恢复记录规避。输出不符合画幅时保留原结果并报告，不拉伸或裁图冒充完整构图。

历史API调用不再提交或重试。已有完成的原图可沿同一import附`--generation-receipt <原回执>`导入，保留真实来源；失败或未知只保留原记录并报告，不切原生重投。已导入的合格图片继续复用。

## 全画幅联合单的并发调用

本节只编排全画幅图片，讲解与片头保持各自调用方法；生成可并发，导入仍串行更新唯一候选。

从同一次prepare返回的全部成员待办中，取出当前确需生成且参考已就绪的图片。依次运行各项begin，收齐其返回的`{key, job}`；这些登记动作保持顺序，随后在同一次工具执行中发出全部独立imagegen请求，不在循环内逐项等待图片。已有`calling / completed`按原记录恢复或复用，不加入新调用。

支持JavaScript工具编排时，将本批begin返回的数组展开为`jobs`，调用关系如下；`job`不重写，结果按原`key`对应：

```js
const results = await Promise.allSettled(
  jobs.map(async ({key, job}) => ({key, result: await tools.image_gen__imagegen(job)}))
);
```

保留每项实际结果；失败项按同下标的`jobs[index].key`定位，不丢弃其它已成图。从工具真实返回取得每张原图路径，依次import到同一候选，不能并行改写候选。依赖图在所需前图导入并查看后，沿原begin显式引用并同样提交；无依赖图不陪它等待。部分调用失败或结果未知时，保全成功图与原调用记录，按原恢复／授权边界处理，不自动重试。

## 落实与局部修正

全画幅按[实图落镜方法](templates/fullframe-narrative/camera/realization-method.md)落实表达、取景、节奏和效果锚点，并判断应调框、返图还是修正设计／程序；本说明不另定专业标准。其它模板沿各自交付方法。

联合单的图片、调用记录和锁各归所属Beat，某图失败不抹掉其它已成图。镜框、转场、效果、解说框或Cue改变不自动重生底图。确认需要修图后，收齐当前范围的具体问题，保留合格图，按阶段授权及少量修图许可运行：

```text
node packages/authored-images.mjs begin <工作单> <候选> <单位/AR编号> --revision-reason "具体修正意见"
```

程序携带当前失败图与意见，保留旧记录，不原样重投。明确失败或未知后的再次调用，只有已有相应用户授权时才加`--retry-authorized`；参数不能代替授权。程序故障、设计矛盾和远端未知不作为图片质量问题处理。

片头按其模板交付必要图片，不另加全画幅落镜或审图轮次；视频首图由后续视频生产者在真实调用前读取。当前作者完成本模板剩余结果后统一交 Module 接纳，图片不另开工作单或独立接纳。
