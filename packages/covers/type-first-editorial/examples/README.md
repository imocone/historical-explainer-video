# 文字优先封面版式参考

- [横版16:9](type-first-youtube.png)：两组字在中下部左对齐，整体向右上留出空间；左侧约10%、底部约10%—12%的可见笔画余量。米白字为主，暖金只强调语义词组，右下保留时长角标余量。
- [竖版3:4](type-first-vertical.png)：两行同字号、同字重，每行汉字的可见字身约占画高8%。长行约占画宽88%，短行自然留白。整组在画面下段居中，字块中心约在画高72%。

两图是中性版式样张，只有占位字和连续灰度背景，不含人物、衣着、器物、建筑、故事、光源或具体场面。它们提供字块位置、阅读层级、米白与暖金的语义强调，以及亮字和安静暗区的分量关系。占位字不作为本集内容，所用中性字形不替代Visual提供的封面字体；不是无字底图，也不供成片采用。

当前原件取代此前带有秦桧君臣场面的成品示例。作者与生图均读取这里登记的当前横竖样张，不沿用旧成品或其压缩预览。具体默认位置与尺寸关系见[cover-rules.json](../cover-rules.json)，数值帮助协调字形与场面，不是裁切或验收阈值。

本集主体、动作、景别和关系从正文独立设计，形成后再按版式协调文字与场面。样张的灰度渐变不规定灯光、时代或主体位置；Visual参考只提供画法。正式封面仍是一次生成的满幅完整图文，保留必要面部、手势和关键物件的清楚结构，不使用独立文字面板、全图压黑或模糊代替取舍。

样张中的占位文案只示范阅读顺序和语义强调。实际句式、字数和行数由本集内容决定。短主句同样用醒目字身，已有成图的局部编辑仍只改用户点名范围。
