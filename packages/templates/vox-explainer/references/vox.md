# 动效创作思路与参考

本页是专业方法的统一入口，按当前工作读取所需文件，不必一次读完。各方法共同服务同一设计与scene，随实际画面往返修订；创作顺序、结果交接、恢复与交回由[作者入口](../AUTHOR.md)拥有。

| 当前工作 | 读取 | 形成或修正什么 |
|---|---|---|
| 接住内容、选择讲法 | [构思与编排](creative/concept.md) | 内容与观众起点、可见依据、需要先建立的认识及讲法取舍；开始设计前完整读取 |
| 整章分镜与镜内编排 | [设计与镜内编排](creative/design.md) | 把理解推进排成关键画面与粗片，组织构图、取景、字图关系和设计疑点 |
| 关键试制、素材和实际制作 | [关键试制与制作](creative/production.md) | 做实形象、材料与变化，确定媒介和可控部分；共同画法见[art.md](art.md) |
| 动作与节奏 | [运动编排](creative/motion.md) | 在原声时窗中安排整章起伏，细排主体、镜头、回应与阅读的时间 |
| 排字、数据与注意力 | [通用图文方法](creative/graphics.md) | 字组、数值比较、标签与标注的具体排法 |
| 局部窗口、全屏细节 | [窗口与细节](creative/windows.md) | 总览与局部的来源对应、取景和操作承接 |
| 复看成品、定位返修 | [复看与修正](creative/review.md) | 从实际画面判断理解、观感、时序问题及返修范围 |

地图专业判断从[空间方法](spatial.md)进入；候选、统一动画及具体工具从[制作与交付](delivery.md)进入，二维镜头与错时制作可按需读[运动实现示例](tools/motion.md)。[已有作品](../examples/README.md)供借鉴相通问题的讲法和制作手艺，不能将其内容与现成构图直接套作本题方案。
