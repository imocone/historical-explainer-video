# 动效创作思路与参考

创作顺序和交回沿[作者入口](../AUTHOR.md)。按当前一步查方法，沿同一原稿和scene继续做。

| 当前一步 | 方法 |
|---|---|
| 理解 | [读懂正文和观众的起点](creative/concept.md#理解整段内容) |
| 讲法与分镜 | [选讲法](creative/concept.md#选定讲法)，[挑关键拍](creative/timing.md#在讲法阶段挑出关键拍)，[按时间排镜头](creative/design.md#整章设计稿)。地理关系用[地图](spatial.md)，需要换尺度时看[窗口与细节](creative/windows.md) |
| 粗排 | [做可播全章](creative/design.md#全章粗排)，用[口播时窗](creative/timing.md)、[运动](creative/motion.md)、[图文](creative/graphics.md)和[预演](tools/preview.md)调准真实画面 |
| 精作 | 沿同一粗片[完成整章成品](creative/production.md)，按[节目画法](art.md)做实造型和场面，用正式图件、字组和动作在实际景别复看 |
| 独立精修 | [用同版成片复看并修正](creative/review.md#单段精修) |

地图专业判断从[空间方法](spatial.md)进入；候选、统一动画及具体工具从[制作与交付](delivery.md)进入，二维镜头与错时制作可按需读[运动实现示例](tools/motion.md)。[已有作品](../examples/README.md)供借鉴相通问题的讲法和制作手艺，不能将其内容与现成构图直接套作本题方案。
