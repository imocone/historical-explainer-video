# 动效创作思路与参考

本页只路由专业方法，按当前工作读取所需文件，不必一次读完。作者决定构思、表示、素材与运动编排；创作顺序、结果交接、恢复与交回由[作者入口](../AUTHOR.md)拥有。

| 当前工作 | 读取 | 形成或修正什么 |
|---|---|---|
| 接住内容、选择讲法 | [构思与编排](creative/concept.md) | 整段理解、可见依据、观看推进及讲法取舍；开始设计前完整读取 |
| 整章设计与镜头粗排 | [设计与镜内编排](creative/design.md) | 同一design.md的画面、时窗、文字交接及关键待证问题 |
| 关键试制、素材和实际制作 | [关键试制与制作](creative/production.md) | 选定形象与场面、素材粒度、实际变化；共同画法见[art.md](art.md) |
| 动作、进退和节奏 | [运动编排](creative/motion.md) | 设计前完整读取；主体动作、取景、回应与换表示怎样接成整段 |
| 排字、数据与注意力 | [通用图文方法](creative/graphics.md) | 字组、比较、连线的用途和主次 |
| 局部窗口、全屏细节 | [窗口与细节](creative/windows.md) | 总览与局部的来源对应、取景和操作承接 |
| 复看成品、定位返修 | [复看与修正](creative/review.md) | 实际解释、观感、时序及受影响范围的返修判断 |

地图专业判断从[空间方法](spatial.md)进入；候选、统一动画及具体工具从[制作与交付](delivery.md)进入。[已有作品](../examples/README.md)供借鉴相通问题的讲法和制作手艺，不能将其内容与现成构图直接套作本题方案。
