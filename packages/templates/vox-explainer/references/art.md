# 画法

本文件说明讲解的绘制方法与可改绘的底稿。精细的完成度和高级的整体质感来自同一幅画里协调的造型、构图、光影和材质。作者按本题和实际景别设计主体、环境、姿态与素材，把入画的部分做成有层次的整体。

## 节目画风参考

当前节目的具象画风以作者任务 `templateContext.visual` 的画法和有序参考图为准。先打开本镜涉及的人物、器物或环境参考，看线条如何随结构走、体块如何分面、材料如何区分，再按本题身份、景别和动作设计形体。把人物、器物与环境摆回一个实际镜头，比较整幅画的层次和质感，再深化露在镜头里的部位。抽象图解、排字、讲解底板及数据地图沿各自模板方法制作。

## 共同画风

用大轮廓和色面组织主体、环境和留白；按实际观看距离，用转折、色面和光影分出形体与材料。把人物、器物和环境放回同一构图，按本节目画风协调它们的分量。数据地图使用包内地图样式，局部地貌插画按本文件的空间地形部分制作。

**让造型服务当前画面。** 要让观众认出特定身份、形制或构造时，按需要查相合的肖像、衣装、实物、照片或图纸。要区分的场景，各自的空间格局在目标景别应当可辨。历史题材沿[时代外观方法](../../../modules/direct-episode/references/period-appearance-method.md#作者把依据落实到画面)使用本单依据。

按整幅画的观看重点组织共同画风，墨线与细节随景别和主次安排。同处一个具象场景的主体与环境，视角、尺度、光向和接触关系相配。换景别时延续主体的比例、结构与材质，取景与媒介选择见[关键画面与衔接](creative/design.md#关键画面与衔接)。身份、服装、地点与物件大小以本题事实为准；史料原件保留原貌，照片、原件与示意插画各自性质清楚。

## 人物、器物与普通情境

沿上述共同画法完成人物、器物与环境，可作为完整画面或独立图件使用。先把主体画成比例、姿态和轮廓成立的整体：主要体块的大小、长短、厚薄及相互嵌接决定它的具体形象，再展开当前景别能感知的体面与结构。人物的重心和肢体姿态支持当前行动，器物的薄厚、接合和内外结构支持当前用途与视角。需要活动、打开或转向时，把接合处和随后露出的形体一起设计，新姿态延续主体的比例、结构与材质。

用受光面、背光面和接触暗部显出体积，同时以明暗和冷暖突出当前重点、形成所需氛围。材料通过边缘、反光、表面起伏和纹理方向表现出区别，墨线选择能说明轮廓、转折与接合的位置，疏密与轻重跟随形体。精细刻画集中在当前景别能感知、对形象与氛围有贡献的位置，近看展开结构与质地，远看保有清楚的形象。需要环境时，把周围物件及其所处空间组织成有联系的整体，大小、聚散、前后遮挡与明暗共同衬托主体。独立图件进入最终构图后，再按实际尺度、承托、接触及光照调整。

## 空间地形

地图构图、底图层次与行动沿[空间方法](spatial.md)组织。地图和具象场景相接时，用实际相邻画面对照明暗、色彩与材质；图解的地理和阵营仍各有清楚含义，人物、器物保留自身材料色。滤镜可辅助镜头气氛或局部辨认，效果在完整画面及进出场中判断。

本节的生图分支用于需要具象地貌、剖面、山口遮挡或操作环境的局部情境。按当前依据和观看任务选择俯视、斜视或剖面，以地表体面、必要断面和光影表达实际关系；只有表达需要取出一块地形时才画自然外缘与实体侧面，剖切厚度不代表真实悬崖。图片不承担地图测绘真源。

保留河流、岩面、植被、道路和建筑的必要连续关系。平原仍是平原，高差有据；总览保留主要关系，近景展开可辨的结构与材质。源图包含完整形体和运镜余量，不为宽幅构图压扁地形。地表、道路、建筑和物件的视角、尺度与接触面相配；操作场景完成主体、承托、活动部分与遮挡，让作用处看得清。

## 颜色与材质

具体颜色以本题对象正常、清楚的固有色为起点，按材料、光照与视觉主次组织，不设固定色板或统一饱和度。用冷暖、明暗和色相差异组织当前画面的色面，使同段图件与环境相互衬托，主体保持足够的反差和面积分量。

受光、背光、转面和环境反光使材料色产生自然变化。磨损、木纹或衣褶按当前景别细化，纹理有对应材料和方向。姿态改变时延续同一对象的材料特征，实际光照与视角决定明暗变化。

物体保有自身材料色。透明、叠色与光影按具体材质和画面需要处理，保住形体、层次和颜色辨识。

## SVG底稿与改绘

先用本章已经认得出的形体。做新对象时，从本题的场面、年代、景别和动作出发，取相合的底稿、部件或动作做法，在实际构图里比较。整件不合时仍可以保留有用的形体、分面、接合或姿态，按本题局部改绘。轮廓、结构或动作仍有具体缺口时，按相合材料补画，也可为本题直接绘制。

| 要画什么 | 制作底稿 |
|---|---|
| 人物 | [people.mjs](../artwork/people.mjs) 有百姓、工匠、官员、护卫和王者的形体与姿态。按本题改体态、衣冠、面貌、持物和接触。地图步卒与骑手由同一护卫改姿态，筏夫由同一工匠改姿态。 |
| 建筑 | [art.mjs](../artwork/art.mjs) 有屋顶、官署、民居、院落、静态城防及可开合的城门。按本题改形制、用材和活动部件。 |
| 主体器物与环境小件 | 同一 [art.mjs](../artwork/art.mjs) 有炉灶、盐锅、货车、粮袋、钱币、旗、树。按用途改尺度、承托和动作。 |
| 辅助图件 | [props.mjs](../artwork/props.mjs) 有卷轴、文书、释读框、木牌、印章和木箱。按要露出的作用处使用分件。见[辅助图件](#辅助图件)。 |

在本单作者脚本生成或在 `scratchPath` 复制改绘，保留相对依赖。每次取件用段内唯一ID；改名时同步改 `href` 和 `url(#…)`。将图形与动作写入原 `scene.markup / scene.animation`，预演与P4直接消费该场景。完整作品的镜头、组合和动作可按需查[案例索引](../examples/README.md)。

案例中的汉代衣冠、建筑原样和通用兵种符号只说明各自用途。当前人物身份、时代形制和具象画风沿本单依据。

## SVG、标注与排字

本节由代码作者执行；生图入口使用前面的共同画法与所选图片部分。

**SVG人物按当前角色的参照起形。** 先定头身比例、体态和衣物体块，再用与身份、年龄、处境和动作相合的面貌、发式、衣装、持物或姿态区分角色。明暗分面随形体，跨镜头延续已定特征。

选用[人物函数](../artwork/people.mjs)时，可在本单制作脚本导入或在 `scratchPath` 改绘。复制 `people.mjs` 时保留相对导入的[绘制函数](../artwork/drawing.mjs)，也可让副本的导入指向该文件。`variant` 提供少量预设外观，`plain` 可取空手官员姿态。

换景别时，沿用角色的头身、衣冠、身份色和能追认的轮廓，再按实际画宽删减或补出细节。`guard({stride, robe})` 提供步态与衣色，`rider` 沿用护卫的衣身和头部，`rower` 沿用工匠的衣身和头部。需要调人与缰绳、船桨的接触时，见[地图的取件与组合](../spatial/symbols.mjs)。

护卫需要撑住、推门或攀爬时，可以用 `guard({id, variant, robe, pose})` 保留同一头身与衣装，直接改手脚落点。`pose` 采用人物本地坐标：站姿脚下为 `(0,0)`，向右及向下为正，站姿肩约在 `y=-186`，髋约在 `y=-94`。`body` 为 `[横移, 纵移, 倾角]`，`headTilt` 为附加头部倾角，单位是度。`farArm / nearArm` 各给 `[肘, 握点]`；`farLeg / nearLeg` 各给 `[膝, 踝, 可选鞋角]`，点写成 `[x,y]`。先把墙沿、踏点或把手换到同一坐标，摆好手和脚，再调躯干与肘膝；肢体各点要拉开。这个姿态不自带长矛、盾和地面影子，所持物件与遮挡由本镜决定。动作需要时，在原工程沿这些接触点排姿态，按实际状态控制 SVG 分件；播放时不导入底稿模块。

```js
import {official} from '/系统根目录/packages/templates/vox-explainer/artwork/people.mjs';
const figure = official({id: 'current-official', variant: 1, plain: true});
// 将figure写入本单scene.markup；位置、尺度与改绘由本题决定。
```

人物生成函数只在制作时使用。将改定的SVG与完整动作函数及其依赖写入原`scene.markup / scene.animation`。动画从当前scene的`root`或`select`取元素，由原`timeline / onFrame`求值。按本题姿态和接触点设计手、道具、衣物和支点的联动。

**SVG建筑与器物按当前对象的参照做实结构。** 按本题年代、用途与观看距离确定建筑的柱网、门窗、屋面和格局，以及器物的厚薄、接合与承托。`hall({roofId: 'storehouse-roof', label: '仓署'})` 提供可独立活动的屋顶。`gatehouse({id: 'east-gate', open: false})` 以门中央的地面为原点，`east-gate-door-left` 和 `east-gate-door-right` 分别在固定铰链下；在原 `timeline / onFrame` 改门扇的 `scale(x 1)`，左扇由 `1` 收到 `.21`、右扇由 `-1` 收到 `-.21` 就会露出通路。需要绕看、穿门或见到门背时，按实际观察面补画门扇、门洞和遮挡。地图与近景要认出同一座门时，共用该门的结构，近景再补材料与细节。

需要开合、持取或操作时，把相关部件与接合处一起做实，沿原 `timeline / onFrame` 连成动作。复制改绘 `art.mjs` 时保持 `drawing.mjs` 与 `people.mjs` 的相对导入可解析。

`cart({id: 'supply-cart', cargo})` 提供货车，原点在轮下地面。`cargo` 可传入放在车斗坐标中的SVG，如 `at(sack(), -21, 0, .54) + at(sack(), 18, 0, .6)`。`supply-cart-wheel-left / supply-cart-wheel-right` 可各自按行程绕轮轴旋转。需要呈现牵引、坡路或卸货时，按当前对象补画受力、接触和遮挡。

**外部造型参考。** 现有底稿和本单资料还缺具体造型时，按缺的部位选参考。可从[0 A.D.建筑](https://github.com/0ad/0ad/tree/master/binaries/data/mods/public/art/actors/structures/han)观察建筑与城防的构成，从[Quaternius建筑分件](https://quaternius.com/packs/medievalvillagemegakit.html)观察屋顶、梁墙和门窗的接合，从[KayKit物资](https://kaylousberg.itch.io/resource-bits)观察材料与物资形体，从[Kenney船艇](https://kenney.nl/assets/watercraft-kit)观察船体、帆与旗的分件。具体时代形制取本单依据。实际复用外部素材或代码时按原来源与许可处理。

代码绘制先在原scene形成当前要看的关键形体。所选动作依赖身体时，先画出真正作用及前后需要看清的姿态，放定支点、躯干朝向、四肢弯折及手脚与道具的接触，再让衣物随这些姿态形成轮廓、承托与遮挡；据此决定哪些部位分开、哪些轮廓需要变化，再连接姿态之间的过程。器物从用途与受力关系确定薄厚、接合和内部结构，再展开当前景别能看见的面。所选画面是一处共同场面时，把必要承托面、通路和前后层次与主体活动范围一起做实；独立分图与抽象图解按自身比较、尺度或对应组织。SVG用路径组织这些轮廓与体面，以分层、遮罩和接合点支持活动；Three.js用实体、内外结构与遮挡显出关系，相机沿观看重点取景。通用组件提供起点，具体形体与控制依本题关键画面完成。

描线选择有意义的外缘与结构转折，线宽、收口和分量随景别与相邻图件调整；纹理沿表面延伸，光影随体面、接触和遮挡形成。三维将光照归纳为可辨的受光面、背光面与接触暗部，与SVG、图片的色面层次和材质刻画相配。运动或视角变化时，接合、遮挡、纹理与光影跟随同一形体，避免圆润积木、塑料高光或全体棕色掩盖具体材料。

代码图件与图片合成后，按完整画面校准形体比例、材质刻画、亮度、饱和度与墨线分量；三维以灯光和色调映射后的实际输出为准，代码色值相同不足以证明画风统一。

图表与抽象符号可以简洁，按它们承载的关系设计构形、层级、排布和运动，保持准确的尺度与清楚的区别；具象人物与场景仍须完成相应造型。同一对象从地图接到近景时，选能认回身份的特征或位置承接，近景按实际机位、材质和动作设计。地图标记需要从复杂地形中分离时，可加贴合轮廓的浅边。

近景可重绘主体或深化原图件，保留前后可追认的结构与材质。作者根据实际图形核对时代、结构、材质与观看尺寸。

身份、行动与临时强调按各自含义使用本段角色色，延续对象的辨识。纸层、边框与阴影按内容主次组织层次。旁图外框与来源指认见[旁图策略](creative/windows.md#旁图策略)。

画面文字沿[文字与标签](creative/graphics.md#文字与标签)排印。

选用手绘标注时，笔迹保留轻重与收笔，落点准确，视觉分量与主体相配；需要分离复杂背景时，可加贴合笔画的浅底边。精确数据与地理边界保持准确形状。按约390px实际画宽复看主体、动作与文字，调整影响观看的细部、反差和前后层次。

## 辅助图件

辅助图件补足当前画面缺的承托、参照、指认或接触，尺度和反差按本镜主次决定。具象辅助图件按具体参照画出实际景别能看见的比例、材料边缘和接合。卷轴看纸怎样卷上木轴，文书看纸边与压叠。

释读框和纸卡按所承托的内容安排留白、边缘和层次，视觉分量配合本镜主次。

需要现成分件时，可从 [props.mjs](../artwork/props.mjs) 调用 `documentSheet({id: 'edict'})` 等函数。每件用段内唯一的英文ID。函数返回连同必要定义的SVG，文字按本题自行布置。

- `scroll` 分出 `scroll-paper` 和两根 `scroll-left-roller / scroll-right-roller`。`documentSheet` 分出 `document-top / document-underlay / document-impression`，可单独揭纸或显印；`readingPanel` 提供承托文字的纸层。
- `woodenTag` 分出 `board / cord`。`sealStamp` 以接触中心 `(0, 0)` 为原点，可对准文书的印迹。`woodBox` 分出 `body / lid`，盖子坐标在后缘起点，按需要补绘打开后的内部与遮挡。

部件名称前带本次传入的ID，如 `edict-document-impression`。需要动作时按实际画面改绘或控制所用部件。
