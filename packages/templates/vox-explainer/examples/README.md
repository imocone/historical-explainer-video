# 作品与源码

仓库只保留教学源码、图例和时序，不附成品视频。需要预览时使用各例已有构建入口，在本机生成；生成物不进入Git。

作品按用途学习：整段表现看主体、镜头、动作与转形怎样带着观众前进；局部讲法看某种关系怎样说明白；技术小样只学接口。题材相同不代表整段表现相通，交付链跑通也不代表作品达到本模板的表现目标。共同画风仍取[画法及参考实图](../references/art.md)，当前内容、构图与节奏重新设计。

## 整段表现参照

[平均工资，藏住了谁？](salary/README.md)是本模板已确认的表现参照。跨题学习一件完整事件：主体如何取得注意，镜头怎样进入作用处，动作怎样留下结果，结果怎样转成下一次观察。先看实际过程，再查对应代码，把这些手艺用于本题；不照搬工资题、人数、钱束、布局或秒数。

## 局部讲法与实现

下面按具体难点取用，不把被选中的局部案例自动当成整片的风格、镜头与节奏基准。取用与讲法选择见[构思与编排](../references/creative/concept.md#构思与编排)。

| 作品 | 制作难点与可借做法 | 适用条件 |
|---|---|---|
| [地图窗口与岸上消耗](map-window/README.md) | 有据地图在原画布展开、推近、让位并返回；SVG兵棋、路线与标签共用当前投影 | 学习地理关系与普通图解间的接口交接；虚构无声技术小样，不提供历史事实或成品造型基准 |
| [一条近路，为什么让全城更堵？](braess/README.md) | 共同状态驱动车流与耗时，让局部选择和整体结果相联 | 本题有可说明的选择条件、瓶颈与结果依据 |
| [流畅，可以攒出来](buffering/README.md) | 表示转换、倒回与同源对照；骑行腿脚和车轮由同一播放状态控制 | 保持同一输入比较策略，或跨题参考身体与器物的接触和动作联动 |
| [少一半力，多一倍路](pulley/README.md) | 完整器物图片与精细代码机构在真实接合处结合，同一位移推导形体与读数 | 需要判断素材控制粒度、不同媒介怎样成为同一个场景；具体比较结构与素材数量不照搬 |
| [一次批准与一次送达](parcel/README.md) | 按作用范围取景，分开编排镜头与主体；分件、接触和状态共同形成结果 | 学习操作细节或镜头与动作的配合，物件结构与作用有据 |
| [诺曼顿号：海难与领事裁判权](normanton/README.md) | 约42秒后同一案件的承接、条约时间追溯与管辖归属转换 | 仅学习身份、归属与时间参照的接续；其中小人物、纸卡、箭头组成的静态流程图不作为整段表现基准 |
| [议立中的两个人选，为什么都没有即位？](succession/README.md) | 从参与者关系图改为可观察的处境与变化，同一人物跨镜头保持身份 | 列清人物和关系词仍解释不了结果变化；只参考讲法取舍，动作与画法局限见该例说明 |
| [粮多，为什么仍会断粮？](supply/README.md) | 同量粮车显示到达、消耗、补缺与储备；每轮结余实际留下并成为下一轮的基础 | 需要解释数量结果怎样形成，或原稿虽给出公式却没有演示作用与积累；附按原声范围组织画面的设计说明 |

理解外部项目的创作思路时，可查[Vox创作参考](https://github.com/holy-templar/vox-animated-ad-mcp/blob/main/SKILL.md)如何把含义与感受转成具体视觉意思，以及[Lemo数据叙事](https://github.com/lemomo-ai/lemo-opuscar/blob/main/styles/dataviz/STYLE.md)如何让数据的表示与变化成为作品本身。这里借鉴的是内容怎样形成讲法；这些项目各自的广告流程、固定数量、帧率、字体、字幕和声音约定不进入当前生产。

需要追到具体设计和实现时，可查[Motion Canvas图像运算](https://github.com/motion-canvas/examples/blob/master/examples/deferred-lighting/src/scenes/lightBasics.tsx)如何拆合、重组同一图像以显出运算关系，[3Blue1Brown表示转换](https://github.com/3b1b/videos/blob/master/_2024/transformers/attention.py)如何把具体词义接到向量表示，以及[花叔的图件、年份尺与剪报](https://github.com/alchaincyf/huashu-art-motion/blob/main/scripts/engine/reference_films/spacex/spacex_vox/scenes/s07.js)如何把时间间隔做成可见跨度。辨认本题相通的理解需要，再取用其中的设计判断或手艺；当前合同与工具沿本模板。

当前作品按本题决定是否使用生图素材及其作用，不沿用案例的素材数量或构图；地图素材沿专门方法准备。

局部窗口的现行形式直接查看[旁图方法与样式参考](../references/creative/windows.md#旁图策略)。

工资和路网保留独立研究作品的30fps与字幕布局；缓冲样片使用现行模板渲染器、公共字幕和60fps。正式创作使用当前工作单的画幅、帧率、字幕与声音条件；作品的剧情、构图、媒介和制作顺序由作者重新设计。
