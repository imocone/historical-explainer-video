# 两部长案例

讲解模板的参考案例仅有下面两部。两部均保留完整工程、时序和本机预览入口。

| 完整作品 | 时长 | 画面形式 |
|---|---|---|
| [运粮：粮在后方，前线为何断粮？](supply-mg/README.md) | 约3分钟 | 二维MG |
| [七国之乱：汉景帝到底在削什么？](seven-kingdoms/README.md) | 约3分11秒 | 全SVG |

它们作为完整讲解作品的表现参照：造型和排版做到什么程度，一整段内容怎样组织画面，动作、镜头、文字和声音怎样配合，整片如何形成变化与节奏。源码供查阅具体实现；不同题目重新设计自己的讲法和画面，不照搬这两部的题材、构图、配色或章节顺序。

各作品中的分段说明用于定位完整画面与源码。

共同画法仍由[画法与参考实图](../references/art.md)拥有；地图接口沿[空间方法](../references/spatial.md)，正式制作沿当前工作单与[制作接口](../references/delivery.md)。案例不提供新节目的事实，也不新增制作节点或验收门。
