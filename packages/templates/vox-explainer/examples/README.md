## 断桥取景试片

这张[同一原声时刻的对照图](../references/creative/bridge-focus-comparison.jpg)取自独立短试片的 8.77 秒。原画面两条路同框，北桥断口偏小，南桥和字幕叠在一起。调整后把注意力先交给北桥断口和两辆车，字幕区的场景淡出，到「看南路」再接另一处。近景同时裁掉了部分总览参照。用这张图判断取景和字位，卡点和前后交接要用连续画面判断。
