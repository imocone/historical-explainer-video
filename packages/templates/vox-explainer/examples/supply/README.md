## 它解决了什么

后方粮多、每天可发20车，并不等于前线每天收到20车。本例以相同粮车表示相同粮食量，把每天消耗10车、桥最多放行6车及储备补足4车放在同一参照中。随后把20车储备展开为五组，每次补4车，看到五天后耗尽。桥改为每天10车之后，到达与消耗相抵，储备仍为零；随后切入每天到达12车的新假设，演示余粮怎样积累。

这些部分由独立作者按模板完成，但初稿到“怎样重新攒起存粮”时，只呈现“到达＞消耗”和粮袋示意。公式正确，观众仍没有看到多出来的粮如何成为储备；前半段做成了演示，不代表结尾的新判断也已经解释。用户指出这一缺口后，原作者只修末段及必要衔接，保留原声和整段时长。

修正版在约50.08秒明确提出新的演示假设“每天能送到12车”：

1. 十二辆同量粮车进入同一排位置，前十辆归入“每日消耗10车”的范围。
2. 十辆被消耗的车退出，剩下的两辆仍可见，随后移入下方储备区；完成移入后，储备读数变为2。
3. 第二天重复到达与消耗，第一天留下的两辆一直留在储备区，第二批余粮移入旁边，储备变为4。

观众由同一批粮的去向看懂结余，由前一批保留、后一批加入看懂积累。数量和画面状态共同变化，读数描述已经形成的结果。这是本例需要的讲法，不能推广成每段都演两轮或一律使用入库、消耗动作。新假设仅用来展示已经给定的数量关系，不是原口播额外声称的现实事实。

## 本例怎样按时间组织画面

作者的整章设计在全面制作前就按原声范围说明画面与承接，试制后继续修订；以下整理的是最终讲法，末段包含这次局部修订。生产时同类决定写在当前单的`design.md`，由[整章设计方法](../../references/creative/design.md#整章设计稿)规定，不另设分镜文件。时间是本例的实际窗口，不是其它题目的固定节奏。

| 原声范围（约） | 观众看见什么 | 怎样支持下一次观察 |
|---|---|---|
| 0—8.45秒，Cue1 | 左侧粮仓有粮，右侧前线领取位置空着，运输条件随后进入 | 先建立后方有粮与前线缺粮可以并存的问题 |
| 8.45—14.65秒，Cue2 | 后方可发20车/日，前线消耗10车/日，十个领取位置同屏 | 保持同车单位与十个位置，等待实际到达量进入比较 |
| 14.65—23.10秒，Cue3 | 六车过桥填入六处，四处仍空；四车从前线存粮补入 | 到达与补缺的来处可分，接下来观察每日补缺对储备的影响 |
| 23.10—29.87秒，Cue4 | 初始20车储备展开为五组四车，按天扣除，最后归零 | 同车单位保留，局部一日缺口转成连续五日的累计结果 |
| 29.87—38.08秒，Cue5 | 回到同一仓、桥、前线；后方加粮，桥仍只能过六车，四处仍空 | 改变后方资源却不改变通过量，显出瓶颈所在 |
| 38.08—46.98秒，Cue6 | 明确假设桥改为10车/日，十车填满原来十个位置 | 保持每天消耗10车的条件，继续区分够吃与有余粮 |
| 46.98—50.08秒，Cue7前段 | 到达与消耗相抵，储备仍为零 | 先保留平衡状态，作为下一条件的比较起点 |
| 50.08—55.08秒，Cue7后段 | 再假设每天到达12车，两轮各消耗10车；余下两车依次移入同一储备区，0→2→4 | 前一轮结果保持可见，后一轮在其上增加，真正形成积累 |
| 55.08—60.63秒，Cue8 | 仓、桥、到达粮车分别归位，短词概括库存、运输能力与实际到达 | 用已经看过的对象总结差别，不再引入尚未演示的新作用 |

这一组织方式允许一段持续多个Cue，也允许一个Cue内比较两种条件。分段依据是认识怎样推进，不按每句口播配一页。末段修订把已明白的平衡演示收束得更早，为到达、消耗、余粮移入和结果停留腾出时间；没有把原来的不等式旁边再堆一套快速动画。

## 可取用的实现

本例的粮车共用`cart-shape`，到达、补缺与储备展开保持同一单位。末段两批粮车各有自己的对象，当前时间分别决定到达、消耗与移入储备的状态；第二批开始时，第一批余粮继续保持落位，储备读数在移入完成后更新。取用这种对象与状态承接手艺，具体讲法仍按[构思与编排](../../references/creative/concept.md#构思与编排)决定。

这部作品仍采用简化器物和压缩的两日演示，不模拟实际物流、修桥过程或历史场景。它的价值在于对应、去向和状态承接；画风与成品要求继续由[共同画法](../../references/art.md)拥有。

## 源码取用与复现

`source.json`保存原口播字幕、真实时序、字体与呈现参数；`scene.html`与`animation.js`保存用户已认可修正版的实际源码；`assets/narration.wav`为同一原声音轨。案例不依赖验证工作单、临时目录或远端调用，构建只写指定输出目录：

```bash
node packages/templates/vox-explainer/examples/supply/build.mjs build /绝对路径/验证目录
node packages/templates/vox-explainer/examples/supply/build.mjs stills /绝对路径/验证目录 19.3 25.8 50.8 52.05 52.7 54.1
node packages/templates/vox-explainer/examples/supply/build.mjs render /绝对路径/验证目录
```

按当前内容取用适合的对象控制、数量对应和动作承接手艺，不能把这一分钟的构图、次序、数量与时间复制成下一章的设计。
