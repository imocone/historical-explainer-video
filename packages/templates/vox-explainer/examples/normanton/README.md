`map/`与`ordinary/`中的`scene.html`、`animation.js`保留正式接纳scene的画面与动作；普通段仅清理了未使用样式，对应源码摘要已同步更新。`source.json`保留对应导演观看目标、原始字幕时窗、moments、Cue绑定、appearance及图件身份，时间相对原声音频；成片从原轴第368帧开始。

本例保留实际交付与成片，不包含原工作区、候选、缓存或远端调用入口。正式创作仍沿当前工作单使用模板。
