# TR002 地理定位依据

本笔记由当前作者整理，仅支持区域定位与地理骨架，不提供诺曼顿号实测航迹、沉船坐标、救生艇航迹或1886年港区设施形制。

1. 横滨市港湾局《横浜港のあらまし》，“横浜港の位置”段：横滨港位于东京湾西北侧，北纬35度19～29分、东经139度37～45分。原页：https://www.city.yokohama.lg.jp/kanko-bunka/minato/yokohamako/gaiyo/gaiyou.html 。本图用[139.65,35.44]为区域地名锚点，不声称出港泊位。
2. 海上保安厅海洋情报部海图档案JLAA00238《神戸港》，资料表“緯度経度”：海图范围34度37.4分N、135度10.1分E至34度43.1分N、135度14.6分E。原页：https://www1.kaiho.mlit.go.jp/kaizuArchive/kaizu/kaizu.cgi?id=JLAA00238&p=928 。本图用[135.20,34.69]为城市区域锚点；不复原该1935年海图内容、港池或1886年设施。
3. 串本町《町の概要》“地勢”第1、2段：串本为本州最南端地区，潮岬北纬33度26分、东经135度46分；纪伊大岛在近海1.8公里处。背倚纪伊山地，纪伊大岛为沿岸岛屿。原页：https://www.town.kushimoto.wakayama.jp/gyosei/kushimoto-town/gaiyou.html 。仅支持在纪伊半岛南端近海标示“大岛附近”；地图不放大到港池、不画现代跨海桥，不把代表性海域标记当沉船精确坐标。
4. 海陆骨架使用模板内已保留的Natural Earth 1:1000万公有领域land/lakes/rivers数据，来源：https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/ 与 https://www.naturalearthdata.com/about/terms-of-use/ 。它只支持宏观海陆形状，不提供高程与历史边界；地表阴影及材质为作者的定性插画。画面保留“地理骨架：Natural Earth”短注。

画面性质写“区域与行动示意”。出发地、目的地与遇险区分开标示，虚线只说明计划行程关系，不画一条由船沿线行驶的伪精确航迹。遇险以熊野滩南部近海的区域圈表示，不放坐标十字。岸边救援随后展开为局部情境示意；其移动不代表已知的具体村落、路径和时间。
