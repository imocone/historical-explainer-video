## 为什么重选讲法

本段需要理解：朝臣还在争论翰与浚谁该继位，宗爱却利用宫禁控制与假诏清除议立者，再扶立第三人余。把人物、宫门、皇位长期摆在同一画面，再连接“拥立”“交恶”“亲近”，会让观众读关系词，却仍看不见原来的选择怎样被改变。

这一版先分开观看两派的选择依据，再切近宗爱实际掌握的出入条件。假诏、重臣入宫、门在身后关闭、伏兵合围及另立新君依次成为可观察的状态变化。人物在不同镜头保有形象和名字，身份连续由这些对应承担，构图随当前理解需要改变。

这段取舍可用于“列清参与者仍讲不清变化”的题目；结构或比较本身就是解释对象时，一幅准确图解也可以成立。本例的宫门、人物、九个画面和先后顺序都来自当前内容，不构成其它作品的固定分镜。

## 看哪些实际画面

- **约4—18秒：** 同一批议立者分到各自人选附近，成年、有威望与嫡系正统的理由分别取得注意。这里靠分组、身份与对照表达支持，不需要再画支持线。
- **约21—35秒：** 先呈现两种可能继位结果给宗爱带来的危险，再引出余。前半处明确是假设，没有将翰、浚画成已经即位。
- **约35—43秒：** 诏命的名义与真实发出者分开，随后进入宫内朝外的视角；同一批重臣进入，门在其身后关闭，伏兵上前。赐死秦王另起一镜，区分被杀的议立者和另外遭到赐死的人。
- **约44秒以后：** 余进入即位位置，前文的变化形成最终结果。没有在结尾重建一张所有人物的关系图。

本例没有关系连线，是因为这些联系已由分组、动作和前后镜头表达。路线、网络、管辖或对应本身需要被看清时仍可使用线，按[连线方法](../../references/creative/graphics.md#跟着讲解引导注意力)选择，不能从本例得出禁用连线的结论。

## 仍有哪些局限

人物主要是完整图件，入宫、倒下等动作仍有纸片移动和旋转的感觉。假诏到达议立者的交接，以及开头两个人选与结尾第三人即位的构图呼应，还可以更清楚。用户的静音观看仍包含原口播字幕；关键画面隐藏字幕后是否保有足够解释，要按当前作品复看，不由这条反馈代替判断。

本例保留了验证时的整屏深色场面和简化器物，它们不替代现行[共同画法](../../references/art.md)及固定底板要求。正式创作保留模板底板，以本题需要的环境、造型与动作重新设计；留白与取景按[当前观察](../../references/delivery.md#画布与动画)安排，不用本例放宽画法。这里的历史叙述与示意也不是新工作单的事实来源。

## 源码取用与复现

`source.json`保存本例声音时窗、字幕、素材引用及呈现参数；`scene.html`、`animation.js`是该版实际画面与动作，`assets/`保留对应图件及已裁出的原音轨。没有工作单、正式节目目录或远端调用依赖。构建命令只写指定验证目录：

```bash
node packages/templates/vox-explainer/examples/succession/build.mjs build /绝对路径/验证目录
node packages/templates/vox-explainer/examples/succession/build.mjs stills /绝对路径/验证目录 15 36.4 39.7 40.9 47.5
node packages/templates/vox-explainer/examples/succession/build.mjs render /绝对路径/验证目录
```

本例的源码帮助观察取舍与实现，不作为其它作品的骨架。当前作者仍从本单内容沿[构思方法](../../references/creative/concept.md#构思与编排)形成自己的讲法。
