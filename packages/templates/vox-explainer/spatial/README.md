# 空间工具

本目录提供vox-explainer的内部空间工具，普通讲解与地图推演均可按需调用。作者决定内容、坐标、布局与动作；地图推演执行[空间方法](../references/spatial.md)，在共同画布上组合数据地图、SVG图件与必要的局部情境，普通讲解可组合其中所需技法。工具只执行几何，不决定史实、控制权或胜负。正式交付仍是scene与moments，不另交配置文件。

按当前调用任务读取下列接口，不必通读全部工具。专业判断继续由[空间方法](../references/spatial.md)拥有。

| 当前任务 | 接口说明 |
|---|---|
| 裁切地图数据、建立地图窗口、区域层 | [地图窗口与区域](docs/map-window.md) |
| 共同镜头、路线、对象运动和指认线 | [空间镜头与行动](docs/scene.md) |
| 局部开口、来源引线、标签布局 | [窗口与布局](docs/detail.md) |
| 地理骨架、地形定位、兵棋及署名 | [地理与兵棋资源](docs/resources.md) |
