# 纪录片回忆片头方法

片头是本集生活画面的短暂回望，观众沿迎面靠近的画流进入一张宽景，再看见本集标题，经过缓慢黑场进入独立成立的正文。

- 前3秒固定五张正文完整场景，D01—D05；约0.6秒一张，持续漂近并交替向两侧微微掠过，采用轻柔叠化和少量交接柔化，画面持续迎面漂近，不强化前段失焦；不在换图时猛推或重新起步，不做闪白、横带或卡片轮播。通读整集后按人物动作、生活气息、空间纵深和情绪连接选图，顺序服务同一回忆，不机械按正文顺序或随机数抽取，也不固定为某几个行业。
- 前五图各只引用一个已完成正文Beat内的`fullframe-image`请求。P4依据已完成正文选定，`bodyRefs`保存该Beat编号，`requestId`保存其原请求编号；未被剧情视频覆盖时，直接使用该请求的P3实图交付；被覆盖时，P4使用实际视频在该请求出现Cue上的定格，沿原片头动画呈现，不补生被覆盖正文图。来源、权利、时代和不可补造项继承正文请求，不另建一套视觉brief或来源断言。
- `focus`给出画面主体或纵深落点的归一化坐标，须依据原图纸的构图与相机方向选择，不能所有图片都套同一坐标。模板据此向前推进，不复制正文整段相机运动。
- 第六张D06固定为本集新设计的鸟瞰或俯视节目世界全景，从3秒延续至收尾；地点、时代和空间身份由工作单`templateContext.openerWorldContext`中的正式节目设定决定，不由通用模板写死。不得从P3各Beat选择、复制或改写正文图片请求，也不得复用其它集、内置或其它节目图片。每一期重新自由选择鸟瞰位置、观看角度和构图，不按集数或固定序列套用方案，并填写`framing: wide / panorama`。
- D06提交`visualBrief`的`subject / actionOrState / environment / visibleResult / composition`，以及`bodyRefs / sourceRefs / mustNotInvent / focus / framing`，不填正文`requestId`。设计只能基于节目正式世界设定、本集已定内容与来源，构成同一时空的完整空间全景；不得补造具体地点形制、人物关系、文字或历史事件。引用SA时必须是工作单已登记且允许外部生产的来源。P4当前作者按现有Visual和图片入口为本集新增这一张，P4直接使用其唯一交付。
- P1一句观察逐字保留，用于约束本集进入方向与选图，但不朗读、不显示。正式seriesTitle明确采用“《节目名》：走进《原典》”时，中央原典名于3.4—4.5秒缓慢溶现，4.95—5.45秒溶出，本集标题于5.35—6.1秒溶入，只切换一次，静止至8.2秒随画面暗下。没有明确原典则直接溶现本集标题，不猜书名。不显示节目名、集数或副标题；统一饱满毛笔楷书，保持居中，不缩放、不移动、不加装饰线。名称来自现行seriesTitle与episodeTitle，不新增作者字段。
- 全片头10.5秒：五图3秒、末景从3秒接入、至5.6秒从深度虚化中缓慢合焦并持续推进；完全清晰后保留2.6秒持续推进，8.2秒开始渐暗，8.85秒到达纯黑，停留0.5秒后正文首景用1.15秒从黑中柔和浮现。正文口播与字幕仍从正文正式时间开始，片头只有原创配乐，不生成TTS或播放旁白。

成品应让人感到回忆涌来并落在一个可进入的世界中；不把本片头做成正文首段的半截，正文不依靠片头补足必要主体或背景。宽景与选择效果由作者判断，字段和文件引用通过只说明结构成立。
