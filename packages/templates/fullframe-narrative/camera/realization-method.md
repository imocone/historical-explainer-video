# 实图与最终镜头

本方法在联合设计成立、图片导入后执行，拥有实图表达、最终取景与图片问题的处置。AI判断，程序测量和呈现；图片写原asset，镜框只写原motion，效果锚点写原请求，不另交相机成果或审图报告。

## 1. 对照设计看实图

合读原`purpose / sceneDescription / attentionPlan / motion`与实图，确认已定表达、必要身份、文字、动作和关系成立；景别、主体分量、近远层次与清晰范围适合当前观看。保留有意的艺术处理，不以写实程度、全身或统一景别作标准。

对照图纸，在实图中找到承担含义的内容，并用实际取景落实其主次。图纸选定物件、空间或关系为主时，让这些内容在镜头中取得相应分量。调框能够兑现设计就校准镜框；实图缺少必要内容或空间时，按末节修图。表达核对与取景校准在同一次落镜中完成。

涉及时代外观时，同步对照已选本人原图与历史依据，确认可见面容、年龄、衣冠、发式、建筑与器物的基本特征确实保住，且实际取景可辨；不能只看换了衣服、提示词写对或传图成功。发现混脸、错代、身份或场合混用时按[时代外观方法](../../../modules/direct-episode/references/period-appearance-method.md)区分依据、图纸、参考交接或生成偏差，沿本步骤原失败回路处理，不削弱场面原有动作、关系与规模。

生成结果已能看清内容与位置时直接使用；否则沿原`inspect-design`取得同源路线图，它同时提供完整原图、路线及实际起中末取景。仅在这些材料不足以判断具体内容、镜框或锚点时补看所需原图，不重复打开已看清且未变的材料。

人物聚焦／疑问提示与柔光按[效果组件的实图定位](../effects/AUTHOR.md#实图与呈现)填写锚点，再测量。图片、设计或程序有问题时按末节处理，不把所有偏差都归为镜框问题。

## 2. 落实原观看任务

将入口、沿途与落点对应到实图，按[实际取景判据](../references/picture-review-method.md#当前窗口内的设计成立)确定镜框。需要看手和物件的关系，就同时保住这层关系，不能只保住脸；非必要外围可舍去。

可调整位置、尺度与中心，保持原任务、运动类型、观看点数量及顺序、焦点和方向意图。不能因某处好看就换重点。作者自选的隐藏手法若无必要，先回同一联合设计按设计复核方法调整、更新原锁，不在落框时静默改任务，也不为手法反复返图。

- **推拉：**先定较紧的框，推近为末框，拉远为起框；保住重点、动作和必要空间，再定另一端及中间点。中心随实图安排，可让重点保持近似屏幕位置，也可向某侧展开；推近逐步内含，拉远相反，不默认居中或最小框。
- **平移：**先定能容纳必要内容的尺度与高度，再按原焦点顺序安排等大镜框。可带竖向位移，保持连续、不折返；布局偏移不应倒置观看顺序，沿途关系与逐渐显露须有余量。

准确镜框写回同一候选的原motion，按[几何与时窗合同](execution-reference.md)测量。归一化矩形以完整源图为基准；源图和输出同为16:9，width等于height。只看改动影响的路线、取景及接缝，未变且已成立的框直接沿用。

`requiredTravel / routeLength`说明需求和可用行程，`visibleEndViewport`说明正文可见末态，`actualEndViewport`含运行尾段。时间结束未到理论终点可以成立，但必要表达必须已经发生；路线提前耗尽不能由程序补停。`speedRatio / speedChanges`沿用联合设计，需要改变时回该设计复核。路线须覆盖整个实际窗口，读落点时仍持续运动；空间不足按同一设计调整取景与路线，实图不能承载时定点修图。

程序只换算、插值和执行，不自动挑主体或替作者找框。测量成功才形成最终相机锁；失败留在当前候选修正。AI不手算逐帧坐标、不另写运镜脚本，也不用两张图片冒充同图运动。

## 3. 看实际观看结果

路线图蓝框是起点，黄框及虚线是完整路线，编号是观看点，绿框是当前阅读窗口末框。下方起中末取景排除已定A/B转场遮挡与入场预运镜；后镜尚未创作时，末图取当前正文末帧，预留尾段仍参加测量。不能把未显露或已遮住的尾段当作观看结果。

确认当前取景确实实现重点、关系与注意力变化，主体勉强入框不等于成立。[冬营对照](../examples/viewing/README.md#同题对照)的原镜头放大了脸，却裁掉手和电报；修正依据三者实际位置共同落框，不复制另一图的终点。部分显露、短暂入框或严格接镜无法由三帧裁定时，按需查看实际接缝。

采用速度变化，或静态材料不能消除具体运动疑点时，用原`--clip <AR编号>`连续看节奏与落点；联合单用`--clip <Beat/AR编号>`，不同时传`--beat`。未落实镜框时，入口先提供完整实图，不渲染旧坐标。恒速且静态材料足够时不逐图渲染；未变输入复用已有预览。单图clip不能代替完整A/B或跨Beat接缝。

字幕与解说框的遮挡边界由[解说框组件](../callout/AUTHOR.md#内容组合与容量)规定，不在这里新增检查义务。所有镜头成立后回根入口完成解说框与Cue，再返回author-beat，由父Module完成后续编排；P4执行同一motion，程序不自记观看结论。

## 完成与定点返图

| 实际问题 | 处理 |
|---|---|
| 内容与空间足够，只是取景不合适 | 校准本图，落实原重点、景别和顺序 |
| 表达、必要内容、身份、文字或空间未兑现设计，调框无法恢复 | 沿当前图片入口定点修正该图 |
| 设计自身矛盾，即使忠实成图也无法完成 | 回同一联合设计修正冲突 |
| 实际执行与确定路线不一致 | 保留图片和候选，修程序 |

明确缺少必要内容时不先做无效落框。继续完成当前范围其它镜头，收齐失败叶图，保留合格图，按当前阶段授权及图片修正许可处理；不设试框次数，不由测量失败自动付费。一次报错也不证明图片无解。

返图理由说明已定表达、实图偏差、为何调框无效及应恢复的条件，交原图片入口的`--revision-reason`。意见只修当前设计，不夹带新细节，不泛写“不好看、人物过大、裁脚”或机械要求退远、缩人、全身。程序携带当前失败图和意见，保留旧记录及合格图；新图到位后在原motion完成必要校准。调用、导入及未知结果的恢复按[图片交付](../../../authored-images.md)执行。
