# 人物身份与造型方法

已选场面有人物时，先按[历史视觉依据的作者使用](../../../modules/direct-episode/references/period-appearance-method.md)读取资料、核对人物时期及活动，完成必要补查和原图交接；本方法负责把这些依据画成具体人物，并保持章内连续性。描述深度服从实际距离：远景、背影不用补五官，也不改成特写。

先写清本图的时代、所属人群与角色，再选实际距离下可见的发式、衣装和装备形状：头发怎样收束，衣襟在哪里开合，袖口、衣摆及裤装是什么轮廓。同场不同群体分别绑定，准确名称与少量必要形状合写；例如已确定穿对襟短褂，就写清前襟居中相接、扣结位置及本图可见袖口，不让生图只凭“传统服装”或国籍选造型。形制依当前依据，不能把一例套给所有时代或人群；缺少必需身份依据交原责任方，不猜族属、徽记或精确肖像。画风参考只提供画法，不提供这些内容。

需要辨认脸时，按下列方法形成或沿用造型；其他人物保持实际距离需要的概括程度。

1. **按本人身份接续已有设计。** 查当前任务`templateContext.priorVisuals`内的相关`sceneDescription`及同一候选前图，不把相同职务当作同一人。已有设计与可靠原图相容则沿用；前图只有身份或衣装时，按第2项补定长相。来源冲突与跨章范围按共同方法处理。
2. **用一句话落实有据的长相。** 对照适用原图，提取少量可画的脸型、眉眼比例、鼻形、颧骨、下颌、发际线或胡须特征，分别绑定对应人物，保留年龄及精度限制。没有可靠本人图像时，结合有据文字及既定年龄、身份作合理造型。不把“英俊、威严、剑眉星目”作为人人共有的脸，不靠更换族群、随意增减年龄或按善恶分配美丑制造差异。
3. **复现时保住稳定特征。** 同一人的脸型与五官特征保持，年龄变化、表情、发式和衣冠服从当前故事及相应时期资料；新图继续使用适用原件，前序生成图只辅助连续性。动作、观察位置、构图与环境按当前场面决定，其他人物不套用这一组合。
4. **普通人物保留自然变化。** 配角与群众不逐人定脸，在已定时代、年龄和人群范围内让脸型、五官自然变化；同场需要看清的普通人物用一句群体差异说明即可。远景、背影或看不清脸的人保持原有概括程度，不为这项方法补人物或强行改成特写。

例如两位同龄的虚构主要人物可以分别写“甲：长窄脸，颧骨略高，下颌收窄”“乙：短宽脸，鼻头圆钝，下颌宽厚”；同场普通人物写“其余人物面部形状自然不同”。这只示范描述方式，具体组合从当前人物重新设计，不按例子分配固定脸谱。

造型细节服从所选景别与观看任务，在同一画面描述中交付，不另加人物表或独立验收步骤。

## 写入本图

在完整场面中按“姓名或明确角色＋身份造型＋当前需要辨认的脸部特征”写清本人，再接其姿态和互动；多人分别绑定，群众写群体特征及自然差异。复现写出稳定特征，不只写“同上”。`acceptanceCriteria`只摘录当前不可丢的辨识条件。原图片入口、P3实图落实及后续全画幅共同消费这份场面原文中的本人造型。
