# 全画幅设计复核方法

生成前在联合设计正式测量后读取并完成下述复核；生成后按落镜方法结合实图落实表达与实际取景，沿用仍成立的设计判断。未变且完整保有的判断沿用，不新增报告、字段或审阅轮次；锁与失败返回见[模板根](../AUTHOR.md)。

## 设计复核

完整消费同次`design / visibleComposition / incomingTransition / transitionReading`，逐图配回来源、旁白、前后图及全片语境；长输出按完整target分段。先还原具体画面，再判断表达，不能只看`ok`、运动名或作者自述的“体现、象征、说明”。

沿本次逐图复核把这一组画面连起来理解：实际展开了怎样的世界、经历和意味，哪些只靠旁白说明，哪些由图像变得具体可感？同一图像换配新一句旁白后，可能只改变解释，没有产生声称的视觉揭示；[运枪教材的误判镜头](../examples/narration-to-scene/README.md#没有被解决的误判)保留了这种局限。尺度、光色和气氛也会改变意思，画得漂亮仍可能让“失去掌握”读成“浪漫启航”。这些判断融入下列原复核，不另开整章审阅，也不以所有镜头都必须转折、增加知识或静音自明为标准。

1. **所画内容是否兑现任务。** 配着当前旁白，从已还原的画面指出支撑主要意味的具体安排：观众看见了怎样的状态、处境、关系或反差，又会因此理解或感到什么。依据须在画面里，不能只来自`purpose / viewerChange`的解释。人物、道具和文字按其实际作用判断：通信、会商或读信本身就是所讲内容时可以成立；讲利益相反、成本叠加或交付受阻时，仅有相关人物、表情和概念标题仍需回到[场面构思](scene-selection-method.md#把文字改编成画面)。名称、数字和背景可由旁白交代，静默、静物、含蓄意象也可成立，不要求图像独自讲完全文。A/B共同承担职责，不把B的任务算作A遗漏，并按[共读判据](scene-selection-method.md#两个决定性瞬间)核对实际推进。选场未兑现职责就重新选场，场面正确而调度、主次不足就联合调整；不因另有画法而返工。
2. **画面与取景是否成立。** 从`sceneDescription`按[交付说明](picture-delivery-reference.md#写成可直接绘制的场面)还原完整画面，再按下节放入实际镜框；具体现场核对视点与动作，其它内容按实际对象与联系核对。找到承担本段意思的可见依据，判断它在镜框中的分量、清晰度与主次是否支持表达。视点、大小、姿态和场地能否同时成立，动作与必要关系是否可读？光照、形体和远近处理是否服从当前场面与Visual？发现缺失或矛盾时，按实际原因在同一设计中调整场面、构图或路线。
3. **接缝是否服务全片。** 合读前后Beat的旁白与观看职责，理解前段留下什么、后段新增什么及主要关系；同Beat判断对应两图。把实际落点、显露、后镜重点与持续运动连成观看，按[共享节奏复核](../../../modules/render-video/references/narrative-transitions.md#接缝与全片节奏复核)判断关系与感受是否兑现，已有贴切选择保留，改动须有明确收益。数量、理由自洽或程序通过不能代替观看判断。A/B各用实际显露窗口，状态变化不能提前、延后或读反；按已定速度变化与持续运动理解实际观看，保留跨Beat预进入与退出尾帧。光影增强后一并看明暗、轮廓与关注位置的接手，判断共显重影、明暗跃变或先露亮点是否干扰阅读；叠化与闪黑按前后字幕的承接或休止需要选择，不因反差增强自动插黑或统一减弱光影。入口镜框不等于已露区域，转场不能补造图中动作。
4. **来源与身份是否支持。** 对照本图`sourceRefs`实际正文及限定核对人物、行为、对象和结果；编号、同话题或前情不等于支持。漏引、错引在当前单位可用来源中修正，C引用不越出单位cue；来源不支持则回选场，不能换编号掩盖。合理演绎、意象和环境细节按原边界保留。时代、所属人群及必要衣冠不能被匿名外貌替换；确需辨认的已定身份特征写入验收条件，不临时补造。`exactTexts`按[交付说明](picture-delivery-reference.md)核对含义、引述真实性与对象绑定。
5. **交付是否抓住关键。** 请求只写本图；`acceptanceCriteria`摘录已定设计中支撑表达、不可失的可见条件，例如去向仍有阻隔、双方作用于同一对象、旧承重与新增重量同时可读。标题清楚、人物出现等辨认条件按需保留，不能代替这些表达依据。缺重点只补必要条件，设计未定先修设计；不重抄完整场面，不套全身、宽景、固定占比或“完整前中后景”。必要画面内容均由`sceneDescription`交付，验收摘要不是第二份蓝图。

## 当前窗口内的设计成立

涉及时代外观时，在上述来源与身份复核中按[时代外观方法](../../../modules/direct-episode/references/period-appearance-method.md)对照适用依据与本图形制，包括环境和器物；关键特征须已写进`sceneDescription`并能在当前观看窗口辨认，不以来源编号或朝代名称代替设计。

把起始、沿途、实际末态与关键显露时刻视作观众看到的镜头，判断主次、主体分量、边缘、遮挡、朝向空间及必要联系。母版与实际采用的取景都应成立，不要求任意裁切、居中、对称、全身或每镜所有景别。源图表达完整；近取景可舍非关键外围，但不能丢掉当时承担表达的动作、去向、规模或环境。

在实际运镜中判断光影与清晰范围是否支持应看的对象、关系和主次变化，不凭源图中人物大小或与旧图占幅是否相同裁定。布局变化按[实图落镜](../camera/realization-method.md#2-落实原观看任务)校准本图镜框；目标或环境联系因缺失、虚化、压暗而无法呈现时回原图修正，不删观看任务。

将已写的位置、大小和连接放入`visibleComposition`实际框及放大量；有数值就与框边对照，没有数值则依据具体相对关系，依据不足回联合设计补实再测。理论终框不能替代实际末态，起中末三帧也不能漏掉关键显露时刻。与`attentionPlan`对照：

先按[清晰观看下限](scene-selection-method.md#阅读与运动)核对单A及A/B每张图，结合阅读预算与进出转场的实际显露；不足时沿原联合设计修正，Beat范围不足则返回Director。随后还原这条路线实际怎样使用时间：入口读清什么，运动中谁获得主位，落点还有什么值得读。把运动名遮住后仍应能从画面关系说明所得。若同段多图只是相似速度反复放大中部或退回整图，按具体内容判断是否在重复同一种观看；需要移交注意力而构图没有接力位置时，回联合设计调整，不能只换运动名或为现有缩放补理由。此判断归原设计复核，不增加轮次、配额或结果字段。

- **强调：**目标的尺度、位置及周边竞争确实改变了主次；两对象都在框内或中心移动不等于强调。
- **揭示：**需要辨认的部分原本在初框外，实际扫过能看清，并有阅读时间；二维移动不能解除遮挡。开头已可见就不能称为刚出现。上游观看任务或因果先后确实要求揭示时，先在联合设计重排场地与取景，不删承诺降任务。若“先完全藏住、再露出”只是作者自选手法，先判断它是否必要；图中已能清楚表达原任务时，可回同一联合设计改为强调或持续观察，复核受影响的观看顺序与接缝，更新原设计锁。不能只为维持自选手法反复重生合格场面。
- **持续观察：**同一主体、动作或处境足以支撑注视即可，不强求每秒新增信息或隐藏后再显露。
- **末态：**时间结束可以未抵达理论终点，但必要焦点与`viewerChange`必须已成立；余程只用于不影响任务的后续构图或收束。

成立设计保留；问题按真实归属修正并重测，不降低条件。静态要求写`acceptanceCriteria`，观看先后写`attentionPlan / motion`，不让生图执行推拉或多个时刻。

## 交给实图落实

设计成立后进入[实图落镜](../camera/realization-method.md)，由同一作者确认生成结果与实际观看。图片、设计或程序的问题归属及定点修正由该方法唯一规定；不增加审阅步骤，不用技术通过代替表达成立。
