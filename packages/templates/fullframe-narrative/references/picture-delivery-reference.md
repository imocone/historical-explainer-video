# 全画幅图片交付说明

联合设计首次写入场面描述时读取；未变且完整保有的内容沿用。本说明只管交付，构图由[构图方法](picture-construction-method.md)形成，测量后的判断由[设计复核](picture-review-method.md)承担。

## 输入与结果边界

结合`purpose / attentionPlan / sourceRefs / mustNotInvent`，写入唯一的`sceneDescription`、少数`acceptanceCriteria`及必要的`exactTexts`；任务或场面改变时按模板根同步修正受影响内容。

`albumPlan / roleInAlbum`限定本页作用，`viewerOutcome / mustShow`限定必须交付的认识或感受，`relationFromPrevious`限定语义承接；复现元素消费当前Beat的对应引用，通过状态、关系或语境呼应。前序读取按[场面方法](scene-selection-method.md#事实环境与前后语境)。`continuity.subjects / props`提供整拍连续性线索，`carryToNext`提供主体／道具的复用提议；每张图的实际出场内容、场景与取景由本图设计确定，并写入`sceneDescription`。图纸选定袖口、手、物件或环境时，按这部分内容交付。跨场景需要实图造型参考时，由作者沿原图片入口显式选择已查看的前图，继承本图所需的身份与外观。

## 场景连续性

`previousTreatment.exitPicture`是同段上一全画幅末张的场景原文，不是整Beat概括。按实际时空与物理现场判断`continuesPreviousScene`，不凭period/location文字异同裁定。将必要承接事实直接写入本图对应字段，保留本图职责和动作；语义呼应不自动建立物理连续性。

## 事实与形式边界

- 具体史事、关键身份、结果与因果依据正式来源。代表性行动和反应可以演绎，场地可合理重建，但细节不成为新的史实证据；多地点、年代或跨事件因果不能冒充同一写实现场。
- 人物身份、造型与动作在场面描述中分别绑定本人，按[人物方法](character-appearance-method.md)形成；文化身份、政权、国籍不能互换，匿名外貌不证明族属。
- 按口播含义创作一张完整16:9画面，不做拼贴或拼图。A/B顺序呈现各自画面。
- 本图只写内容与观看要求；画风归Visual，图片工具装配与保存归共享交接程序。按语义区分制作指令与剧情中的装箱、画布等正常对象。

## 写成可直接绘制的场面

`sceneDescription`是完整静态画面的唯一原文。先在联合设计中形成画面，再按阅读顺序表达，不能把原来的字段标签串成清单：

按当前画面写清主要内容、位置、分量及必要联系；需要具体现场时，先说明从哪里、以什么距离看向哪个场所，视野容下什么；再写场地怎样从近处连接主体和必要去向，交代主次、分量、距离、遮挡与四边范围。沿这些位置写入人物身份、必要造型及当前姿态、视线、支撑、接触、承重和回应；结果写成此刻可见的状态或痕迹。最后写时间、天气、空气、剧情光源、明暗重点和情绪所依赖的可见安排。静物、环境与意象按自身需要组织，不为凑要素加人或动作。

必要占幅与坐标直接跟随对应对象，注明当前姿态、可见测量范围和完整16:9叶图基准。场内站位写“在场地中段”，需要较近取景时才写相应景别；不能一面要求小人物，一面又称其为近处主像。数字说明已经设计好的空间，不代替空间本身。

通读场面，确认这些安排在同一完整画面中成立；具体现场能从同一视点同时入画，位置、大小、持握和状态不相冲。同一动作与关系只讲清一次；观看收益及隐喻解释留在`purpose / viewerChange`，例如“未获婚约”不能被误写为“手里没有礼物”。`acceptanceCriteria`只摘录少数不可失的可见条件，不承载另一套设计；必要画面内容须已在场面原文中写清。

交付描述一张静态画面。“平移后露出门口的人”应写成源图中人与门口的位置、大小、遮挡和连接，显露次序另交`attentionPlan / motion`。镜框坐标、推拉过程和“留足运镜空间”不交生图补设计。材质和有剧情作用的局部颜色可以写，统一媒介、配色、纹理与渲染技法归Visual。

修辞的`intendedMeaning`落实为动作、处境或意象；`prohibitedLiteralization`防止事实误读，不等于禁画象征物。程序按本图引用合入适用限制，作者不重复抄入`mustNotInvent`，也不把前图比较过程写成禁造项。

画面需要文字时，登记`exactTexts`并在`sceneDescription`绑定对象与作用，随完整画面一次生成。作者可以准确概括已有含义；标为原话、史料或文书原文的文字须有对应来源，不能把转述冒充引文。保留已定符号、小数点和词间空白。程序据此交付准确文字，验收条件不重复抄写。

图片入口原样传递`sceneDescription`，只附加时地背景、原文字与事实限制、连续性参考及Visual。`purpose / attentionPlan / acceptanceCriteria`继续供设计复核和同一作者实图落实读取，不再作为重复叙述拼入绘画指令。生成端不补选主要关系，原来源与禁造边界保留。
