# 全画幅场面选择方法

本方法由全画幅作者读取，唯一拥有场面选择与A/B决定性瞬间的成立判据。Director按需读取以预判画面组织和窗口可能性；正式画面数、Cue绑定与完整设计由Template作者决定。

## 把文字改编成画面

把口播理解到足以构思的程度，再选择画面：**进入事情的具体世界，找到值得观看的角度，把它组织成一段经历。** 关系清楚是其中一部分；规模、氛围、生活质感、情绪、反讽与想象力同样可以承担内容。以下推敲都在原联合设计内完成，不新增步骤或分析稿。

**先理解事情怎样存在。** 合读当前口播、局部语义和`viewerOutcome / mustShow`，放回全片理解其作用、语气、条件、程度与不确定性。能复述“计划冒险”“各方分歧”“最终失控”还不够指导选场：计划动用什么真实力量，参与者希望它做什么，准备与实现之间差在哪里，失去掌握对谁意味着什么？从正文和已投递来源认清相关的人、空间、物质条件、作用过程与处境；不熟悉的关键事实不能靠想象补全，非关键场景与代表性动作仍可合理演绎。这番理解让作者有东西可选，不要求把整个过程画完。

声音承担适合听取的人名、数字、地理名称和背景，画面让这个世界及其中值得体会的意味成为观看内容。文字里写着“某人决定”，画面未必需要重演决定现场；可以看见决定作用于什么。但计划、愿望与风险仍须保持未实现的性质，不能为了画得具体就补成卸货、出兵、事故或真实会面。已有`mustShow`仍须兑现；声画分工存在实际矛盾时返回Director处理。

**从事情中选择观察角度。** 想清观众此刻跟谁、跟什么，站在哪一侧体会。筹划者看见可以发动行动的力量，搬运者面对箱子的重量，掌握运输的人关注船与目的地；同一件事可形成完全不同的观看。根据当前意味，选最能打开内容的一面，不默认沿着被提到的人逐个给肖像，也不把港口、城市与人群当作丰富背景往后贴。

例如运枪，先把“购买步枪与船”理解为武器、仓储、搬运、装运和航程组成的一项行动，才会想到沿成排枪箱、吊具与装货船建立规模。并非因为港口比书房壮观，而是这些内容属于事情本身，并共同让冒险具有重量。选择也可以落到局部：当接触、痕迹或人的细微反应承载了当前意味，近景能比大全景更有力量。画面丰富来自取舍准确，简洁与含蓄照常成立。

人物成为主位时，用本段具体的行动、处境或反应承担表达。表现压力，就选择压力的来源及其对行动或生活的影响；表现情绪，就选择值得体会的神态、姿态与当时情境。会商、通信、读信或一个表情本身值得观看时，按实际需要采用人物近景。

**把第一反应推敲成构思。** 如果第一反应是“有人读到消息”“几张纸标出几方”，继续追问：消息改变了什么，几方背后是什么力量，观众为何在乎？从这些具体内容换一个观察角度或表现方式，比较它是否让原文中的意味更鲜明。比如“WAIT／NOW”能标记不同意见，却没有展开武器被收住与被期待投入行动的不同意愿；门内军火、人的收存动作和厚重门扇可以让其中一端变得可感。另一个题目可能恰恰需要信件或脸部细节，不能把此例变成禁用物件表。只在构思薄弱或真实两难处比较，不要求每图固定交几案、穷举手法或记录淘汰稿。

抽象内容可以从实际环节、具体后果或形象类比切入。先想清要让人理解或感到哪一层意思，再选择与它有贴切联系的形象；意象中的位置、状态与作用需要支持这层联系。并置、替换、尺度、空缺、容纳和受力都可取用，也可将跨时地的联系组织为一幅统一的非写实意象。枪械投出人潮的影子可以表现筹划者对动员的期待，却不能仅凭“影子不是真人”就声称观众已看懂准备被夸大。意象有魅力、关系能解释，并不意味着全部语义都已被它承担；也不要为每个概念寻找对应象征物。文字承担命名、引述和辨认，画面与当前旁白共同形成意味。

以下只示范含义怎样成为可见安排，场面与画法依当前输入选择：

| 口播的主要意味 | 一种可成立的构思及其依据 |
|---|---|
| 已有货源，仍不等于能安全交货 | 将罐区存油与泊位、装油臂、油轮及外海航道组织在完整港区，让货源、装运环节和未完航程可读。旁白交代风险，场面不预断安全交付，也不补造海难。 |
| 卖方希望高价，买方希望低价 | 可用匿名交易意象：油桶已交到买方一侧，同一笔货款正从买方递向卖方，交货与付款在一个场面中对应。买方的支出正是卖方的收入，旁白交代身份和价格意愿；不补造具名人物会面或谈判破裂。 |
| 新负担叠在原有压力上 | 可画已被货物压弯的承托面，新重物仍由人托着，却已压上同一支点。旧承重与新增重量共同入画，形变与受力让叠加可感，旁白赋予成本含义；不借此声称真实事故。 |
| 市场像吃饱的胃，难以立刻吸收第二轮债券 | 可用编辑插画意象：已有债券占满胃形容器，新一摞停在狭窄入口外。已占据的容量与尚待吸收的新供给共同可见，旁白说明金融含义。保持象征表达，并保留发行结果的未定性。 |
| 城市庆祝胜利，家庭仍在承担牺牲 | 正文支持这种反差时，可从家中望向窗外庆祝街道：室内留着缺席者的位置和日常负担，窗外是明亮人流。物件、空位与两个空间的反差承担意味；人物通过具体生活状态参与表达。 |

**成场：把这个想法做成值得看的完整画面。** 选择最能承载意味的时刻和状态，让动作、环境、规模、距离或反差取得鲜明作用。需要紧张感时，先找到事情中的牵制；需要震撼时，先找到值得感受的力量、规模或反差。再按[构图方法](picture-construction-method.md#3-在同一场面中联合安排整体局部和路线)组织视点、主次、光影、层次与路线。**生图交付完整场景和必要联系，运镜决定最终呈现的部分、尺度与顺序。** 人物和细节可以取得主位，具体景别由观看需要决定。

表现动作时，先理解过程，再选发力、停顿、反应、余波或有意味的静默。静图只保留一个状态，让接触处、承重点、用力方向与身体姿态相互支持，保留必要的对方回应和场地联系；细节按实际景别取舍，不逐项补齐手脚。比如箱沿已搭上台边、另一端仍在手中，承重可由双方关系读到，具体推导见[关键帧教材](../examples/keyframe-story.md#把连续动作转成一张静图)。通信、会商本身就是所讲事件时，文书和人物行动可以成为主要内容；书信也可以承载情绪或隐喻。

**放回连续观看中取舍。** 章内各图一起构思：前图让观众进入什么，后图怎样接着展开、改变或重新理解，最后留下什么。运枪案例从可装运的物质力量走到期待、保留使用的意愿、改航及失去掌握，尺度、环境与气氛随内容变化；它不是每句换一个地点。反复看同一对象也可让意义积累，但换旁白或换取景并不会自动产生新的视觉含义。若连续设计只是人看纸、镜头看脸，回到这段仍未展开的内容；不靠轮换景别或统一放大环境求丰富。

选定后在原`purpose`里写清具体场面、状态与支撑意味的可见依据，`sceneDescription`交付同一完整画面。配着当前旁白推演观看，指出本图的具体安排表达了什么；与前后图连看，确认本图在行动、关系或感受上的作用。有意重复与情绪停留按其实际收益保留。表达依据不足时回到构思，意味成立而主次不足时调整构图。保留适当的多义与含蓄，准确呈现条件、可能性和作用方向。推敲结果写回原字段。

遇到“意思能复述，构思却仍泛泛”的情况，读[运枪片段改编](../examples/narration-to-scene/README.md)，对照原图、完整源图与实际取景，重点理解选场怎样推出来、哪些表达没有兑现。该教材只示范取舍，不提供本集事实、画风、通用意象或可复制镜头。

不因画面形式自行换模板。只有当前任务确实超出静图、取景和现有呈现能力时，才按原观看骨架交Director处理。

## 事实、环境与前后语境

具体史事、身份、关键结果和因果依正式输入；合理重建的动作神态、场景细节以及明确的象征关系由作者创作。不能据此声称具名人物确有某种隐秘动机、说过新台词或实施了新事件。比喻含义写在`purpose`，可见的意象写入`sceneDescription`，不另贴分类标签或加解释字幕。继承已投递的具体限制，与合理表达直接冲突时返回其真实责任方修正。

前序材料的范围、完整读取与复用由[模板根](../AUTHOR.md#输入与范围)规定。用同段前序画面比较当前选择是在推进、呼应还是重复；相关场面可以不相邻。只有职责时不猜未知构图，是否沿用前图安排由当前职责与连续性决定。精确上一镜参考按[相机接镜方法](../camera/execution-reference.md#5-前后镜头观感与严格接镜)使用。

参考不提供当前事实或别页写权，比较过程不交给生图。重复主体可有新表达作用；泛泛配图从当前文字重新选场，不以换道具、场地或机位求异。选择与比较仍在联合设计中完成，不另交参考清单。

## 两个决定性瞬间

一个Beat的A/B共同呈现同一次具体变化或关系。每张图抓住一个有观看价值的关键瞬间，两张可以是动作的前后阶段、行动与直接反应、关系的两端，或对同一主体持续观察并逐渐揭示状态、关系或情绪；这些是例子，不是固定角色菜单。每张的职责说明当前瞬间及其在这次推进中的作用，不要求各自新增知识点、改变文字或更换主体，也不要求每张独立完成整个Beat。

成立必须同时满足：

- **同一任务**：共同兑现当前`viewerOutcome / mustShow`，不把两项独立观看任务塞进一对A/B。
- **真实视觉推进**：从A到B能具体指出动作、处境、反应、关系或注意焦点怎样推进；可以持续观察同一主体或同一空间，只要观看目的在揭示、观察或情绪感受上成立。删除一张会省掉这一关键阶段、反应或揭示过程；口播仍能说清同一结论，不构成否决理由。仅换姿势、机位、房间、道具或措辞，没有上述推进，仍是同义重复；只写“增加节奏”也不成立。
- **意义与画面成立**：每张分别按[交付说明](picture-delivery-reference.md)形成完整画面；A/B可表现不同时刻、处境两端、表象与代价或同一意象的变化。象征不冒充来源未支持的历史因果，关键历史断言仍由当前cue或登记来源支持。

A/B成立还须各自窗口可读，不把焦点字段或文字差异当作额外条件。画面数与时窗选择按[观看骨架](viewing-skeleton-method.md#2-决定画面数与职责)落实。

## 阅读与运动

**单张全画幅至少留3秒清晰观看时间，单A及A/B中的每张都适用。** 这是本项目的制作下限，复杂关系仍须留足实际读懂的时间。按原阅读预算和转场显露判断，混叠、闪黑及跨Beat预进入／退出余量不能拿来凑足3秒；清晰观看期间仍持续运镜。

不足时先调整画面组织与合法Cue切点：能由一张完整画面承担的内容合为单A；确需分别呈现的变化保留其先后。若当前Beat连单A也容不下，或必要的A/B无法各自满足下限，把具体Cue和观看任务交回Director合并相邻Beat或调整边界，保留全部口播与信息。不能以短句有独立意思为由做一张一闪而过的图，也不能靠删掉必要表达凑时长。

对每张图，包括A/B中的A和B，按本图真实阅读窗口判断：把所画内容还原为完整静图，再配着本图绑定的旁白从头到尾推演观看。持续看的是什么，后半段是发现原图中的关系、随旁白重新理解眼前处境，还是停留在值得体会的情绪中？静图里的坠落、转身、递交不会真的继续发生，运镜只能改变取景，不能把动词当成持续动作的收益。入口与落点的依据开头就全可见时，按持续观察或情绪停留设计，不再声称是先后揭示；不要求每秒出现新内容。

若这段注视仍无具体支撑，先调整场面表达或在合法Cue中选择更相称的窗口；“仍在同一场景”或“镜头继续慢推”本身不是理由。单A也可考虑成立的A/B；A/B中的长图同样不能靠两图已成立或运镜可执行收口。若暴露原页面吞并了独立推进，返回Director修正。`motionBudgets`提供真实窗口与行程测量，本方法不按时长自动指定图数，但每张图都须满足上述清晰观看下限。

本文的“停留”指注意力继续体会同一处境，镜头仍须持续运动。阅读预算与完整运动窗口不同，按[观看骨架的Cue预算](viewing-skeleton-method.md#3-选择cue边界)选择，联合设计再按[相机时窗合同](../camera/design-method.md#4-时窗合同)落实；图数或运动持续时间本身不能证明观看成立。

按当前`readableDurationMs`取舍需要辨认的对象与关系，留出听旁白和体会画面的时间。多个物件都认得出，不代表来得及理解多层比喻；先调整表达与主次，不设固定对象数量。需要同时理解的关系可以从起始完整呈现，只有声称后续揭示时才安排发现次序。

选定结果按[观看骨架方法](viewing-skeleton-method.md#2-决定画面数与职责)写入每张请求；在同一结果内完成构图和相机，改变观看任务时按模板根同步修正受影响内容。
