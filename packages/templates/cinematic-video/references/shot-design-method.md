# 镜头、首帧与视频提示联合设计

本方法负责V2，先读取同一候选中已落盘的V1结果。由段落含义设计场面，再共同推导首帧和后续活动，直接写进已有镜头与提示字段。范围、叙事目标或来源必须改变时回V1，不靠提示词补造选段资格。

## 接收已核实的审核拒绝整改

P4视频生产按正式返回入口交来审核拒绝时，读取当前工作单的具体失败、实际输入及用户已选整改范围，不凭报错文案猜原因。同类续接拒绝已选择换首图处理的，在原叙事目标、来源、Cue窗口及Visual内，联合重设计受影响段的firstFramePrompt、镜头起末态和各分次完整videoPrompt；保留必要事件与先后关系，不只把原提示换几个词，也不删掉事件来冒充完成。

根据本段实际观看任务选择新的场面、机位与可辨关系，使首图能进入首组活动，首组实际剪定参考能承接后组。高机位、全景或某种画法只是具体场面的选择，不是审核通用解法。范围、目标和来源不变时，沿Module在当前候选建立或复用同一范围的V1结果，再修V2并核对整条受影响接续；不重新取舍选段，不增加后组首图。未受影响的独立段保留原设计以复用合格素材，不因同次返工附带润色。生产交回P4视频生产原入口，设计修改不证明平台必然通过，实际触发项未披露时保留该事实。

## 先确定观众要看见什么

读`storyChange / whyVideo`、所选Beat的完整正文和全部Cue、相关understanding与来源，再核对P3观看任务及邻接设计。理解本段要表达什么、从哪里进入、主要看什么、在哪里结束，不只依据标题、修辞或旧图构想。

**拍清这个Beat或合段的主要活动或变化；原内容需要交代结果时，再把结果拍出来。** 例如材料只说大型工场持续作业，画面就让规模和作业可见，结束时仍在作业；不增加竣工、启用或事故。若材料与观看任务确实要求撞开封锁，则接触、受力和通路打开都要发生，不能只拍前后状态。

年代、身份、制度、动机和抽象结论由旁白承担，不逐字翻成行为。“拒绝条件”不自动授权摇头，“请求保护”不自动授权递信或会面。区分意图、尝试、担忧和已发生；不把修辞拍成事故，不补造人物心理、命令、反应或损失。普通站位和无标记衣着可作不主张具体史实的辨认设计，代表性重现不能伪称某个瞬间有史料证明。

## 从观看任务共同推导首帧和活动

先确定必要主体、位置关系、活动空间及可见过程，再依据本段观看重点，选择既能把活动拍清、又能使其分量与意味可感的构图、景别和机位。例如共同守路的一方撤走：两方起初都要可辨，撤走时仍看得见留守者，才看得出距离拉开和缺口形成。只跟着一队人走会丢失关系，首帧先画缺口则提前交付结果。撤离动机继续由旁白承担。

首帧是这套场面的第一个可画瞬间：具备紧接着的活动所需条件，不提前画完尚未发生的结果。可从已经进行中的活动开始，无须回到历史事件最早时刻或让所有人站定。顺着这个起点设计后续；走不通就调整场面或首帧，不用抽象结论跳过缺失过程。P3正文设计提供叙事依据，不强制沿用旧图构图。

大场面用整体空间、纵深、主体距离和运动方向让规模可读，同时明确观看重点。关键主体或主要活动持续可辨，远处群体可呈现一致趋势，不同时安排许多互不相关的精细动作。全景、近景或长镜头按表达需要选择，没有固定顺序；不能把规模缩成一个人的小动作，也不能只靠烟尘、晃动和切走代替必要作用过程。

## 落实镜头和生成分次

`shots`从S01顺序编号，`durationMs`总和精确覆盖真实Cue窗口。Beat是正文单位，镜头是表达单位，分次是制作单位：三者不一一对应。单Beat可以多镜、多次生成，不因此扩大选段；第一镜与首帧起态一致。

| 字段 | 内容 |
|---|---|
| `purpose` | 本镜的观看任务；必要事件对应的实际Cue及可调整的普通切点 |
| `framing` | 景别、机位、主体位置朝向、距离与观看重点 |
| `startState` | 能画成一个瞬间的起始状态，包括必要人物、道具和空间关系 |
| `motion` | 谁在怎样活动或发生变化；有互动时写清对象、方向和可见响应，相机如何服务观看 |
| `endState` | 镜头结束时的可见状态及下一镜或下一次的交接条件；可以仍在持续活动 |

每镜聚焦主要观看任务，以合适的主运镜或固定镜头服务它。切镜应增加必要信息或视角，不重复同一内容凑镜数；关键过程在原Cue窗口内，按动作展开和观众辨认所需安排快慢与停留，既有看清作用的时间，也让值得体会的状态得到适当观察。用画面位置及少量稳定可见特征辨认人物，不能仅写历史人名或含糊代词，也不新增旗号、徽章、武器或特定人数凑细节。

同场保持轴线、视线、运动方向、位置与道具关系。有依据的时空变化用明确剪切，在新镜起态建立场所、主体和关系，不让场景变形或把数日事件伪装成实时连续。新人物、新场所或未出现在紧邻参考片中的旧角色，要在对应提示重述已有的必要辨认特征，不能依赖未上传的更早片段，不另生角色图。

有序`parts[].shotIds`按顺序覆盖全部镜头一次，每次包含一个或多个连续完整镜头，正文至少4秒；加活动余量后的生成时长不超过15秒。每段仅第一组在正文前保留0.9秒；最后一组在正文后保留0.9秒，后接叙事画面时还包含两段Cue之间的实际停顿，持续末镜已有活动接到下一段。一组承担整段时两端都留，中间组不重复加余量。正文shots.durationMs不含余量；由同一timing程序量化帧数，按包含余量的实际容量安排分次，不压缩正文动作来腾空间。次数服从剧情阶段、复杂度和可辨交接，不强求时长除以15的最少次数，也无四次上限。多镜能清楚共同表达就同次生成；硬塞会丢过程、混淆主体时，在自然边界分开。换景不自动增加任务或首图。

分界选在可辨的交接状态或明确剪切处。持续活动可以在方向、主体关系清楚时接续，不要求先完成事件；跨次的关键动作须写清已经发生及尚待发生的阶段，后次不能重演。24秒可为12+12，也可因三个必要进展分8+8+8；15.2秒不能拆15+0.2，且首末组须容纳各自余量；短于4秒的镜头应与相邻镜头同次生成。不要在难以辨认的碰撞、快速遮挡或转身峰值机械截断。安排理由体现在purpose与起末态，不另写分段报告；仍无法兑现观看任务就回V1，不延长旁白。

## 写唯一首帧和每次完整提示

`firstFramePrompt`写第一镜所需的16:9画面：时代地点、机位景别、主体位置朝向、当前姿态、物件归属、必要环境与光线。展开多少空间取决于本镜：桌前交接可取中近景，必须辨认双方和通路时就容纳它们，不统一要求整间房或完整场地。它是视频起点，不是静态后期运镜底图，不套用相机坐标、缩放限制和路线余量。

首图是段首活动余量开始的瞬间。向后0.9秒自然进入正文首镜起态，保持同一场面和运动，不提前演完正文关键动作，也不站定等旁白。首图只画一个瞬间，不写多个时刻或分镜拼贴。与第一条动态提示对照：要推送的文书仍在递交者一侧，要打开的门仍关闭，持续前进者方向一致。读工作单`visual.stylePrompt`，以节目既定绘画媒介表现，不能变成真人摄影。Compile只编译AR001，四槽包装与切图由原生图链承担，作者不设计四宫格或后续首图。

`parts[].videoPrompt`必须是模型能直接执行的完整场面表达。模型只取得本次图片或视频及本次提示，不知道V1、Beat、Cue、来源编号和其它次的文本。不要粘贴字段清单或写“按上述镜头创作”。

用自然语言写清本次起态、主要活动或变化、必要运镜或剪切以及结束状态。涉及互动就说清谁作用于什么、怎样响应；涉及结果就保留使它发生的过程；持续活动则说明怎样继续、观众怎样看清，不强造新事件。水流、尘土和衣料等细节用于读清速度、重量或规模，不堆形容词和无关动作。写清同时与先后，代词有明确主体，不逐秒指挥无关手脚动作。

简单活动可写一段，有必要的多镜才按先后或粗略时间段组织。关键事件须对应不同口播阶段时，在实际提示里保留少量时间提示，不能只写在内部purpose；不逐条抄Cue，不规定字数、镜数或固定节拍。第一组的来源时间含开头0.9秒余量，正文对应事件的提示时点因此加0.9秒，后组不加；末组正文结束后按程序给出的完整尾部时窗自然继续，包含后接叙事画面前的停顿及0.9秒活动余量。提示秒数是目标节奏，不是模型精确卡点的保证。

首图已建立的外观、构图和光线不整套重复；辨认主体、保持画风或建立新场面所需的内容仍须写明。根据当前Visual提炼必要媒介描述，把本次会改变事件含义的具体禁造要求写进提示，不复制全套内部规范。程序只补真实参考用途、已计算的正文与余量时间窗、画风延续及统一无字无台词要求，不代写剧情。

后次从前次交接状态写**接下来发生的内容**，不能重复播放前片、重新开始动作或提前演完后组。默认直接引用前次原生成节点，普通分界及整数秒多出的尾部安排为可持续活动，最终精确裁切不应删掉关键动作。换场在本次parts的connection.type写cut，继续同场活动可省略或写continue；程序分别补充换场参考或动作延续要求。只有确实必须从前次剪后结尾继续时，才在同一connection.trimReason说明具体原因，程序提前剪定并上传该前组；这不是默认步骤。首组不填写connection。实际前片未达到交接条件时归原来源问题，不临场改写后组来迁就。

时长、分辨率由程序参数负责。内部编号、精确Cue、来源和后期叠字指令不送供应商；成员Beat旧相机、A/B切点及解说框也不带入。视频不生成字幕、标题、水印、台词、黑场或烧入淡入淡出，整数秒余量自然承接，不重播剧情。按当前难点读[示例](../examples/selection.json)：单Beat短剧情、持续活动的大场面、跨Beat同一进展、群体关系推导和复杂作用接续；不套用事件、画风、镜数或时长。

## 对齐旁白与前后交接

核对前邻Beat或片头的设计末态，以及后邻Beat的设计起态；邻接视频则看其首末镜。位于整集末尾时，末镜的可辨末态交给P4既有整集收尾，不另设片尾设计。

同场保持方向与位置，换场用具体构图、明暗或视线关系接入、接出，落实到首镜startState、末镜endState及提示。不为匹配邻镜改掉必要起态、提前交付结果或补造情节，供应商提示不带邻镜编号或重播邻镜。

P4在转场中播放真实的段首、段尾活动余量，正文有效动作保持原Cue时间。余量和正文须为同镜连续运动，不是独立片头片尾，不烧入转场；主要动作留在正文窗口，不能为了显露提前完成。首尾构图须可辨、方向与速度感能接住邻镜，关键动作不能只占首尾一帧；活动可以继续，但不能在无法辨认的状态截断。后接讲解留清楚末态作背景。成员Beat原解说框不参与，较早未覆盖全画幅的框按既定生命周期收束。

沿实际字幕核对设计是否兑现`storyChange / whyVideo`，再只依据每次模型收到的参考与提示，检查主要活动、必要过程及交接能否成立。口播说文书移交而提示只有“两人坐着、镜头推近”就不成立；口播说持续作业则无需补竣工结果。首帧、各次起末态、动作先后与关键旁白时点须一致。发现具体矛盾只修相关内容并核对受影响衔接，通过即回根入口，不新增复审轮次。

正常P4视频生产由程序按既定窗口连续取用素材。看片或编辑须由用户另行明确要求；获准编辑时，只在固定分次窗口内按真实素材调整普通切点，仍保留镜头顺序、主要活动、必要过程及关键Cue；不以变速、循环、冻结或挪字幕填长。来源不足归上游，技术通过不证明实际生成质量。
