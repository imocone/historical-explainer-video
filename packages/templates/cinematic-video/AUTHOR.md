# 剧情视频模板

从当前工作单的正文、Cue、理解、来源、P3已接纳设计和节目Visual创作视频。把视频留给整集最重要、最宏大、最关键的段落，先找本集重点，再解决视频表达；最多3段，没有合适段落就不做。具体判断由V1方法拥有，不能从容易生成的动作中凑名额。选中范围由视频整段接管，原旁白和字幕时间不变，成员Beat的已成图片保留，播放时不再执行原相机和解说框。

当前Module与阶段决定入口：

- P4 `author-video`：V1选段落盘 → V2读取并联合设计 → 生成单首图 → 回Module提交同一候选。
- P4 `produce-video-assets`：按已接纳设计生成，由程序按既定时长剪接交付；读取[输入与直接交付方法](references/production-review-method.md)，生成后不看片，画面由用户检查；不重做V1/V2。
- P4：登记渲染入口在原正文时窗播放并接前后转场，不取得创作或生产权。

P4局部返工时，Module已将本单`currentVideoPlan.content`保存进唯一候选：先读返工要求、当前正文及既有完整设计，确认实际受影响的选段或接镜。范围、目标与来源仍成立时保留V1，进入V2按原方法只核对和修正受影响关系；邻接讲解的版面或图示变化不自动要求重写视频场面。现有方案仍准确时原样提交，不能为了表示复核而改写提示词。确实需要改变选段、目标、来源或本单明确要求重新划段时回V1，其它有效设计保留。当前方案只是返工输入，不能替代本次判断和正式接纳。

## V1 选段

准入：工作单已给出完整正文、Cue及P3已接纳正文设计。完整读取[选段判定方法](references/selection-method.md)，先识别整集最重要、最宏大、最关键的段落，再确定其中需要用视频集中表现的现场、合法范围及可行表达。没有这样的段落就空选，不降低标准找替补。

将结果写入当前`candidatePath`的唯一`candidate.result`：`episodeId / templateId / selectionReason`，以及每段的`id / beatIds / storyChange / whyVideo / sourceRefs / mustNotInvent`。此时不填镜头或提示词。选择已成立且依据已落实到这些字段才进入V2，不能留待设计或生成试错。空选在`selectionReason`简要说明本集为何没有需要且适合这样表现的重点段落，写`spans: [] / incomingTransitions: {}`后直接返回Module提交；不进入V2，不生成首图，不另造候选证明用过名额。

## V2 联合设计

准入：V1结果已经落盘。先实际读取该结果，再完整读取[镜头与提示词联合设计方法](references/shot-design-method.md)，从段落含义设计场面，并共同推导首帧与后续活动。P3提供观看任务和邻接上下文，被接管Beat的旧图构想不限定视频构图。

继承相关正文已定时代外观及其来源，把适用于当前活动的衣冠、环境和器物特征保留在首帧与分次动态提示中；构图和动作可以重新设计，不能退回泛化古装或另换不相容的身份、时期。按原V2判断设计，不新增视频生成后的观看步骤。

V2同时读取[共享转场方法](../../modules/render-video/references/narrative-transitions.md)，依据替换后实际播放顺序、前后正式口播、导演安排及保留的P3设计，在本次联合设计和复核中完成受影响接缝的选择；具体理由写入原候选，不另交全片规划。纯转场变化不重生素材。

按实际片段顺序在同一候选的`incomingTransitions`中，以进入片段ID为键交付每个受影响叙事媒体边界的效果、时长与理由；包括全画幅进入视频、视频进入下一全画幅，后者取代该片段原入场设计但不写回P3。连续视频之间只记后一段一次，被覆盖成员内部、片头及讲解交界不登记，讲解仍走专用进出，未变接缝保留P3设计。0段交空对象。按共享方法的活动余量前提与首末镜共同设计；所需素材不足时在V2修正镜头或效果，确需改变V1结果才按下文返回。

在同一候选补齐`shots`、唯一`firstFramePrompt`和`parts[].shotIds / videoPrompt`。联合安排首镜进入与末镜接出的真实活动余量；正文镜头时长仍等于原Cue窗口，生成分次容量须包含段首、段尾余量。场面、首帧、镜头、分次与完整动态提示表达同一观看任务，并在实际Cue窗口内成立，才算完成。范围、叙事目标或来源需改变时回V1，只删除或重做实际受影响的后续设计；其它矛盾在V2内修正，不另建候选、分析稿或复审步骤。

联合设计成立后按[作者图片交付](../../authored-images.md)生成每段唯一首图，写入原 `span.asset`；接续段不另生首图。已有仍有效首图保留，只有实际图像内容改变才修图。完成后回`author-video`提交。Engine以Schema与Validator接纳为正式video-plan；同阶段produce-video-assets直接读取实际首图、镜头和分次提示。接纳后设计错误按当前工作单正式返回，生成质量问题归原生产对象；结构与时窗通过不等于实际画面或观众效果已验证。
