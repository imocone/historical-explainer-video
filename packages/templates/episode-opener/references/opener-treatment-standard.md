# 三画面片头业务标准

本文件是`episode-opener`三画面成果的唯一业务标准，由P4片头主模型作者读取。

## 继承正式内容

- `flashbackLine`必须逐字等于当前P1正式`openerNarration`；P4直接消费已接纳内容，不重复核对正文事实或来源对应。
- 不得新增正文没有承担的事实、关系、因果、比较、程度、第二问题或完整答案。
- `bodyRefs`记录本图实际消费的正文Beat，供依赖投影使用；`sourceRefs`沿用当前输入中的引用身份，不要求与正文图片请求逐项对应，不据此再次取证。来源资产继续遵守使用权限。
- 可以使用代表性的历史处境与普通布景；画面不新增历史结论、具名参与者、确切数量、人物关系或战果，必要禁造边界写入`mustNotInvent`。

## 三个可见观察面

- 固定使用`O01 / O02 / O03`三张闪回图，分别承担三个先后可见、互不重复且不可互换的观察面；三者共同投影同一句片头，不增加第四画面。
- `screenLines`只能从`flashbackLine`连续原样摘取，保留小数点、符号和词间空白，最多两行、每行最多10个可见字符，必须独立表达完整可见语义；`highlight`只能完整命中其中一行一次，否则为`null`。
- 每个`visualBrief`必须明确`subject / actionOrState / environment / visibleResult / composition`，形成可直接生产的完整画面；不把普通布景或调度写成新的历史事实。
- 原图是完整、均匀曝光的16:9历史画面；人物面部、主体中心和关键证据位于画面高度35%—65%的中央带，画面内不预制文字、黑块、暗角、渐变遮罩、横带或动态装饰。

## 唯一候选边界

- 作者只需交付`templateId / flashbackShots`及Schema规定的内部字段，程序从当前P1原句补齐`flashbackLine`后按完整合同接纳，不写接纳后才产生的`narration`证据或运行信息。
- `flashbackLine`是全片头唯一口播；三张图依次完成同一个片头并直接进入正文，不增加标题页、停留画面、第二段口播或平行片头结构。
- 完成结果包含三张正式闪回图所需的全部创作判断；Schema、字符数量和字段数量由现有Validator验收。
