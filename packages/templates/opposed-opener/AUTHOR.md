# P4逐段错层对冲片头

只创作当前 `opposed-opener` 片头，完整继承P1正式口播、正文、Understanding和整集进入方向。原句由程序补入 `flashbackLine`，不得改字、添加事实或另写钩子。素材来源与权利沿当前工作单及作者图片入口执行。

按原口播的逗号和句末标点分成连续的口播段：逗号前后各是一段，各做一次对冲、一段一张图。例如“前半句，后半句？”是两段、两张图；两段两次，三段三次。保留原文原顺序，不为画面数量补句、加标点或把没有断句标点的文字硬拆；数字中的千分位逗号不是断句。每段在 `spokenText` 交付对应原文，依次连起来必须覆盖整条原文的有声文字，不能增删、重排或重复。为每段交付一个 `flashbackShots` 条目，编号按O01、O02顺序；`screenLines`按阅读与画幅需要分行并表达本段完整原文，`highlight`可标记一次有意义的原字，不另造口号。

每段设计一张完整16:9场景，明确主体、动作、环境、可见结果与构图，并交付真实 `bodyRefs / sourceRefs / mustNotInvent`。图片在上下错层裁切与轻微透视运镜时仍须让人物脸、关键动作和证据可辨；文字、暗带、分割线、对冲和特效由模板渲染，不预画在母图。按作者图片入口生成每段唯一实图并写入对应 `asset`；保留仍有效的图片。

程序使用同一正式配音取得各段真实卡点；每段上下画面沿左右相反方向冲入，停稳后保持错落与持续运镜，最后一段多留蓄力再沿原方向左右弹开，直接露出正文首镜。配乐沿用原片头，对冲用短促刷声、最后弹开用齿轮撞击。不要加片头尾卡、额外画面或人为重复；实际卡点缺失返回片头音频接纳，画面与文字问题留在本模板修正。

正反例仅解释逐句与图片合同，不提供当前节目的事实或人物。完成唯一候选后交回author-bookend H2。
