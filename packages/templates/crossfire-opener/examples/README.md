# 交叉对冲定稿

成品视频不随仓库分发；完整原片仅在本机local-media/private-assets/对应路径保留。公开教学保留golden.json、negative.json及模板的渲染源码。

本机选定的完整样片：三画面燃边、字组、交叉对冲、整幅展开，并包含5.8秒正文，供判断真实衔接。配乐已按大刘选择换为现用片头《沈黙》，画面、旁白与动作音效保持。此文件只作教学，不作为生产媒体或每集口播。

golden.json演示本模板字段；其中事实、标签、画面与来源身份仅为非生产示例。每期必须按当前正式P1和正文重新创作，保留固定动作与声音。

negative.json列出画面、来源、前景和正文衔接的易混错误。
