# 历史解说AGY成稿的一次事实核对

AGY拥有稿件的全部文字。普通／full由所选作者补齐封面与平台文案后，进入本卡。本卡只对已写入唯一候选的成稿执行一次；返稿仅按下文确认原错误，不重做整套核对。事实错误只回这一个原作者会话一次；定点路线仍核对唯一候选。

## 核对范围

按共享[发布内容作者方法](publication-author.md#整套文字一次核对)区分完整创作和定点核对范围；以下事实尺度只作用于该范围。

先按整段实际传达的意思判断：即使疑点属实，观众会不会因此误解主要人物、重要经过、关键因果或结局？只有会造成基本误解、且有具体疑点的断言才回查。用本单已取得的正文、Query引用及定位核实。NLM取材需要回查具体断言而不知道出处时，使用[取材方法](explainer-evidence-and-query.md)的原文定位入口；已知出处直接阅读。参考视频的转述用于定位，涉及关键引语、诏令或文书时核对原文及必要上下文。

普通／full中，现有依据不足以判断上述具体重大疑点时，定点补读可靠正文。实际使用的正文按[直接读取正文](explainer-evidence-and-query.md#直接读取正文)追加到同一reference-materials.json，保留真实文献标题、来源、正文及必要定位。资料库中已核实、可直接引述的原文也存入同一documents，source沿用原source_id，text保留实际cited_text，title使用已确认的文献名；身份不明的转引只作线索。完成核对后一次列清确认的硬伤。

定点返工的正文事实只消费工作单固定材料，核对范围保持本次授权。公开文献的还原、核读与书目信息补充按[来源与素材交接](publication-author.md#原文保存与固定正文)处理；发现影响锁定正文的反证报告对应上游冲突。固定依据不能裁定某个会改变基本认识的疑点时，如实说明具体疑点和证据缺口，保持作者原文。

有可靠依据确认讲错，或能具体说明编造了关键事件、原话、决定性动机或因果，且会造成基本误解，才列入纠错。每项交清原句会让人误解什么、哪个证据确认了错误。现有材料未记载、只支持较粗层次、讲法还能更严谨或有次要例外，均不足以立项。

按实际语义放行合理概括、程度强化与符合处境的叙事细节。“眼前没有船”可能只是说这支队伍当时渡不过去，应按局部处境判断。原文若把这种困境扩成整个阵营从来没有水军，再核对后一个断言。即使同一句有需要改正的硬伤，也只登记错处，保留不影响史实的神态或连接动作。结构、详略、节奏、风格、语言和材料取舍由AGY负责。

首次创作的字数、集间范围及其它要求保持不变，但不作为本次审计或修订理由。不统计、评价或要求调整正文长度。格式和锁定原文等机械交付错误按Skill停止，不混入事实错误清单。

## 只返修一次

没有重大硬伤就原样接纳。确有硬伤时只回同一原作者会话一次，登记实际造成误解的最小片段、正确事实和最短依据。连带位置须确实传达同一个错误或是受影响的章节定位；相似词句按各自上下文判断。以选定原稿为底，能改一个词或数字就只改它，必要时最多改本句。把关键动作或因果张冠李戴时，交清正确归属，让有据的经过继续承担原段的讲述作用。段内其它句、标点和换行逐字保留。

按[事实清单交接](author-handoff.md#选中稿的事实处理)保存原文和定位编号。`places[].path` 从候选的 `result` 内部起算，使用 `/narration`、`/openerNarration` 或 `/publication/platforms/youtube/description` 这样的斜杠路径。续接原作者会话时，只把唯一候选与事实清单的绝对路径替换进固定提示：

```text
只读<本次唯一候选或明确恢复的所选原稿绝对路径>中的result和<事实清单绝对路径>。以候选原文为唯一底稿，只改清单点名的硬伤。每处只改出错的词、数字或分句，必要时最多改本句。其余原文连同标点、段落和换行逐字保留。

只返回清单编号对应的替换文字。保留原句中仍然成立的动作、因果和讲法，禁止改写相邻句、删减段落或把原有讲述压成摘要。相邻原句已经讲清该事实时，直接删去错处。改完仍须能直接朗读，正文不加圆括号、编辑注释或核对口吻。章节定位只在原锚点实际被改动时同步更新。

不得修改文件。只返回精确修改JSON：
{"edits":[{"id":1,"after":"纠正后的文字"}]}
id取清单places里的编号。after只含该编号片段的替换文字；删除片段用空字符串，删除数组里的整个文字项用null。共用文案只交它的一个编号。不要返回整篇。
```

所有纠错路线共用此格式，片段定位和恢复规则见[作者交接方法](author-handoff.md#选中稿的事实处理)。

AGY返稿后用现有交接入口，逐条比对`before`与`after`，确认每一处都对应清单所点原句的最小必要替换，再按[原错误确认](publication-author.md#纠错后的原错误确认)核对同一硬伤及受影响锚点，成立后执行原accept。超出原句或以整段摘要代替纠错的返稿保留现场并报告。无第二轮整套核对。机械失败或未知仍按Skill保留候选并停止或恢复原调用。
