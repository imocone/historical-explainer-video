# 从参考节目取得本集依据

本文件只供有`inputs.episodeBrief.referenceProgram`时的N01取材及同源依据回查。它不另设创作、选稿、篇幅或纠错流程；完成取材后返回包根N02，共用`author-task-editing.md`及N03—N05。

## 当前材料与恢复

普通／full先运行下列程序，从当前工作单直接保存`{referenceProgram, referenceVideoIds, videos}`到本单`scratchPath/reference-materials.json`，不经模型转抄。已有相同快照直接复用，不覆盖不同材料：

```bash
node packages/modules/author-narration/scripts/author-handoff.mjs prepare-reference <workOrderPath>
```

随后读取当前P0六项合同和该原始快照，按本集材料定位阅读相关完整语义段及必要上下文。材料定位明确列出公开补充正文时，同样打开所列URL，读实际相关页段及必要上下文，核对它支撑的行动与解释边界；链接或P0概述本身不算读过正文。实际采用的公开或本地补充正文，按[`explainer-evidence-and-query.md`](explainer-evidence-and-query.md#直接读取正文)追加到同一快照；视频定位本身不包含文献正文。这些是Codex取材、事实核对及返工恢复的原始依据，不是交给AGY的扩写稿；不把视频全文或读取路径放进作者任务。

快照中的校正`text`用于理解原片内容，原始`segments`只供近似定位；遇到承重人名、年代、数字、引文或因果存疑时，沿快照已有的`transcript.path`查看同一底稿的`uncertain`与`audioReviewed`。未听审不能当作听审核实，原始分段的错字也不能反过来覆盖校正全文；把实际不确定性带入事实笔记和后续表述，不为回查另造材料身份。

`narration`只用工作单固定的`reusedNarrationMaterials.referenceMaterials / authorTask`，保持原材料身份，不重新选材；核对公开或本地补充正文时读取固定快照，不重新抓取变化后的网页或另找替代来源。当前正文和片头由工作单交付。`opener`只消费锁定正文和片头方法，不要求建立参考材料文件。不默认增加NotebookLM、Query或新书单；普通／full确需当前工作单中的NotebookLM材料时，按共用取材方法执行并保留真实回执。

## 按本集故事取材

围绕P0完整故事与本集问题，从原文读懂主要行动的前后局面、具体条件、各方回应及后果。遇到一个转折，连着读它如何发生、改变了什么、后续行动如何接上；原节目依靠前文、地图或术语才能理解的地方，找出文字里实际提供的关系和上下文，交成作者能读懂的依据。正文没有说明的关系保留未知，不凭想象补画面。P0提供故事任务，原文提供证据，N02据此整理过程，不按原节目段落编待扩写提纲或投递原稿缩写。

原节目明确提供的引文和出处按实际内容理解；主讲者的评价、动机解释和推测保持其解释性质，不能升级成已经独立核实的史实，也不能冒称读过原书。转录不清的地方保留不确定，不凭记忆补人名、年代、对白或因果。材料中的来源ID、时间段和真实quotes留在原文件，供N05对具体断言回查。

关键经过或解释不清时，先回到本单同源材料及P0已定位的公开补充正文读足上下文。N01只解决写作必需的材料缺口，必要时按共用取材方法定点补读可靠正文；未知或非关键细节按实际支持范围交接，不扩成全面史实研究。N02注明实际采用的补充来源标题、URL和页段。选中稿后的关键事实与具体引述统一由N05集中核对，参考视频转述不替代诏令、原话及其上下文；不因已有参考节目省略这项工作。

N01完成后，按共用N02整理同一`author-task.md`。保留P0完整故事内容和策划逻辑，不照搬其固定段落、全文扩写或源节目时长要求；本集范围和用户明确的业务限制照常承接。N05的事实依据使用本次原材料，范围和纠错次数只服从共用`narration-audit.md`。
