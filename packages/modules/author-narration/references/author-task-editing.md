# 给AGY的作者任务

所有解说入口共用本文件。Codex交清任务、材料与事实边界，AGY自主写成节目。委托简短，材料充分。

## 准备作者任务书

普通／`full`在同一`scratchPath/author-task.md`交付任务书，只用`创作任务`、`写作范围`、`依据材料`三个一级标题。正文与片头返工沿用这三栏，追加下节规定的输入。

### 创作任务

交清P0母标题、本集问题、材料支持的初步答案、受众、独有收益和展开意图，用自然语言说明哪些内容必须讲清。用户明确锁定的标题及适用平台原样交接；其余母标题是方向与已有表达的基准，作者可以另选切入和组织方式，不能换掉核心问题、主要主体、范围和收益。P0已有完整故事时，保留其人物事件、处境、关键行动与关系、转折结果及策划逻辑。没有既定故事时交主题与目标，由作者构思。叙事参考供作者选择，不规定正文写法。中心证据与策划确有冲突时交清冲突，不把初步答案写成必须凑出的结论。

交清已选片头的真实播放方式和正文起点，正文开头接住同一观看期待，整篇以具体内容兑现。交接片头实际占时与可听见的信息，按所选正文方法落实最初几秒的具体入口和前30秒的首次兑现；不预写钩子或逐秒结构，文字审读不能代替成片核查。

按包入口的“正文方法的选择”，在本栏说明本次采用通用解说还是时政解说方法，并列出对应方法的实际绝对路径，供AGY创作及Codex选稿直接读取。普通／full三路共用同一选择，`publication-input.md`先读组列同一路径；正文／片头定点提示也明确读取该方法。这里只确定适用的专业方法，不预写结论、逐段推理或讲述顺序。方法只对应当前工作单中P0确定的`explainerType`，不由P1另行分类；不把参考节目的口头姿态或旧作者的段落组织作为要求。

### 写作范围

交清`episodeScope`的时间、主体、停止点和真实排除项，并原样交接用户明确的时长要求。目标时长供作者组织篇幅与取舍内容，硬上限约束整集；`episodeBrief.maxDurationSeconds`存在时包括片头。结合实际片头安排及委托已有的语速或时长信息估计正文可用篇幅，预留自然停顿，文字估计不称真实音频时长。字段缺失不等于用户没有时长要求；未给明确时长时不自行设定，也不沿用参考节目的篇幅。

### 依据材料

来源是N01实际取得的参考节目、公开或本地正文、主Query与必要补充Query，可以组合使用；原文保留在本次材料中。Codex完整理解后整理为作者能独立读懂的研究笔记，保留与本集有关的具体经过和必要上下文，包括行动、命令、条件、各方关系、变化与后果；不压成事件梗概或待扩写的逐段提纲。材料先后与有据因果保持准确，讲述顺序由作者决定。

笔记按事实关系写成清楚的自然段，合并重复事实，长度随内容决定。对本集主要变化，交清行动前的局面、实际做法、各方回应和结果，保留能让作者写开这些经过的信息；“协同不足”“形势逆转”等判断不能代替命令、行动和变化。次要背景只保留理解所需内容。影响理解的术语、制度和技术条件随事实解释；必要时间、数量、比较基线和量级保留，相近数字交清年份、单位、分母或口径。姓名转写不稳时可用有据职分，仍交清行动归属。

时政稿在相关事实旁交清重要参与方实际提出的理由、行动条件、有据的可选做法及后续回应，保留会影响判断的不同解释与不利事实，包括削弱P0初步答案的部分。让作者既能理解争议怎样产生，也能自行检验解释；不只交行动时间线，也不把Codex的分析排成必须照写的论证。事实、当事人说法与Codex推断保持区别，没有的回应或选择不为凑双方而编造。P0任务、有据初答及完整策划逻辑照常交接，不以保留作者空间为由删成零散事实。

对影响本集答案的关键理由，保留原材料说明条件怎样起作用的具体内容：行动有哪些限制，相关办法怎样改变结果，比较用的对象和基线是什么。当事人只提出主张、材料没有继续说明时如实保持这一层，不由Codex补成证明；有这些内容时也不能只压成财政困难、形势变化等标签，让作者凭常识扩写。材料提供可展开的依据，作者决定怎样讲。

按本集资料截止点交清措施处于宣布、获批、安排、落实还是已有结果的哪个状态，保留当时已知与未确认的部分。尚需完成不改成正在完成，允许投入不改成仅够投入，未取得结果不改成已经失败。仍写在现有材料自然段内，不增加清单、字段或预定论证顺序。

材料用平实说明，去掉Codex自行拟出的开场、转折、比喻、金句和煽情评价，避免三位作者把笔记当正文改写。P0已授权的故事和叙事参考照实交接；笔记中的事实先后不指定节目讲述顺序。材料能说明技术或制度怎样影响事情，就交清具体作用，不用“巨大鸿沟”“艰难跨越”等评价代替经过。

真实疑点在相关事实旁简短说明，只影响其所涉及的内容。数字不稳时保留有据的相对关系；原因未核实时交清已知经过与解释边界，区分本次有据的经过和帮助理解的一般背景，不以一般原理补成确定原因，也不把本次材料未查明扩大成历史上没有定论。未采用的细节及辨析留在原材料中，不转成任务书里的反复告诫。中心解释缺依据时沿N01/N02原补缺范围处理，不把取材缺口留给作者。

参考节目、主讲者和观点归属在内部当前来源中真实保留，供Codex事实核对；正文不因此转成介绍参考作者的节目。公开参考文献不列二创参考视频，按[发布输入方法](publication-author.md#youtube来源与素材交接)沿其书目、引语及关键事实反查并核读底层材料，与本集其它重要文献合并去重后交入同一publication-input；没有依据不声称视频原作者实际使用了某本书，未读原文不冒充直接参考。原主讲者独有且没有独立依据的解释不转成定论，仍保留有据经过。实际采用的公开补充正文在相关事实末尾附标题、URL和页段；其余追溯留在当前原材料中。实际引用外部视觉素材时的必要署名仍按发布输入方法处理。

交付前连读任务、范围和材料：未看过原稿的作者能否理解事情，并自行选择入口和讲法？删去预写的表达，不删支撑理解的经过；需要补经过时从当前来源恢复上下文，仍缺依据时沿原补缺边界处理。故事任务、范围和事实均须由本次输入支持，不为连贯补造因果、意图或场景。

## 确定返工范围

Codex从工作单`currentScriptPackage / currentOpenerNarration`核对现行稿件和本次返工范围。任务书交清返工原因、任务、范围和依据，按下列路线决定是否附现行稿件。只从固定来源材料与原`authorTask`继承事实证据和不可写边界，按当前P0形成作者任务；保留仍有效的完整故事，不复制旧稿的段落组织、全文扩写要求或提示词。同源材料中已有但旧任务书或正文遗漏的事实，可以按现行方法重新交清；不改变题目、范围或主要主体。

### 正文返工：narration

`narration`由新的单路作者读取本次任务、固定材料与工作单提供的现行正文、片头，按用户明确的返工范围修订。现行稿是待改对象，不作口吻范文，也不继承旧会话的修改要求。用户只改正文时，片头、文案和封面原样保留。局部修正保留未受影响的正文；整篇重写由作者重新组织讲述，不默认只改开头或冻结主体。

### 片头返工：opener

`opener`在任务书中附当前正文与片头，围绕新片头调整正文开场与必要承接，保留未受影响的正文；有用户原句时只锁定该句，仍交作者完成衔接。

### 共用交付要求

`exactOpenerNarration`须逐字保留；其它片头修订服从本次明确范围。正文与有旁白的片头均须能直接朗读；原有括注的必要信息融入口播，不保留编辑注释。

## 使用固定作者提示

Codex交接已有故事骨架和用户指定的叙事结构，不预写逐段提纲。完整Query、参考原稿、原始材料路径和取材方法留给Codex核对。普通／full作者共读本次任务书、本次所选正文方法、`publication-input.md`及其中登记的发布与所选Cover资源、已选片头方法；不读取未选正文方法、其它未选资源或生图实现。固定提示交清创作顺序、边界与完整交付，具体写法由作者发挥。

调用前从工作单`resolvedAssembly`取得唯一片头模板的`copyRules`，按`resolvedRules`核对路径与摘要。普通／full按[发布输入方法](publication-author.md#解说完整创作的前置输入)完成共同输入，将实际绝对路径填入以下固定提示：

```text

你是这套作品的唯一作者，依据材料写成让观众愿意听到结尾、可直接录音的完整口播。按本次正文方法理解本集要讲清的事情，分出主要内容、必要背景和可舍枝节，再在允许调整的范围内试拟标题、封面主句与场面，选择进入故事的方式。正文与题图在同次创作中相互校正，用户明确锁定的原字保留；本集问题、必要内容、主体和范围不因包装改变。采用通用方法时，写出讲述者的口气与趣味，让经过和解释不断带来新的理解。

封面按所列封面方法，把最值得看的具体动作、变化、处境或关系写成自然的短主句，再确定值得放大的词组；由本次实际选择的可见文字和画面共同交代主题，系列名和集号只在确有识别用途时保留，不自动占一层。保住自然用语与必要含义，不拼凑概念词，也不把完整说明句搬上图。横竖各自精炼措辞并考虑适排，共同兑现同一内容承诺，让真正的看点得到强调；每幅场面独立写足主要人物和关键物件的身份、材质与形态。具体文字与场面由你决定，不套固定冲突、句式或字数。

按本集范围和明确时长组织内容，先把决定走向的行动、回应、变化及必要解释讲透，再安排背景、支线与例子。时政稿同时形成并检验解释，把支撑判断的条件、作用过程和比较写开，让事实与分析共同推进。人物、空间与术语在理解需要时交代；不能只报事件、概括原因或亮出观点，让听众自己补过程与理由。需要收短时先省并对核心理解帮助较小的展开，再收紧重复、绕话与空泛评价，保留必要铺陈和自然停顿，不靠提高语速或省掉推理迁就时长，也不靠重复道理和悬念撑长。研究笔记提供事实，入口、结构、详略、语言和节奏由你决定。

交稿前按本次正文、平台与封面方法读回整套作品：主要内容是否讲透，篇幅是否适合委托，题图引出的具体问题怎样由开场开始推进、由全文兑现。比较实际标题的观看理由，不能只因母标题含事件名、正文能回答就直接保留。简介围绕主要看点，选有分量的事实、变化或生活细节，交出标题之外的信息与最少必要背景，留下值得跟随的具体事情。简介不负责讲完整集，不按正文顺序压缩各段经过、结局和意义，也不把章节各抽一句拼成摘要；逐句取舍有信息或观看用途的话，不补空泛价值总结。人物动作与影响要自然说清，不机械禁用必要术语；话题按各平台实际输入和本片内容选择，不能填几项泛词收尾。实际读取已交接的相关原文与出处，公开文献按对主要认识的贡献择重要、合并转载与重复作品，不把未读原书列成直接参考。二创参考视频、主讲者、频道、链接及改编说明不进入公开文字，不照抄内部取材用途；实际视觉素材署名继续保留。发现缺口就在这次创作内调整相应内容，使观看理由、实际回答和事实确定程度一致；不压缩必要内容迁就题图。完成三平台文案与话题、横竖各自的完整封面构思，一次交齐一套定稿。封面只构思，不生图。

正文只含可直接朗读的文字；片头服从所选方法。口播不使用中英文圆括号或编辑注释。内部参考节目及其主讲者不写入口播，本集本来以其为主题时除外。
```

固定从项目根目录调用。普通／full及`narration`的首次创作使用新会话，不带`--conversation`；`opener`续接工作单`reusedNarrationMaterials.agyConversation`固定的作者。取得本次成稿后，事实纠错及定点返工必要的发布续写使用该稿作者会话；普通／full不再选后补写。后续调用及未知恢复也沿本次作者，不重新开会话。

```bash
agy -p "<PROMPT>" --model gemini-3.8-flash-high --effort high --dangerously-skip-permissions --output-format json --print-timeout 10m
```

普通／full共用同一任务书、固定提示和参数，不指定不同风格、不分别取材、不展示其它稿件或选择意见。定点路线直接写唯一候选，不建立三路工作稿。调用记录、原始回包、机械交付与中断恢复统一按[作者交接方法](author-handoff.md)，本文件只拥有给作者的输入和提示。
