# 发布输入与原作者定点续写

两个P1作者共用。解说普通／full在N02读取下节，先准备三路完整创作的共同输入；三路首稿已含发布内容，选稿后直接事实核对，不执行本文件的续写。纪录片普通／full选定整稿后、两类节目正文或片头定点返工取得新稿后，按后续章节由当前原作者一次补齐需要创作的发布内容。只改发布内容的工作单直接进入相应定点路线。仅改正文且发布内容全部保留时，原样沿用工作单`currentPublication`；已随口播完整返回的，不追加续写。Codex负责调查依据与确定字段，不代写或润色。

## 解说完整创作的前置输入

N02完整读取[平台方法](platform-packaging-method.md)与[封面方法](cover-content-method.md)，根据当前P0任务和实际材料完成必要平台调查，三路共用同一份结果，不按路号分别取材或指定标题。保留来源、适用语境和调查局限；调查只帮助选词与表达，不改变P0内容任务，不把热度当成事实依据或效果保证。

将系列名、P0母标题与内容任务、受众、范围及调查原文和必要来源写入同一`scratchPath/publication-input.md`，内容材料引用本次`author-task.md`，不复制另一份笔记，也不引用尚不存在的候选。为YouTube按[来源与素材交接](#youtube来源与素材交接)交清实际借鉴作品、研究来源及外部素材的署名元信息；这些公开出处不同于SEO调查记录。作者在同一次成稿中形成简介、参考资料和适用的章名／正文定位，不增加一次写作调用。资源按读取时点分两组，均用实际绝对路径：

- 先读的创作方法与合同：`author-task.md`按综合解说包入口选定的唯一正文方法、平台方法、封面方法及`contracts/publication.schema.json`。时政稿列[时政解说方法](current-affairs-authoring-method.md)，其它解说列[通用解说方法](explainer-authoring-method.md)；实际输入只登记本次所选方法的绝对路径，不要求作者同时读取两套正文方法。
- 按内容试拟题图后读取的外观参考：工作单已选横竖Cover规则与各自样图，用于同次创作内的图文协调与定稿。

三位作者共用同一输入并实际读取两组资源；供应商参数、生成代码及未选Cover和Visual不进入作者输入。共同事实和主要看点不等于三平台复制同一篇文字，按[分平台成稿](platform-packaging-method.md#分平台成稿)在同次创作中分别完成：YouTube交完整介绍及适用的章节、出处；抖音标题与YouTube同类型且能共用就共用，配文简短；小红书单独写20字符内标题，正文逐字复用YouTube完整文案、只去时间章节，保留参考资料与视觉素材出处。抖音仍只写短配文、不带附录；所有平台都不写声音素材，末尾标签按各平台分别配、只追加一次。两组读取属于同一次联合创作，不新增构思文件、候选池或确认步骤。

## 交清本次输入

- 纪录片普通／full：只读唯一候选，续接选中稿的`conversationId`。正文与片头逐字锁定；不再调用未选作者，不另开包装作者。解说普通／full不进入续写。
- narration / opener：以唯一候选的本次修订稿为准，续接`scratchPath/agy-conversation-id.txt`中的本次作者；与工作单`currentPublication`对照，仅在用户允许的范围内修改受口播变化影响的发布内容，其余逐字保留。
- publication-all：以工作单当前正文、片头为准，联合写`platforms / covers`；已有文案只作本次明确修订对象，不能据旧稿扩大范围。
- publication-copy：只改平台文案；存在`publicationFields`时只交点名字段。`youtube.description`包含其附属章节设计，需改章时随同交`chapters`；未交章节沿用，明确不再分章才交空数组。只改title或其它字段时章节也锁定。未选字段、封面设计由程序继承。
- cover-content：只交`covers`，平台文案由程序继承。选用登记样图时，按工作单固定的`coverExampleAdoption`对齐可见原字。

完整创作读取[平台方法](platform-packaging-method.md)和[封面方法](cover-content-method.md)。定点编辑只读内容理解、相关平台、读回章节；改标题或正文再读题图方法，改标签读取调查与标签方法并查相应平台，改封面读取封面方法及相应Cover。工作单提供`reusedNarrationMaterials.publicationInput`时，先读其原始调查与来源，按当前任务保留仍适用的依据，不沿用旧修改意见、稿件路径或字段范围。已有充分调查直接复用；新看点、时效或事实疑点才补实际缺口。调查记录与局限不写进发布正文。

Codex按平台方法调查，交给AGY真实可用的叫法、话题和语境；不先拟标题、主句或设计方案让作者填空。将当前任务的系列名、受众、范围、修改意见、相关调查原文和必要来源写入`scratchPath/publication-input.md`；沿用的调查保留原文、来源和局限，连同未改平台仍有效的依据一并保留，使下一次修订能够直接复用；正文、片头引用当前唯一候选路径；仅发布内容定点修订引用工作单的当前正式稿字段，不重新抄写。文件末尾只列本次需要的专业方法、发布字段合同、已选横竖Cover规则及样图的绝对路径。生产程序、供应商参数、未选Cover和Visual不进入作者提示。

本次涉及YouTube简介时，按下节交清实际来源，供原作者写公开出处；章节定位只摘当前正式正文或本次唯一候选原句，不预估分钟。

平台方法说明怎样表达看点与选词；封面方法负责本集主句取舍、文字密度和图文语义的联合设计；Cover拥有文字材质、配色、层级、版式及配图的视觉强弱，Visual拥有场景画法与字体，由生图模块装配。主句的试写、压缩、图文协调与读回由原作者在本次续写内完成，接纳后生图原样呈现。将这些职责分清，不给作者预设统一冲突、问句、标题模板、人物数量或场景类型。

## YouTube来源与素材交接

Codex在本次已有`publication-input.md`中整理内容与视觉素材来源，原作者据此写入`platforms.youtube.description`，小红书复用其中除时间章节和平台独立话题外的完整文案；两类节目共用，不建立另一份出处表或新增创作节点。

- 从当前工作单的参考节目、当前`reference-materials.json`、Query实际引文及已保存的补充正文，判断本集实际借鉴的内容与独立核实资料。参考视频只取本集`referenceVideoIds`及实际采用的条目，不把其它集或整库作品都署上，也不能因重新组织了语言就省掉原作品。
- 将本集实际采用或用于具体断言核实的条目，与拟公开的参考资料和视觉署名逐项对照，补齐遗漏；不只摘几条机构主页，也不把未用过的整库资料照单列出。同一作品可简洁合并，但保留本次实际使用部分的可追溯定位。
- 交给作者的是已核实的作者／频道、作品名、公开原链接和实际用途。元信息缺失时从本次已有原链接补读；不猜频道名，不用内部文件路径替代公开出处。不要交原视频全文、转录读取路径或旧作者的段落方案，正文仍由作者独立组织。
- 原视频转述的书目只算转引；本次确实打开并读过、用于核实的原文才列为直接参考。SEO对标频道的标题格式借鉴不等于本片内容取材，二者分清。
- 外部图片、视频片段及地图，交清本次实际使用、改绘及所需署名的信息。声音素材来源及权利记录仍保留在原制作资料，但不交成公开文案条目；任何平台都不写声音素材栏目、零散配乐／音效署名、音源链接或待补提示。
- 新增外部视觉素材使已交付署名需要补充时，沿已有发布内容定点入口交接实际来源；本次授权覆盖两边共用文案时，同时点名`youtube.description`与`xiaohongshu.body`补齐相同出处，保留标题、封面和抖音。只点名一个字段的工作单仍按锁定范围执行，报告另一边需同步的具体内容，不暗中扩大范围。现行工作单未投递所需来源时报告具体缺口，不从旧会话补材料。

## 一次原会话续写

按已读[作者交接方法](author-handoff.md#选中作者补写发布内容)进入或恢复本次续写；只在允许首次发起时，沿作者包原模型与参数增加`--conversation <原作者ID>`，使用下列提示：

```text
请读取<publication-input绝对路径>及其中列明的当前稿件、方法与所选封面参考，为这篇已经写好的作品完成本次范围内的发布内容。正文与片头保持原样。

你是这些文案和封面构思的唯一作者。自行选择最值得让观众关注的角度，让标题、简介、话题与封面各自有用，并共同兑现正文确实展开的内容。可以采用问句、陈述或生活过程，不必套统一结构；依据事实、受众和各平台字段要求作取舍。

按平台方法定稿：YouTube与抖音使用同一类型的标题方案，满足各自长度时优先共用原题；抖音仍写短配文。小红书标题独立创作、不超过20字符，正文逐字沿用YouTube完整文案，只去时间章节，参考资料和视觉素材出处保留。所有平台一律不写声音素材。末尾标签按平台分别研究和选择，只追加一次，不能机械照搬或用泛词凑数。只改本次点名字段，其余锁定内容保留。

本次涉及封面创作或文字修改时，按所列封面方法，把最值得看的具体动作、变化、处境或关系写成自然的短主句，再确定值得放大的词组。由本次实际选择的可见文字和画面共同交代主题，不强拆A/B或添加系列名。横竖可分别措辞与分组，共同兑现同一内容承诺；把各自原字放到对应画幅中考虑，完成文案与场面的取舍。保住自然用语与必要含义，不拼凑概念词、不把内容提要加问号当作吸引力。每幅场面独立写足主要人物与关键物件的必要身份、材质和形态，不依赖另一幅补全；具体主体、行动与构图由你决定，文字外观遵循所选Cover。交稿前连读主句并按两种小图的阅读条件读回；在本次范围内完成必要的语言与图文取舍，只交定稿。

只读，不得创建、修改或删除项目及节目文件。只返回一个JSON对象，包含本次要求的platforms与covers字段；不返回正文、片头、分析、多套方案或评分，不填写生产者、复用标记或运行身份。
```

当前字段形状读取登记的`contracts/publication.schema.json`；AGY只填写创作字段。原回包由交接程序补齐身份、继承锁定内容并合入同一候选，不由Codex重抄。各路线的接收命令、进度和恢复仍按交接方法。

调用未知只恢复同一次，明确失败停止，不重开作者或追加润色。字段和锁定范围由现有合同核对，不把解析错误当作史实错误。

## 整套文字一次核对

本次唯一候选的整套文字交付齐备后，进入作者包的一次事实核对。普通／full核对整套。定点修订先与工作单现行稿件对照，只核对新增、改动的事实断言及必要上下文；publication-copy与cover-content限于本单字段，片头修订包括受影响的正文承接。发现问题牵涉锁定内容时报告具体冲突，不扩大范围。

完整读取唯一候选中本次范围内的正文、片头、三平台标题与文案、话题，以及横竖封面的文字与场面。先核对正文与片头，再逐平台、逐画幅对照其中的时间、主体、数量、程度与因果，并回到本次来源确认依据。按各处实际表达判断，包括问句预设的事实与结果；正文的条件限定不能使题图中已经发生或必然发生的断言自动成立。输出截断时按字段或段落补齐，不以摘要、节录或任务笔记代替成稿。整套只作这一次核对，不另存检查表或增加审稿轮次。

读完后一次保存全部已确认事实错误，每项列清本次范围内所有相关字段、必要原句、正确事实及依据，使正文、片头、题图和文案中的同一承诺在同次纠错中得到一致修正。只核对基本事实与正文支持的事实性承诺，不评价看点强弱、材料覆盖或讲述充分程度。

封面艺术化姿态、布景和象征不要求逐项史料取证，但不能虚构具体历史事件或结果。平台调查依据与正文共同界定能够承诺的内容。

不另开文案审稿轮次，不因个人文风偏好追加修订。无错误直接接纳；有错误把本次范围内全部已确认错误一次交给原作者，必要连带修改同步完成。完整创作／口播返工的纠错返回“片头”“正文”“发布内容”三段，最后一段为完整publication JSON；发布内容定点返工仍只返回本次publication JSON，正文和片头由程序锁定。纠错后的复验边界沿各作者包原规定。

Engine接纳后分别写正式正文、片头、publication.yaml和即时可读的publication.txt，并把本次publication-input.md保留在正文绑定的材料目录，供下次修订使用。封面图片由独立produce-covers节点负责；本步不生图或发布，也不把机械接纳当成用户满意。
## 纠错后的原错误确认

原作者一次纠错并交接同一候选后，按已保存的错误清单确认原错误已改正、收窄或删除，及其必要连带表述已与正确事实的范围、因果和确定程度相容。读取清单涉及的句段与必要上下文，依据沿用本次已核实来源，需要时回看对应原文；确认包含同一错误相关的片头、题图和文案。此步只确认原错误，不重新核对整套、不查找新问题、不评价结构风格或篇幅，也不润色、换作者或追加修改调用。

普通／full使用所选工作稿的原factErrors；定点返工使用本次已交给原作者的完整清单及同次调用回执，不创建三路记录。定点有错误时，在发起同一次纠错前，将完整清单原子保存到当前scratchPath/fact-errors.json，作为本次纠错输入，保留到接纳收口；不作为正式审计成果。原清单或纠错进度不能确认时，保留候选并报告缺口，不把缺失当成无错误，不凭印象重审或重投。

普通／full由`correct`保存的ready表示回包与候选已完成机械交接；有原事实错误时，ready不代替上述确认。定点不写三路进度，仍须确认原调用已完成、唯一候选已完整交接及原错误已改对。恢复时，已确认的空清单直接接纳；非空清单沿当前候选完成原错误确认，当前上下文持有对未变候选的确认时沿用，不重置整套核对或纠错次数。未知调用仍只恢复同一次。

原错误及必要连带表述已改对才执行原accept；仍未改对时，保留当前候选并报告具体未解决的原错误，不接纳、不追加作者调用，也不把语义问题标成技术失败换稿。正式accept仍执行原有合同；拒绝时报告回执并停止。
