# 综合解说口播创作

只接收`episodeBrief.programForm=historical-explainer`，只提交一份正文、片头与发布内容的联合候选。

## 共用创作职责

所有解说入口共用下述N01—N05。Codex理解当前来源，交清P0内容任务、范围与充分的有据材料，保留具体经过和必要上下文；已有完整故事策划保持其内容与策划逻辑。P0决定本集讲什么、必须讲清什么，P1决定怎样吸引观众及怎样展开；平台标题可以改写母标题，不能借此换掉核心问题、主要主体、范围或独有收益。材料与核心任务确有冲突时说明具体冲突，不硬写结论或暗换选题。

AGY是正文、片头、发布文字和封面构思的唯一作者，自主决定主次、入口、结构、详略、语言、节奏和篇幅，在同次创作内联合调整。完整正文是本次创作的主体，题图和开场服务它；按本次正文方法充分展开主要内容，次要背景按理解需要收紧。通用解说保留主要故事与经过的充分展开；时政解说同时展开事件与形成判断的理由。Codex先判断相应内容是否写到位，再比较整套作品，不以要点齐全或包装完整代替正文充分，不预写本集讲述方案、代写、跨稿拼改或追加润色。参考全文与Query只供Codex取材和核对。

## 路线

```text
N01 取得或复用本集依据（原文、视频、Query可结合）
  → N02 交清P0任务、事实过程及共同的平台与封面输入
  → N03 三路各自先拟题图，再写正文与开头，联合调整并交完整方案
  → N04 比较题图、实际开场与全文，整套择优；无可选稿则停止
  → N05 整套一次事实核对，按需原作者纠错并接纳
```

- `full`：新`executionId / scratchPath`，不读取旧尝试。
- `narration`：复用工作单固定的来源材料，重新交清本次任务，以新的单路AGY会话处理正文返工，按用户范围保留或修订片头；该稿发布续写、事实纠错和后续修订跟随新作者。
- `opener`：复用固定材料并续接现行正文作者，同步修改片头及必要的正文开场与承接，其余内容保留。用户指定片头原句时只锁定该句，仍由作者调整正文。

换题、越过`episodeScope`、更换主要主体、用户明确整稿不要、固定材料或外部结果无法确认时，保留现场并停止或交回正式入口；不静默换会话、重投或扩大范围。写作必需的材料缺口沿取材方法处理；普通／full选中稿后的关键事实及具体引述缺口统一在N05集中补读核对。仍无依据的细节说明限制，不自行换故事。

本次P1第一次实际调用AGY前，运行`agy --output-format json models`确认`gemini-3.8-flash-high`可用；不可用时停止，不静默换型号。

## 正文方法的选择

N02读取正式工作单`inputs.episodeBrief.explainerType`，按P0确定的类型使用对应方法，不从题材、标题、参考频道或旧任务书重新分类：

- `current-affairs`：采用[时政解说方法](references/current-affairs-authoring-method.md)，学习《王局拍案》的整篇讲述与推理方式。
- `general`：继续采用[通用解说方法](references/explainer-authoring-method.md)。

类型缺失、非法或与用户新要求冲突时，说明需要P0补齐或修订该选择，保留现有成果；不默认通用、不在P1暗换路线。

本次选择及方法绝对路径写入现有`author-task.md`的“创作任务”，普通／full还在`publication-input.md`的先读资源中列明同一路径。AGY只读本次选用的正文方法，不要求先套另一套写法；平台、封面和已选片头方法继续共用。方法不规定本集结论、段落顺序或固定篇幅，不新增P1结果字段或生产步骤。

普通／full三路共用同一方法，由各作者独立组织整篇。正文／片头定点返工也按当前P0类型交接方法给作者，只在本次获准范围内使用；不因方法更新扩大修订或重做旧稿。N04按同一方法判断展开是否充分，N05仍只核对基本事实。

## 准入

`publication-copy / publication-all / cover-content`直接进入“定点返工的发布内容”，使用工作单固定的现行稿件与原会话，不执行N01—N04。

按`inputs.returnRequest.revisionScope`唯一确定路线。Codex核对P0六项内容合同、节目受众、当前来源身份、用户明确的时长限制和现行正文／片头，确认题目、范围、主要主体与集间边界没有变化；完整核对供理解任务与取材，不表示逐字全部交给作者。

N02原样交接P0的本集展开意图、用户明确的时长要求及存在时的`episodeBrief.maxDurationSeconds`；篇幅由AGY依据任务与材料决定，不设统一字数、最低长度或常见节目时长参考。`narration / opener`须证明固定来源材料、旧证据与当前任务一致；材料缺失或摘要变化时停止，需续接的作者会话缺失时也停止。`exactOpenerNarration`先通过已装配片头Validator，不得让AGY改写。

## N01：请求本集资料

先从当前工作单确定实际来源；普通／full可按本集需要组合取材：

- 有`inputs.episodeBrief.referenceProgram`：完整读取[`references/video-led.md`](references/video-led.md)，保存并阅读当前参考原文。
- 公开网页、本地书稿或NotebookLM取材：完整读取[`references/explainer-evidence-and-query.md`](references/explainer-evidence-and-query.md)。按P0创作任务中的材料定位实际读取正文；采用NotebookLM时按该方法调用`scripts/run-cited-query.py`，不能用answer代替实际引文。没有Notebook输入时直接取用可靠正文，不为取材强制建库。

实际采用的公开与本地正文保存到同一`reference-materials.json`，与视频和Query共同交给后续事实核对及返工恢复，再进入N02。正文与片头返工只复用工作单固定材料，不重新取材。已开始的远端调用仍按原边界恢复，不靠改用网页掩盖失败或未知结果。

## N02：材料理解与作者交接

完整读取[`references/author-task-editing.md`](references/author-task-editing.md)。普通／full在同一`scratchPath/author-task.md`交付创作任务、写作范围和能独立读懂的研究笔记，保留主要变化的具体经过与必要解释，按实际用途处理疑点和细节取舍。任务书不设条数或长度，不锁定作者的讲述方案。再读取[发布输入方法](references/publication-author.md#解说完整创作的前置输入)，形成三路共用的`publication-input.md`，交清实际平台调查、专业方法、字段合同及所选横竖Cover规则与样图；不预写标题或封面，不引用尚不存在的候选。两份输入形成后进入N03。定点返工输入和锁定范围仍按本次范围形成；原始材料供Codex事实核对，YouTube公开署名所需的作者、作品名、原链接与实际用途沿发布输入方法交给原作者，不因此投递参考全文或锁定其讲述方案。

## N03：三份独立成稿

完整读取[`references/author-handoff.md`](references/author-handoff.md)，用已登记的`author-handoff.mjs`保存调用进度、原始回包和工作稿；固定字段、逐字封装及机械检查由程序完成。定点与纠错返稿也使用该入口，不临时编写封装或重抄正文。

继续按`references/author-task-editing.md`中的固定调用、作者提示和恢复方法执行。普通／`full`同时发起三路AGY请求，三路共读相同任务、所选正文方法与发布输入；各自按本次正文方法和题图方法理解内容、试拟题图，再读取已选Cover外观参考，联合完成正文、开头及发布内容。读回整套并在同次创作内调整，一次交齐正文、片头与完整publication。暂拟内容留在作者创作上下文，不新增文件或审批；三路不互看方案，不按路号指定角度。

原回包交给程序保存为`author-1.json`至`author-3.json`。此步只运行现有完整结果、发布内容及片头的机械合同，不评选、不事实审计、不让Codex改稿；缺文案或任一画幅构思不算完整交付，不选后补齐。不提前写`candidatePath`或根会话文件。定点路线保持单路及原锁定范围，直接形成唯一候选与本次作者身份；正文与片头返工仍交接实际受影响的发布内容，再进入N05。

进程正常退出、JSON可解析、`status=SUCCESS`、`response`非空且无权限软拒绝才算成功。必须三份完整方案均为机械可交付的`received`才进入N04。任一路明确`failed`时，继续接收其余已发起结果，保留稿件并报告“三稿未齐，P1未完成”，不减少选稿数量或自动重投。用户明确授权重试失败一路时，只按[作者交接方法的单路重试](references/author-handoff.md#用户授权后的解说单路重试)恢复，其它有效稿件保留；重试再次失败须有新的授权。未知结果只恢复同一次调用，不能当失败跳过；无法确认原调用时保留现场并停止。定点路线机械失败停止。

## N04：整路选一稿

完整读取[`references/draft-selection.md`](references/draft-selection.md)，结合N02已选正文方法，连续读完三路机械可交付的标题、封面构思、实际开场与全文，先判断P0内容任务与相应展开是否成立，再比较整套吸引力与兑现，用实际题图和段落说明理由。没有可选稿时按该方法停止并保留本单三路工作稿，不调用选择器、不写候选、不接纳或自动重写；普通继续仍只读取同一稿件，用户明确重做才交回Director的现有入口。全部创作字段原样采用同一路，不跨稿配对、不改写；此步不查证事实，未选稿不审、不修。

选出成立整稿后，按[作者交接方法](references/author-handoff.md#锁定整稿)的`select`命令只提交所选路号，完整result与作者身份进入唯一候选，直接进入N05，不再补写发布内容。选择锁定后不改选、不在此accept；事实处理已开始时恢复其当前进度。

## 定点返工的发布内容

仅narration或opener形成修订稿后，完整读取[发布内容作者方法](references/publication-author.md)，按本次范围交接发布内容，再进入N05。需要补写时只续接当前原作者一次；仅改正文且发布内容已原样完整返回时不追加调用。publication-copy、publication-all、cover-content工作单直接按该方法单路处理，不重新取材或选择正文。普通／full不经过本节。

## N05：事实核对与接纳

读取[`references/narration-audit.md`](references/narration-audit.md)，在这一次核对中完成唯一候选的关键事实与具体引述核实；现有依据不足时只按该方法定点补读并保存正文。逐平台、逐画幅核对实际断言及其与口播的关系，全部读完后一次列清已确认的基本事实错误，再交原作者纠错。进度与事实清单按已读交接方法保存和恢复；已有清单直接复用，不重置核对或纠错次数。

普通／full无错误时用原mark将所选工作稿标ready；定点返工不标三路进度。各路线有错误时只按核对卡回所选原作者会话一次，再用交接程序的correct更新唯一候选。完成原有机械交接后，只按[原错误确认](references/publication-author.md#纠错后的原错误确认)核对原清单及必要连带表述；不重做整套核对、不查找新问题、不润色、换作者或追加修改调用。机械失败停止，未知只恢复原调用。

无未知调用，唯一候选已完整交接，原清单确认为空或已完成原错误确认时执行`accept`；普通／full还须所选工作稿为ready，定点只确认本次原调用已完成，不创建ready状态或三路记录。恢复有原错误的ready工作稿也须完成该确认；未改对或无法确认进度时保留候选并报告，不接纳或重投。Engine保留本次实际使用的Query及reference-materials、作者任务书与所选作者会话并清理工作稿；正式接纳后交回Director，由独立produce-covers节点按封面授权处理，不自动进入P2。

## 提交边界

普通P1、`full`、正文与片头返工均提交正文、片头与publication。发布内容修订锁定正文与片头。Engine分别写入正式文件，不把发布文案送入TTS。机械通过不代表观众接受，也不代表纠错返稿经过第二次内容审计。
