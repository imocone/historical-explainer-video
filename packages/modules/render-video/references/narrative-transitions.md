# 全画幅转场：叠化与闪黑

本方法只用于全画幅叙事画面之间，包括剧情视频替换后的全画幅媒体接缝。涉及讲解的进出及讲解互接，沿讲解模板专用呈现；片头沿片头模板。创作时合读前后正式字幕、口播和观看要求，再结合导演节奏与已知画面选择。首次使用读本页及[执行说明](transition-execution-reference.md)，恢复时沿用未变材料。

## 选择规则

**还在讲同一个问题或过程，用叠化；前段已告一段落，下一段需要重新起笔，才用闪黑。**

“讲述单元”是一件事、一段解释或一个完整侧面，不等于一个Beat。闪黑须同时满足两点：前段当前要表达的内容已讲清；进入下一段前，确实需要让观众消化、停一下或重新定位。

| 转场 | 适用情形 | 要形成的观看 |
|---|---|---|
| 叠化 | 承接、递进、因果、问题接回答、同一问题的对照；回忆或跨时空画面仍需保持联系 | 前镜逐渐交给后镜，同一关注继续展开。 |
| 闪黑 | 一个事件、结论、情绪或论述单元收住，再展开下一单元；时空变化需要明显分隔后重新进入 | 前镜淡到黑，留一口气，再建立后镜。 |

### 容易选错的地方

| 前后字幕的意思 | 选择与原因 |
|---|---|
| 粮食运到港口 → 再运入城市 | 叠化，同一运输过程继续；换地点不等于结束一段。 |
| 宣布改革 → 但乡村依然照旧 | 叠化，仍在对照同一问题；“但是”不等于需要休止。 |
| 他继续等待 → 又一个春天过去 | 叠化，时间省略仍在延续等待；年份变化不自动触发闪黑。 |
| 战争已经结束 → 十年后，另一场危机出现 | 闪黑，先让结束落下，再建立新处境。 |
| 全画幅讲完财政机制及结果 → 转入另一个完整的军队问题，需要重新起笔 | 闪黑，收住这个论述单元再展开另一个；仅说“第二点”不足以这样选。 |

## 在原联合设计中落实用法

1. 先确定前段留下什么、后段新增什么，以及这里应当继续还是停一下。选择随画面设计写入原候选；理由说清具体关系、效果收益及已知画面怎样接手，不用“自然、丝滑”代替。
2. 叠化时安排两镜主体位置、分量、明暗和运动，避开人脸、文字、关键动作在混合最强时首次承担辨认。若遮混，先修构图、取景或时长；不能只为避开重影改成闪黑。
3. 闪黑前让必要信息读清，后镜在旁白需要时重新可辨。黑位不能打断尚未完成的动作、追问或因果，也不要求声音一起中断。

## 接缝与全片节奏复核

沿原作者的设计复核和实图／预演范围，配回原声看前镜是否读完、后镜是否及时接手、关键结果是否提前露出。连续多次叠化可以成立；每次闪黑都要有具体休止价值，不能轮换、凑比例或因叠化用多了就插黑。参数合法不证明观看合适。

跨章依据正式语义和导演意图选择，不等待或虚构章外实图；只有设计时，结论限于设计。时间、因果与回忆身份由正式内容交代，效果不补造关系。选择和修正留在原候选，不增加分析表、生产节点或交付后整集审查。

[联合教材](../../../templates/fullframe-narrative/examples/joint-reading.md)用同一对图片、不同字幕任务说明两种选择，并保留人物遮混的实操难点。

## 专业依据

- [普林斯顿剪辑示例](https://commons.princeton.edu/remote-ethnography/editing-remote-interviews/)演示黑位如何标示时空变化，也展示它插进连续一句话时的打断感。迁移到本项目，判断讲述是否需要分隔，不能只看地点或连接词。
- [Ken Burns团队剪辑师Craig Mellish访谈](https://www.provideocoalition.com/art-cut-ken-burns-doc-editor-craig-mellish-ace/amp/)说明照片段落也需有进入和收束，末镜要配合音乐与退场留出分量；不同段落不能套同一种起法。
- [哥伦比亚大学叠化](https://filmglossary.ccnmtl.columbia.edu/term/dissolve/)与[淡变](https://filmglossary.ccnmtl.columbia.edu/term/fade/)解释共显和退去再进入的区别。全画幅之间只保留两种及上述选择规则是本项目的创作约定，不是所有影片的统一规范。
