# 全画幅转场执行说明

选择依据只见[语义方法](narrative-transitions.md)。作者交付选择，程序计算并执行；缺少选择返回作者，不自动补叠化。

## 写入位置

| 作者 | 唯一结果 |
|---|---|
| P3全画幅 | 相邻全画幅的Beat入场写`treatment.incomingTransition`；同Beat B入场写该请求的`incomingTransition`。首Beat及讲解后的Beat顶层写`null`，由对应模板拥有进出。 |
| P4剧情视频 | `candidate.result.incomingTransitions`，以进入片段B／V编号保存视频替换后改变的全画幅媒体外侧接缝；片头、讲解交界及被覆盖成员内部不登记，不回写P3。 |

两种效果都只交`type / durationMs / reason`，不带方向。技术容量至少2帧、至多1800毫秒；规划预算可保留未设计边界，正式全画幅接缝不能用空值代替选择。

## 时长与呈现

- **叠化**：可先在0.4—1.2秒内推敲，按共显主次、后镜独显阅读时间及余韵调整；共享呈现沿现有线性光混合。
- **闪黑**：可先在1.0—1.4秒内推敲；总窗口前30%淡出、中间40%黑位、后30%淡入。1.2秒时约有半秒纯黑，让前段停一口气再进入后段。黑位仅指正文画面层，字幕按实际画面取色，黑位用亮字；独立注释沿原合同显示，声音不自动重排。

上述秒数是创作起点，不是默认值或行业标准；按实际窗口选择，上限仍为1.8秒。效果以原Cue接缝为中心，字幕、旁白、正文总时长不移动，预演、测量和P4同源。

## 媒体与测量

跨片段固定余量不随效果变化：后镜保留接缝前900毫秒，前镜覆盖下一片段Cue前的间隙，再保留接缝后900毫秒。全画幅延续相机，视频延续原真实活动。讲解专用进出使用自己的时窗，不套用这份全画幅边界余量。

同Beat A→B按实际显露计算各图阅读和运动窗口；`dissolve-in`只是B入场的Cue动作名，效果仍读B的选择。全画幅用原`inspect-design`的`transitionReading`核对同帧取景与显露，读法见[相机执行说明](../../../templates/fullframe-narrative/camera/execution-reference.md#转场观看反馈)。视频沿原V2设计及提交核对首末活动。

纯转场参数不进入图片或视频生产投影。活动不足返回原作者，不用定格、拉伸、变速或追加付费补造；视频内部剪辑与分次connection仍归原视频方法。
