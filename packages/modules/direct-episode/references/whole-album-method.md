# 整集画册方法

本方法服务`direct-episode`的初稿形成与统一章节划分后的共同校正，执行顺序和交付点由根入口拥有。它把正式口播、cues和完整已接纳Understanding转化为整集画册方向，与章节的类型、范围及全画幅Beat共同收敛；完整画册脚本由`albumPlan + beats + templateRuns`共同组成，`albumPlan`不是脱离正文范围的第二份抽象稿。本方法不产生第二时间轴、镜头表、素材请求、正式画面设计或模板实现。

开始前完整读取全部正式cue和已接纳Understanding。cue承担正文事实，Understanding只补充多个下游必须共同继承的非显然主张／关系、登记来源证据、整集与局部`semanticReading`、uncertainties和mustNotInvent。说话立场、语境、修辞和人的处境决定文字表面以下真正要表达什么；不确定项与禁造边界限定事实结论。缺少F/R对象不等于缺少正文依据。预想画面时可以合理演绎、使用象征、反差和幽默；修辞不能冒充史事，但它可以成为可见意象。画册需要交付认识、感受和观看兴趣，不把观看内容都收缩为一项可考据的办理动作。

## 1. 先确定整集观看路线

先回答四件事：

- `intent`：这集最终要让观众看懂的视觉命题；
- `openingState`：观众进入正文时看到的起点状态；
- `progression`：状态、关系或注意力怎样随着正文推进而变化；
- `endingState`：正文结束后观众应看到的收束状态。

先从最后希望观众形成的认识或感受倒推：哪些处境和关系需要先建立，哪里应看见变化，哪里应看见人的后果；再顺读正文，想清这些话发生在怎样的具体世界里。人名背后的人在做什么、依靠什么、受什么牵制，物件怎样进入行动，变化怎样触到人和环境？只展开有助于当前内容的部分，事实强度沿正式输入；这番理解用于选择，不要求全部入画或另写理解稿。

从中选择适合这段的观察线索。运枪计划可以跟随同一批武器，从取得物质力量，进入不同人的期待与使用意愿，再到改航后失去掌握；不必始终跟着筹划者读文件。讲一种制度也可以跟随它触到的一次生活过程，人物近景则可以承接此前已建立的处境。这些只是选择方向：同一物件贯穿、人物视点或宏观全景均非必选。选中的线索要使本段内容获得具体形态和感受，不能只把政治、金融、生活依次换成三种背景。

在`progression`及各B记录的原职责中落实这条观看路线：前面建立什么，后面让观众怎样重新理解、感受或看见后果；人名、日期与背景仍可由旁白承担。导演交付各段的观察对象及其叙事作用，正式场面、画数、构图和镜头由作者形成。先想清联系，再决定是否让同一人物、地点或物件反复出现；贯穿元素从表达需要中产生。

构思时，把相邻画面放在一起想：前一幅使观众注意到了什么，后一幅接着让他看见什么？例如一段虚构故事先表现生活恢复，随后仍留在同一座城，却转向一个尚未等到亲人的人。地点没有变，观众对这座城的感受却加深了。推进既可以来自事情继续发生，也可以来自同一处境中另一面被看见；示例只教组织方式，不提供节目事实。

前后若只重复同一种意思，可以省去重复的一幅，或从正文中重新寻找值得展开的侧面；后面的画面若需要前面建立的空间、对象或处境才能读懂，就保留这个铺垫。画面各自精彩之外，还要考虑它们共同形成怎样的经历。将选定的推进写入`progression`，不能只列“权力—财政—社会”主题；一个阶段可以跨多个Beat，全画幅不把一个主题、一段业务或一处场景直接对应成一页。全画幅Beat边界统一按Beat方法判断；讲解保留整章要求，具体画面、构图与运镜交给Template作者。

在同一`progression`中交代必要的节奏意图：哪段持续推进、哪里蓄势或转折、哪里让观众停留消化、最后如何收束。由全画幅Beat或讲解整章范围记录的`roleInAlbum / relationFromPrevious`落实这些关系；不先指定效果名称、时长、出现次数，也不另造节奏表。作者把这些意图与本单正式语境、实际画面和运动一起实现为衔接。连读时若内容不断发展，预想却一直是读信、看表情、换一份文书，就回到事情本身寻找未被展开的部分；若等待或通信正是这一段值得体会的经历，则保留其必要持续，不为丰富而硬换场。

四项的意义必须来自当前口播与最小共享Understanding，并受相关登记来源、局部语义、不确定项和禁造边界约束。视觉组织可以发挥，不能用常识补写历史判断，也不能用抽象口号替代由实际正文范围落实的观看路线。

## 2. 只保留真正跨正文范围演化的元素

`recurringElements`可以为空。只有同一主体、对象、地点、状态或关系确实需要跨两个或更多B记录被重新看见，并且每次出现都会改变其处境、意义或观众注意力时，才建立一个元素。全画幅B是Beat，讲解B是整章范围记录；单条B记录内部的呼应由作者组织，不为登记元素切Beat：

```text
RE001 = {
  subject,
  purpose,
  progression,
  beatRefs: [B001, B003, ...]
}
```

`beatRefs`使用整集全局B记录ID，按正文顺序登记；可以跨越其它记录，不得使用章内序号、局部索引或不存在的ID。`purpose`说明它为何值得前后呼应，`progression`说明它怎样演化；不能把单个记录中的普通主体包装成recurring element，也不能为凑数量设置重复元素。

`subject`必须是能在各引用范围中被具体辨认的同一对象、处境、状态或关系，不能只写“中央权力”“社会代价”“改革推进”一类抽象主题。每个`beatRef`对应记录的`mustShow`保留本次呼应的可见依据，在原`progression`中说清重见的意义，不强求物件改变；删掉某次引用不损失真实演化，就删该引用，全部只重复同一抽象意思就删整个元素。贯穿物是呼应线索，不包办所有选场：商信可以串起往来，但信中记录的缺舱、货源或资金处境，仍须按当前观看任务预想其可见表现。

## 3. 在一个专业创作环中形成整本画册

本节用于初稿与统一章节划分后的共同校正；执行顺序、审计次数及恢复统一见[根入口](../SKILL.md)。以下成立条件用于当前创作与已安排的审计，不另开迭代。

先通读整篇，不急着切Beat。沿正文明确观众从什么认识进入、本章的画面与口播共同交付什么认识或感受、它怎样推进整集。直接比较合理全画幅与讲解的表达，再划定必要范围；认识不一律变成读图任务，情境也不一律排除讲解或地图。相邻事件共同说明的关系要保留，不能概括成笼统主题后丢失比较机会；具体模板取舍由正文章节划分方法完成。

根入口第一步按[正文章节划分方法](template-selection-method.md)先划讲解章节，再按相对完整叙述组织剩余全画幅章节，保存同一候选。将范围放回整集：所选章节带来了什么认识，前面是否已有必要背景，后面继续推进还是重复一遍，重要的人物处境与情绪是否仍然成立。完成第二步历史视觉考据后，第三步才按[全画幅Beat方法](beat-page-method.md)，结合画面预想和真实窗口切分各全画幅章节；讲解只交整章观看要求，不安排内部Beat。落实实际成员后，同步整集关系、重复元素和模板连续性；进入或结尾变化时核对其依赖范围。不为插入讲解或地图固定停顿或凑数量，预判深度与拆合判断仍由Beat方法规定。

在根入口的同一次切分审计中，按章节划分方法看章节组织，再按Beat方法看全画幅Beat的预想画面及讲解的整章要求，对照口播确认能否表达当前意思，是否共同完成`albumPlan`，前后呼应是否有依据。设想只有题材相符、没有表达本章关系或处境时，将场面或`mustShow`的问题列入本轮意见；需要改全画幅Beat或章节边界时，同时列明边界问题。相同人物、场地或动作可继续承担表达，不为变化而换场或合页。Director负责整集意义与正文范围交接；逐图场面、构图和运镜由Template作者形成。

成立条件是：每个全画幅Beat均按[全画幅Beat方法](beat-page-method.md)成立，讲解范围完整且要求覆盖必要阶段；各条`roleInAlbum`能解释其推进作用，`mustShow`承接真实可见义务，每个呼应元素都在其`beatRefs`范围上发生真实演化，模板归属与章节成员完整且不打断`albumPlan`，整集最后状态由前文逐步形成。可见义务只进入现有`viewerOutcome / directorBrief`，不保存为`showables`、第二候选或另一条分段。

缺少完成导演任务所必需的事实或共享语义时，按根入口停止或退回Understanding，不自行补造。具体注意力路线和构图由Template Author完成，不写入导演结果。当前切法不可创作时，由Director按本方法与Beat方法调整边界或预想表达。

## 4. 禁止越界

本方法不决定构图、景别、机位、运镜、素材、生图提示、P4 时间和版式。`albumPlan` 只保存整集语义方向与前后关系；正式Template结果仍由Codex作者实际创作并判断，机械校验不能替代它。
