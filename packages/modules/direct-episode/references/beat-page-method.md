# 分镜与剪辑方法

章界确定后，沿完整口播组织观众的注意力。全画幅精排到逐镜的场面构想、观看职责、切点和接法。讲解段作为一个完整的观看单位，定下它怎样承接前镜、展开关系和转交结果。进入作者制作前，沿两类单位的实际播放顺序审修接缝，封存同一导演候选。

## 1. 从正文形成镜头

从同一候选的共享理解认清话语所指、立场、修辞和人的处境。正文已经交代的背景可以由声音承担；画面优先交付关系、尺度、制约、动作结果或人的代价。沿上下句找实际的表达落点，保留条件、限定、动作与结果间的必要联系。一个关系可以跨镜，几个连续变化也可以在同一镜内完成。

- **全画幅**用一幅完整静态主画面支撑该镜。先明确哪一刻的场面能承载这次观看，再决定第一眼看什么、何时发现另一层关系、末尾为何值得停留以及在哪句切走。持续运镜可以改变观察位置和重点；要呈现不同的时刻、反应或取景而一幅图承载不了时，就比较拆镜和重新组织单图的实际收益。定下镜头后交作者落实源图、具体构图和相机。按[场面选择](../../../templates/fullframe-narrative/references/scene-selection-method.md)核对清晰阅读窗口。
- **讲解**按一章交接。定下进入本章所需的参照、必须看懂的变化、需要对齐的关键揭示及退出前留给观众的结果。具体镜头由模板作者看着原工程的全章粗排决定。

逐对设计相邻全画幅。沿两侧口播，先摆出前镜最后看清的结果、后镜第一眼要认出的主体和下一次揭示，再一起定切点与接法。还在讲同一个问题或过程时，用叠化接住能追认的形状、方向、视线或处境，把新的辨认留给后镜清楚显露后。前段已经收住、后段需要观众重新定位时，用闪黑留出停顿，给下一镜留出建立新处境的时间。按[全画幅转场方法](../../render-video/references/narrative-transitions.md)和实际Cue推敲两侧的可读性。接法、时长和两镜如何交接随这一对分镜一起确定。

## 2. 写入同一导演候选

全画幅一镜一条B，新讲解一章一条B。加入所属章节的 `beatIds`，按正文顺序连续覆盖所有Cue。

- `viewerOutcome` 写这次观看要让观众理解或感受到什么。
- `directorBrief.roleInAlbum / mustShow` 写本镜或本章在整集里的职责，以及必须看见的动作、对象或关系。全画幅把已定的场面构想写进 `mustShow`，供作者落实这镜的具体构图与取景。
- `directorBrief.entryFocus / reveal / exitHold` 写进入后的观看重点、应在哪句或哪层关系揭示什么、结束前留住什么。确实关系到整集节奏的揭示，写明Cue或短语。
- `directorBrief.relationFromPrevious` 写这一镜或这一章怎样接住前文。首条填 `null`。
- `incomingTransition` 填在进入的全画幅镜头。相邻全画幅间交付叠化或闪黑，填写 `type / durationMs / reason`，说明下一镜承接什么或为何要停顿。正文首镜和紧接讲解的全画幅填 `null`，分别由片头或讲解的专用接法接入。讲解章记录省略该字段。

全画幅镜头边界取下一镜首Cue。已有有效结果按原身份和实际业务依赖保留。

### 可创作性规划的读取

逐镜查看真实Cue时窗、接镜时钟和前后过渡留量。全画幅新镜只消费单幅的 `planning.options`，其中有正文时窗、预进入、尾段、运动行程和倍率范围。按 `clearViewingMs` 核对计划接法后实际留给全画幅阅读的时间。不要用接镜重叠或闪黑凑清晰阅读时间。纯推拉没有可用恒速时，结合画面预想有意义的平移或变化速度；时窗仍不足就调整剪辑边界。

讲解读取 `planning.viewingWindow`。`entryPush / exitPush` 是实际推移开始、结束的帧位，以本段开始为零点，结束帧不含在区间内。负帧表示推移已在本段开始前发生。`clearViewing` 是段内两次推移之间完整显露的区间，`null` 表示没有这样的区间。没有对应接缝时推移项为 `null`。用这些数据对照两侧Cue，判断前镜落点、段首参照和段尾结果何时能读清。数字只描述显露时窗，观看判断归导演。

## 3. 逐边界复核

读同次规划输出的 `editWindows`，以正文时间原点看叠化、闪黑和讲解推移的实际起止，结束帧不含在区间内。相邻转场挤在一起时，先保证中间画面的观看任务有足够的清楚显露时间，再调整全画幅接法时长或相关切点，并在原候选上重算。

从头顺读整集，同时看章节推进和逐镜组接。查漏掉的揭示、口播已转而画面没转、解释尚未读清却抢切、相邻镜头重复、片刻黑场或静候过长，以及切换模板后观众是否还能认出关键对象。每处讲解接缝把前镜最后可见的参照、推移期间的显露、讲解开头第一眼或退出前的结果、后镜接住的内容连起来判断。全画幅逐镜确认场面和切点足以托住观看任务。把需调整的Cue、前后观看关系和要得到的效果在原候选集中修正，沿根入口封存并接纳到同一故事板。实作证明必须改全画幅镜头职责、切点、接法，或改变讲解段界、承接及后文依赖的揭示时，作者带具体Cue和观看后果返回导演。

例如，以下是虚构口播，示意语义和画面职责怎样配合；时长、分镜与具体拍法须按实际cue再定：

| 连续话语 | 具体观看表达与边界判断 |
|---|---|
| 船靠不上损坏的码头。货物还在船上，岸上的人只能等。 | 可以共同表达“船岸被阻隔，货与人都困在等待中”；若两句只是把同一处境说清，不按句号再造一张同义图。若原文后段深入个体等待的代价，则按新的表达另判。 |
| 工人决定搭一座临时栈桥。 | 新的一拍接住“开始主动打通通路”，有决定与行动方向即可成立，不必吞入最终成功。预想能看到搭建与断口的联系，不能只写“工人出现”。 |
| 第一箱货终于上了岸。 | “终于”落在障碍被突破、第一次兑现上。若这句有自己的口播落点与阅读时间，就让承重、交接或落岸取得独立画面分量，用承接连回搭桥；让前一镜的期待在这一镜兑现。若只是极短、不可分的动作兑现，则合在同Beat组织。 |
| 可仓库已经塞满了。 | 转折改变观众刚形成的预期，应及时转到“上岸仍无处安放”；不能继续展示成功卸货，让口播独自承担逆转。 |
| 他们只好连夜把货转运到镇外。 | 再交给新的去向与夜间处境，承接库满的原因；不因同属“运货”合成一幅长镜。 |

完整的运货事件由章节连接；每一拍有自己的意思，又能沿同一批货顺着看。若把“工人／决定／栈桥”分别成拍，或“仓库／已经／塞满”逐词换图，就没有完成一个可观看的表达。反过来，用一个“排除困难”的长Beat装下全部过程，会丢掉决定、兑现与逆转各自应有的分量。

相反，“买保险要付钱，不买则自行承担沉船损失”共同建立同一个具体选择；宽敞车厢与檐下挤行的人群可以共同呈现一次待遇对照，不能只因主体或地点不同就拆。“他等到深夜”及环境、神情对这次等待的必要展开，也不因可单独画出而各成一页。保留同页仍须有画面能支撑各自真实窗口，不能用“对照”或“情绪”泛称掩盖空撑。短段若已完成具体转折且满足逐图清晰观看下限，也不因cue少就并回前页；不足下限时按第1节调整相邻边界，保住转折。

“来源转运作”须结合实际画面判断，不能只按解释题目或关系标签拆合。先后或共现不自动等于因果，毁校与跨期入学率不能凭相邻口播写成行动与结果。例子只示范判断，不规定角色、页数或画面，不代替当前cue。

全部长短页都在本轮完整顺读中覆盖，详细比较只针对发现的疑点；在原复核中落实逐图清晰观看下限，不因时长另加审计轮次；不设时长硬上限或页数配额。

规划给出创作条件，Director用具体画面判断当前任务是否能在其中交付；不以容量取代语义，也不把画面设计留到切分之后才考虑。本轮发现当前切法不可创作时，将缺口列入完整意见，审完后按根入口在一次集中修正中联合调整任务、画面组织与合法边界；不能合法调整时报告真实能力缺口。拆合后更新镜头合同、albumPlan和实际改变的引用归属；身份保留、编号整理与同版技术交接按根入口1.1、4.3及第五步执行。引用歧义由Director根据实际归属修正。

专业依据：[Murch谈思想节奏与切点](https://cinemontage.org/visual-music-walter-murch/)、[Murch谈实时选择切点](https://www.provideocoalition.com/aotc-murch-books/amp/)、[电影事件分段研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3208769/)、[Pearlman对切点、速度与段落组织的区分（第3章公开预览）](https://www.oreilly.com/library/view/cutting-rhythms/9780240810140/10_ch03.xhtml)。这些材料不规定本项目Beat、静图时长或注意力收益；这里结合静图、持续运镜与旁白转用，事件连续不要求全程同Beat，节奏也不等于切得越多越好。

## 4. 整集收口

在第3节同一次顺读中，一并留意碎页重复建立、必要推进被省去、信息拥挤及长图空撑；只判断这些问题是否要求改页，不提前验收作者的逐图方案。普通场面代称或同义重复不能充当持续观看理由；存在此类问题时并入本轮完整意见，不另加逐图检查或整集扫描。

用本轮顺读结果对照`albumPlan`，确认进入、推进和结尾都由实际范围兑现，没有引入当前cue与共享语义之外的事实；不为收口再从头或反向遍历全部页面。全画幅镜头与讲解章节连续、无空缺、无重叠地覆盖全部Cue。数组和Cue决定播放顺序，每条Cue恰好属于一条B记录，记录边界位于相邻Cue之间。讲解作者沿原字幕与实测短语证据编排章内卡点。后续F/R/E与局部语义由System Control按cue范围自动求交，不写入Beat合同。

根入口在语义稿、章界和考据后细化全画幅镜头并交接讲解章节。全画幅一镜一幅完整主画面，讲解按整章交接时窗与观看任务。选型变化时校正实际范围与职责，不能把全画幅的独立场面原封不动交给讲解或地图作者。全画幅章节组织共同设计，不吞并成员Beat的独立观看推进。模板实现的可创作性由根入口调用同源检查，不能反向制造分页理由。同页两端跨地点或时段也不能被写成虚假的共同大厅、档案室或会议现场，诚实的场面、构图、相机、运镜与卡点由所选Template Author决定。
