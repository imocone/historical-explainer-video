# 历史纪录片口播创作

只处理`episodeBrief.programForm=historical-documentary`，只提交一个正文、片头与发布内容的联合候选。Codex是制作管理者：负责工作单、材料身份、Query回执、重大事实边界、交付合同、候选提交和正式接纳；普通／full另从三个独立首稿中原样选择同一作者的一套作品，选择只用于已有稿之间取舍，不代替作者决定段落、详略、材料取舍、节奏、意象或句子。AGY拥有各自稿件的主编和写作责任：在P0故事大纲与有据材料范围内决定整套文字，并亲自处理必要修订。P0保有本集主体、核心收益、必要过程、范围与重构边界；AGY可省并非关键连接动作、选择叙述入口和详略，不把故事动作链逐项扩写成正文，也不改造真实历史先后。P0授权的合成人物、合成路线和合理文学细节可以串联史料；沿途历史事实只认Query的`references[].cited_text`。Codex始终不得改写AGY口播字段。

## 路线

```text
DN01 取得或复用Query材料
  → DN02 写出creative-outline.md
  → DN03 普通／full三路独立交正文与片头；定点返工保持单路
  → DN04 普通／full整套择优并锁定唯一候选；定点返工跳过选择
  → 选中原作者会话一次补齐发布文案与封面构思
  → DN05 整套一次基本事实核对；按需原会话纠错一次并确认原错误，再接纳
```

## 准入前提

`publication-copy / publication-all / cover-content`直接进入“选定后补齐发布内容”，使用工作单固定的现行稿件与原会话，不执行DN01—DN04。

路线与现有P1一致：普通和`full`使用本工作单新材料尝试；`narration / opener`均复用Engine固定的旧Query和原作者会话。片头返工同步调整正文开场与必要承接，其余内容保留；存在`exactOpenerNarration`时只锁定片头原句，仍由原作者调整正文。必须核对`episodeConcept / episodeThroughline / episodeScope / episodeBenefit / storyOutline`、节目非虚构边界与`notebookId`。同时读取`episodeBrief.audience`与`programPlan.maxDurationSeconds`（存在时）；纪录片时长来自工作单的节目输入，不从旧单集、其它剧集或记忆补取。其它节目方法字段只帮助管理者确认没有拿错任务，不整包转交给AGY，也不把解说型Q/A字段当作替代。正文路线在DN01前依当前委托时长、已知片头安排和委托提供的语速估计正文篇幅，预留必要停顿；没有语速信息时保守估计，不为估算另取材、读取其它剧集或调用TTS。时长上限不是必须写满的目标，汉字预算不冒充真实音频时长；未给时长时仍以约2000个汉字作为默认创作参考。该预算供本次Query和DN02共同使用，不建立新字段、计算脚本或接纳门。

必需输入缺失时停止。普通／full进入DN01，narration与opener进入DN01复用固定材料。首次实际调用AGY前按下文核对模型，不调用则跳过。

## DN01：取得并核对本集事实材料

普通与`full`完整读取[`references/evidence-and-query.md`](references/evidence-and-query.md)，把其中的查询输入对应为：本集必须呈现的历史生活、承载这些内容的故事骨架、创作要求和本集边界。运行：

```bash
node packages/runtime-config.mjs python -B packages/modules/author-narration/scripts/run-cited-query.py <workOrderPath> --confirm-clear-chat
```

脚本本地等待超时但NotebookLM已经在同一会话完成时，只按同一`conversation_id`和逐字相同的提示词取回该次服务器结果及引用，不发起第二次Query。NotebookLM已经明确返回非空答案和可确认的同一会话身份、但没有可用`references[].cited_text`时，脚本原样重提同一提示，连同首次最多三次；任一次取得有效引用即停止重提，三次均无有效引用才停止。服务器结果尚未完成、提示词不符、JSON无效或会话不一致时不重投；恢复仍不能取得可确认结果时，导演入口可以在现有P1授权内正式放弃该次未知Query、换新身份从主Query重新取材，也不再询问用户。

`narration / opener`只读Engine固定的旧Query。各创作路线完整阅读每条`references[].cited_text`，只做管理性核对：P0故事涉及的地点、物件、行业、制度、数量、时序、因果和生活后果，哪些是原文直陈，哪些只是多材料推论，哪些属于P0已声明的艺术串联。合成人物、连续路线、合理天气、气味、身体负担和当下反应不需要伪装成史料，也不需要逐项取证；但它们不能承担新的制度、数量、时序、真人生平或历史因果。

Codex不在本步替AGY决定正文用哪几条材料、怎样铺陈、什么细节更动人或哪一句应当先说。只有P0故事赖以成立的一项重大历史关系缺少引用时，才允许建立一个同会话定点补充提示；同一提示因已确认答案缺少引用而由脚本重提，不构成第二个补充问题。不得为文学细节、预设高潮、篇幅或个人偏好补Query。

完成条件：主Query有非空答案、会话身份与完整引用；P0指定的原书细节群和承重关系能指回`cited_text`；艺术串联与史实断言已经分开。需要新增事实、改变P0故事或越过`episodeScope`时停止。

## DN02：写出AGY唯一消费的故事大纲

普通、`full`、`narration`和`opener`在`scratchPath/creative-outline.md`写给AGY的唯一文件入口。文件开头列出主Query及现行故事仍实际需要的补充Query绝对路径，供DN03定向读取原文和出处，不复制回执中的旧提问或Notebook总结；定点返修若遇到P0已经移出旧补充Query所承担的内容，该文件即使为历史溯源保留，也不得再写进大纲或交给AGY。同一文件先原样保留`episodeBrief.audience / episodeBenefit / episodeScope / episodeCreativeBrief`及存在时的`programPlan.maxDurationSeconds`，再注明本次正文篇幅估算及片头、停顿预留；原值不存在时不伪造时长，不把上限改写成精确目标。它们是作者必须收到的业务委托，不是管理者另定的覆盖或文风规则。随后忠实提炼一份短故事大纲，交代：

1. 人物或观察视点；
2. 眼前必须完成的任务、现实限制和直接代价；
3. 按先后发生、实际需要的可观察变化；
4. 本集要让观众进入的原书细节群、它们共同显出的承重关系、对应Query路径，以及P0已经划定的本集专属重构边界；
5. 希望留下的气质与余味。

大纲交清事实、证据适用范围与重构边界，不要求作者把这些核查说明逐项讲给观众。以基础书为节目主体，是呈现书中生活与关系，不等于每段介绍书名或证明出处；只有书、作者或记述差异本身参与本段事情时，才保留相应叙事用途。不得把材料未记载某事，扩写成当时无人知道、没有发生或制度禁止。

大纲不是创作规范、审计表、事实禁令表或半成品正文。不得另造“必须入稿／可以留在后台”的资料清单；P0已经写明的核心内容与排除范围原样保留，不能为了简短删掉业务要求。不要指定逐段详略、转场、句式、声音、情绪曲线、修辞或固定叙事节拍，也不要把片头方法复制进大纲。非虚构边界与交付格式由DN03提示词单独说明；装配的片头方法由DN03作为独立文件直接交给AGY。同一大纲把业务要求与故事交给作家，不预写成稿。

`narration / opener`还要把工作单投递的`currentScriptPackage / currentOpenerNarration`和返工原因原样写入大纲，明确当前待修稿；不以会话记忆辨认正式稿，不读取未接纳旧稿。

`opener`的大纲只交本次片头修订目标与现行稿件，要求同步调整正文开场及必要承接，其余内容保留；仍沿上述路径交接固定材料。有用户原句时逐字锁定该片头，不锁定正文。

完成条件：正文路线中，AGY只读大纲就能复述“面向谁、要让人理解什么、范围与时长是什么、跟随什么必要过程、哪些连接可以省并、最后留下什么”，再沿Query路径自由完成文字；没有第二套创作规范。片头修订仍返回衔接成立的完整片头与正文。所有材料路径存在可读。

## DN03：独立成稿并保存各自结果

完整读取共享的[作者交接方法](../author-narration/references/author-handoff.md)，沿其原入口保存工作稿、调用进度、原始回包、会话身份和唯一候选；定点与纠错也用同一入口，不临时封装或重抄正文。

普通和`full`共用DN01的一套材料与DN02的同一`creative-outline.md`，启动后不改输入。只构造一份[固定作者提示](references/documentary-author-prompt.md)，先并发发起三个新的空白AGY会话再收取结果；三路使用完全相同的提示、模型、参数、大纲及材料，不分别Query、不分配不同风格，不向任何一路展示其它稿件或选择意见。`narration / opener`返修同一份现行稿时，必须读取工作单`reusedNarrationMaterials.agyConversation`固定的原作者会话文件与ID，在当前`scratchPath`保存同一ID并用`--conversation <ID>`续接；缺少、摘要不符或无法恢复时停止，不得静默另开会话。定点返工不扩展成三路。固定命令如下：

本次P1任务第一次实际调用AGY前先运行`agy --output-format json models`，确认`gemini-3.8-flash-high`当前可用；只有CLI更新或异常时才查版本与帮助。模型不可用时停止，不得静默换型号。

```bash
agy -p "<PROMPT>" --model gemini-3.8-flash-high --effort high --dangerously-skip-permissions --output-format json --print-timeout 10m
```

从工作单`resolvedAssembly`的`opener-copy-template`唯一实现取得当前`copyRules`，按`resolvedRules`核对文件存在且摘要一致。片头由节目配置选择，不因纪录片形式固定为回忆片头。DN03首次消费提示时完整读取已登记的[固定作者提示](references/documentary-author-prompt.md)，按其原文及占位替换要求构造`<PROMPT>`；已完整持有且未变化的提示不重复加载。规则缺失或摘要不符时停止，不得凭记忆重写方法；发布／封面路线不加载该提示。

`opener`沿同一联合提示和原会话修订，只处理大纲点明的片头与必要正文承接。有`exactOpenerNarration`时将其逐字交给作者并锁定；不为迁就正文改写该句。

取得完整返回后，按共享[三路首稿](../author-narration/references/author-handoff.md#三路首稿)用`receive`交接；定点路线按[定点返工](../author-narration/references/author-handoff.md#定点返工)用`candidate`保存唯一候选。原文提取、确定字段和现有机械检查由程序完成；歧义、明确作者机械失败及未知调用按该方法处理。此时不读事实审计方法、不查证、改稿或接纳。

需要新事实、换掉本集观察者／任务／主要过程／内容主体，或用户明确整稿不要、要求重新创作时，不能借校改单扩张，必须由导演入口处理正式替换；真实输入变化时保留原现场，只处理实际失效范围，不让三路消费不同版本。用户明确修改同一稿且主体未变时，仍续接被选原作者。普通／full先按上述逐路记录恢复和汇合，单路失败不构成整批重跑资格；全部初始调用明确失败时，才按Director已有替换条件处理，机械失败不能改判为重跑资格。定点路线技术恢复仍失败或没有可恢复身份时，仍按正式替换入口处理。Codex不得因文风偏好追加会话或通过重跑重置审计和纠错次数。

完成条件：普通／full三路均为received或有明确原因的failed，可交付稿factErrors=null，无未知调用；至少一稿可交付才进入DN04，不补开第四路。定点路线逐字保存唯一候选，保持原作者会话，不建三路记录，跳过DN04。正文与片头返工先交接对应发布内容，再进入DN05；未知只恢复原调用，无法确认时保留现场并停止。

## DN04：按纪录片观看体验整套择优

三路结束后，先以同一P0委托、受众、节目气质及本集生活过程为背景，连续读完每份received正文；failed不参选。核心判断是：愿不愿意跟着这段生活走完，过程中看懂一些门道，并对人的劳动、处境或关系留下真切感受？比较实际正文开头怎样让人进入，不能拿后文亮点代替开场判断；以整篇体验为主，不让一句漂亮片头决定胜负。按当前所选片头方法判断同稿配对：有旁白时连读，无旁白时核对具体观察及正文兑现，不把内部片头句当作观众已经听到的信息。

连读时注意出处介绍、考据说明是否打断正在展开的生活；来源本身有叙事作用时，不因出现书名就认定它破坏叙事。这只用于已有整稿的体验比较，不成为事实纠错项或追加润色的理由。

吸引力可以来自陌生用途、具体动作、现实限制、变化或发现，不要求冲突升级、反转或人物成长。生活细节与自然停顿有作用就保留，不按知识点数量、紧张程度或逐项大纲覆盖评分，也不把从容等同于拖沓。选择要服务P0的历史生活使命，不能仅因独立虚构戏更刺激就优先。先作整篇判断，再回到一两处实际段落，简短说明它比最接近另一稿更值得听的原因；不打分、填表或另写选稿报告。相近就说明相近，全部平庸时只能称相对可用，只有一稿时说明采用及局限；文字通读不冒充实际冷听或观众效果。

选择只用于当前已有作品，不查证事实、审计未选稿、改写正文、跨稿配片头或要求作者润色。没有配对成立的可交付整稿时保留现场并报告，不拼补或追加创作。选定后按共享[作者交接方法](../author-narration/references/author-handoff.md#锁定整稿)的select命令只交作者路号，原样锁定完整正文、片头与根会话身份，进入唯一候选；选择理由在当前会话说明。锁定后不改选；发布续写或事实处理已开始时，从其当前进度恢复。

## 选定后补齐发布内容

普通／full锁定整稿后、narration或opener取得修订稿后，完整读取共享[发布内容作者方法](../author-narration/references/publication-author.md)，原作者同一会话一次补齐三平台文案与横竖封面构思，随后进入DN05。保持纪录片的生活使命、故事骨架与文学重构自由，题图不强套解说冲突或悬疑。publication-copy、publication-all、cover-content直接按该方法单路修订，不重取Query或重选正文。

## DN05：只核对一次基本事实，按需最小纠错一次后接纳

发布内容补齐后，读取[基本事实核对方法](references/documentary-narration-audit.md)，按本次范围核对唯一候选，回查相关大纲与来源；只核对有明确依据的基本事实错误，不审字数、大纲符合度、写作或片头方法，不读取未选稿找问题。

普通／full从已锁定稿按共享[事实处理](../author-narration/references/author-handoff.md#选中稿的事实处理)进入reviewing，一次保存完整事实清单；定点路线按共享[定点返工](../author-narration/references/author-handoff.md#定点返工)保存本次清单，不建三路记录。无错误时直接按原进度接纳，不调用作者；有错误时一次交清原句、正确事实和必要依据，不给替换句。

纠错只续接选中原作者一次，沿DN03参数增加`--conversation <原作者ID>`，按交接方法保存本次纠错进度与新终端句柄；不得复用首稿句柄或重发。只把当前候选路径与完整错误清单替换进下列固定提示，不追加要求：

```text
只读<candidatePath绝对路径>。仅修正下列事实错误及因纠错必须同步修改的相关表述；其余文字（含片头）逐字保留，不为字数增删，不润色。
<原句、正确事实、必要依据>

依据供你修正事实，不要求写进口播；在原叙事中改正、收窄或删去错误断言，保留必要限定与观点归属，不另加查证说明。
仅在上述事实纠错涉及的文字中，把必要补充信息自然写进句子；不要新加中文或英文圆括号、编辑注释。

不得修改文件。只返回完整成稿：
片头
<唯一片头>

正文
<完整正文>

发布内容
<完整publication JSON>
```

发布内容定点修订只返回本次publication JSON，正文与片头由程序锁定。

返稿按共享交接方法用`correct`原样覆盖同一候选，保留首稿与原事实清单，不另建候选。纪录片纠错仅原样封装，不独立重复机械复验，正式accept仍执行原合同。`exactOpenerNarration`始终逐字锁定；原句自身有问题时停止，请用户另给合规原句或明确放弃锁定，不交给作者改写。

随后只按[原错误确认](../author-narration/references/publication-author.md#纠错后的原错误确认)核对原清单及必要连带表述，不查找新问题、重新审稿、润色或追加调用。普通／full的ready只表示机械交接完成，有原错误仍须确认；定点路线也须确认原调用已完成、候选完整且原错误改对。原错误未改对或进度无法确认时保留候选并报告，不接纳。

继续、恢复或完整重跑不得重置本次核对和纠错次数。已有清单按共享交接方法恢复，未知只恢复原调用；明确纠错失败或正式accept拒绝时保留现场、报告并停止，不改选或重投。
