# 综合解说P0六项策划方法

本方法只负责综合解说P0的六项单集内容合同，不负责P1成稿。先确定本集必须回答的问题、材料能够承担的初步答案、覆盖边界和独有收益，再用一个自然段写清创作任务，材料定位另起一段交清标题、URL或本地绝对路径、必要页段和用途；不能先决定主角、故事类型或叙事载体，再把结论贴上去。

## 六项合同共同成立

每集只保留一个能够独立成立的题材，并写：

- `episodeTitle`：P0为陌生观众确定的正式单集母标题，不是P1各平台的最终标题；不超过30个字符。优先用观众能识别的时代、人物、物件或事件，加上具体冲突、反常识结果或因果承诺；标题本身必须零基础可懂，并由`episodeAnswer`和后续正文真正兑现。不得只写文学气氛、陌生术语、空泛“传奇”，也不得为了点击把多重原因锁成未经支持的单因；
- `episodeQuestion`：这集真正要回答的唯一问题，可以比单集母标题更准确完整，不承担平台字数和包装职责；它要写清被解释的对象或关系、究竟发生了什么变化／怎样被维持／有哪些关键差异／判断边界在哪里，以及本集必须解释到什么程度，使P1据此知道该找什么材料、证明哪件事。它不是“介绍某段历史”“为什么很重要”“应该怎样理解”这类只有题材没有解释目标的大问题。长期累积、结构约束和秩序维持本身都是可讲过程，不因缺少单一转折而排除；
- `episodeAnswer`：用完整自然语言正面回答问题，写清决定结果的主要条件、约束、关系或机制，带来了什么变化或结果，以及结论成立的必要边界；让P1能够区分必须证明的核心判断与只是可能采用的材料。只有“重要、复杂、影响深远”之类评价、定义、结论标签或事项并列时必须重写；但它也不得预写引用级事实序列、具体入口、人物弧或场景，更不是要求P1写成答题作文的标准答案；
- `episodeCreativeBrief`：用一个完整自然段交代本集的创作任务：围绕什么对象、关系或矛盾展开，起初处在什么局面，必须讲清哪些变化、维持、比较或检验，哪些内容区分与后果不能遗漏，最后需要形成什么理解。每项要求都应实际改变P1的取材或构思，不得为了简短压成题目换写或几句摘要；创作边界见下文；
- `episodeScope`：写清本集纳入哪些时间、对象、关系或解释任务，讲到哪里停止，明确排除什么，并说明怎样不重复或抢答相邻集；使P1能判断哪些事实属于本集必要解释、哪些即使相关也应留给别集；
- `episodeBenefit`：承接整季观众收益中由本集独有答案负责的部分，用日常语言写清零基础观众看完后新明白了什么：当时的人怎样办成一件事，什么限制改变了选择，或不同条件为何带来不同结果。必要的概念区分服务这层认识，不把多个名词或层次的区分并列当成收益；必须由本集的答案和必要内容产生，换成别的时代题材便不再成立；

`episodeTitle / episodeQuestion / episodeAnswer / episodeCreativeBrief / episodeScope / episodeBenefit`共同构成本集唯一合同。创作任务只规定必须讲清的对象、关系、矛盾、变化、比较、检验、区分、后果和最终理解；不预写故事大纲、逐字稿、人物／史料清单、强制Beat、固定段落或半成品口播，也不规定主角、故事类型、叙事载体、具体开场、固定推进单元、事实顺序或结尾写法。AGY保留材料取舍、具体开头、揭示顺序、段落、详略、节奏和语言。P0不向NotebookLM请求逐集故事大纲、搜证种子、探索卡、资料映射或第二套策划。
每项正式业务字段都从最终结果反推：必须能指出它将改变节目拆分、当前单集任务、P1创作、P3模板或视觉、P4包装中的哪项真实决定。必填字段若只能被下游原样转述而不能改变决定，应修正其内容；只有当前合同明确允许省略且本次不适用的字段才省略。正式字段的增删不属于P0生产。节目级字段已经落实为单集任务后不再为了证明消费而重复投递给P1。若最终结果需要合同中不存在的上游决定，也先修正P0，不在下游补私有字段、状态或第二套策划。

六项必须互相兑现：标题的承诺由问题准确展开，答案正面回应问题，创作任务规定不可遗漏的内容，范围装得下完整解释并阻止抢答，收益来自答案。删掉或替换其中一项后P1仍会写出同一篇内容，说明该项没有写实，应在P0收窄、拆分或重写。

## 整季脉络与分集

先沿题材的变化、因果、比较与必要解释关系接通整季，再确定集数、集序和边界，将推进依据写入`seriesFramework`。历史叙事通常按时间向前；比较、长期变化与同一时期的不同视点可以另行组织，但要说明时间关系，不能把材料章节顺序当作历史先后或因果。这里确定内容分工，不替P1规定正文的讲述顺序。

同一完整事件或解释链能在委托容量内讲清时优先合讲，不把准备、行动和结果拆成各自薄弱的题目，也不按知识点、原章节数或均等篇幅凑集数。合并后的唯一问题与答案必须承接各部分的关键经过、必要解释和后果；去掉重复铺垫，明确完整展开的主体与简短支持的侧面。不能为减少集数把重要内容缩成一句结论；不同题目各有独立问题与结果、合后只剩并列专题时仍各自成集。

修订已有节目时，从现行问题、答案、创作任务和范围反查新归属，确认重要经过与解释仍在新任务中实际承担内容，不能只保留原集号或题材名。保留用户冻结的已完成内容；取舍与相邻归属写入既有`episodeCreativeBrief / episodeScope`，不另建覆盖表，也不把某次压缩比例或集数当作通用目标。

## 观众旅程与编辑边界

先确定零基础观众已经认识的时代、人物、物件、矛盾或结果，再确定真正陌生且值得讲透的一层认识。选择能支撑这层认识的必要内容，为首次定位、白话解释和自然停顿保留展开空间；同题相关的经过、概念和例外不必全部变成创作任务。按包入口的单集篇幅原则，判断本集是否保留了理解变化所需的条件、行动与后果，把展开意图写进现有创作任务；较大题目不能只剩结论，小题目也不因自然较短而扩大范围。按完整解释与相邻内容的关系拆合，不预设统一字数。委托明确上限时，才判断这些内容是否能在该容量内讲清；不足时先收窄范围或在委托允许时拆合，不靠加快语速或抽掉必要解释装下原题。最后确认本集答案能够独立闭合，不能靠相邻集铺垫或下一集预告补足。

内容判断可以用下面两组假设例子校准，不能直接写入节目或当作新增必选题型：

- “介绍某项通行制度”还只给出题材；“同样拿到许可，为什么一批货能抵达码头，却仍进不了城”才指出需要查清的具体关系。若材料证实分属不同许可，就讲清这些限制怎样改变运货行动；若材料不支持，就修正问题和答案，不围绕设想编故事。
- “国家和企业存在利益冲突”可以套用到许多题材；“政府为什么扶持这家企业，企业获得支持后又为何不肯承接政府要求的运输”会改变需要查什么。收益应落在有据的目标、经营约束、选择与后果上，不能只把“利益冲突”换成更响亮的结论。

初步答案还要经得起会让它收窄的材料。已有可靠解释可以直接讲清，不要求每集推翻常识；这些判断只落实到原六项合同，不新增发现卡、反转指标或P1故事安排。

创作任务可以要求比较、检验、责任判断、长期累积或结构约束，但只写必须讲清的内容使命，遵守上述六项合同的创作边界；随后继续材料闭环与提交。

再做两项不阻塞接纳的作者判断：喜欢本季任意一集的第一受众，是否会因为同一种观看理由也愿意选择这一集；这一集的`episodeBenefit`是否补上整季`viewerBenefit`中其它集不能替代的一块理解。它们只帮助作者优先调整入口、角度、顺序、节目边界，或合并、替换明显重复的集；不能单独拒绝题目、阻止P02进入P03、要求用户确认或成为Validator硬门。只要六项内容合同成立、答案能够独立闭合、没有实质重复且材料范围能够承载，即使这两项没有达到理想状态也继续，不增加分数、报告或下一集钩子。

## 适用时的专业判断

只有题材本身明确属于以下情况时才启用对应判断；默认不套用，也不把它们做成字段、标签、卡片或报告：

- 本集核心是相互竞争的解释、责任归属或流行说法时，先确定各说法究竟在哪个可观察的关系、条件或结果上冲突，再把问题落到可靠资料能够核对的层级；答案只写资料能够支持的行动、条件、约束、关系或机制、结果，以及不能继续判断的边界，不把争议本身当卖点，也不强行二选一；
- 整季或单集跨越多个时期、政权、地区或群体解释长期变化时，先确定一个在各观察点含义一致、都能用同类关系、条件、行动或结果核对的共同观察轴；整季把它落实到编辑方向、节目框架和拆集，单集把它落实到问题、答案和创作任务。只剩年代切换、人物串联或事件并列时就收窄或拆分；
- 本集核心追问失败为何发生、当时是否存在另一条路或结果是否必然时，先最低限度说清谁想实现什么目标、以哪个可观察结果判断是否达到，以及本集观察到哪个关键节点为止，再用实际发生的条件、当事人当时可见的选项、行动与结果立住问题；可靠资料显示局部有效与最终未达目标并存时，两者都要保留。P0把必须讲清的对象、关系、变化、比较或检验写入`episodeCreativeBrief`，但不规定逐字开头、段落、详略或揭示顺序。可以把“如果少了某个已知条件，会不会不同”保留为有据的开放比较，让AGY据材料组织悬念或因果理解；不能预设确定结论、完整替代历史或给当事人补后来知识。

形成最终方案前，两路都用可靠公共资料或可核对书目，对最终节目骨架和逐集答案中承重的关系、机制、约束、状态变化和争议边界做同等级的最小可信度核对。基础书不能豁免外部核对；作者立场鲜明、存在争议或补充材料可能改变结论时，必须校正、补足或收窄。局部判断不成立或只能支持更弱结论时，直接调整问题、答案或边界；`book-led`的书源框架本身不成立时停止，不能静默换线。不要新增质量字段、报告、引用表或证据矩阵，也不让NotebookLM代写策划或证明逐集材料覆盖。存在最长时长时，再检查题目本身能否在上限内讲清；不得靠删掉必要解释硬塞，也不得靠重复和趣闻填满。默认只形成一套最强方案，不为要求用户选择而制造弱方案。

## 反推材料

材料充分不是来源数量。沿每集问题、答案、创作任务和范围反查：历史主体、制度、数量、时序、因果、比较尺度和具体后果是否都有P1可读取的可靠正文；艺术组织本身不要求证明一个真人经历完整过程，但它连接的地点、行动条件、制度关系和生活后果不能靠常识冒充事实。

取得材料时同时考虑原文怎样被读取。扫描PDF可见页面不等于Query能返回文本引文；能取得同源可搜索文本时优先采用，需OCR时核对原页，不能将识别内容直接当成已经核实的原文。只有页面图像的材料仍可供有据阅读，但不以NotebookLM来源就绪推断文字引用已经可用。不因此新增逐集试Query、材料格式门或第二份资料库；实际不可读的必要材料仍按下述既有缺口处理。

所有集共享一份最小充分材料需求，不按集分包，不建立逐集来源映射或第二套策划。一项材料能关闭多个缺口时只取一次；只为不可替代的独立缺口增加材料。材料可来自公开正文、本地书稿或NotebookLM，P1实际读取正文或引用原文；不要查询逐集写作方案，也不要另存事实表、材料卡或审计报告。

## 材料缺口的处置

- 已识别必要材料但尚未取得、缺页或不可读：保留同一候选，在材料步骤交付具体找书或补齐需求，完成独立工作后等待；不能把“没找到”当成“不存在”。
- 已读材料只支持较弱结论：在原委托内修订受影响的答案、范围或故事安排，不保留无依据的结论。
- 原设计缺乏可靠依据且无法在既有范围成立：提出收窄、合并或替换方案；触及用户明确限定或需要更换基础书、入口、节目形式时等待用户决定。暂时拿不到材料本身不构成删集或换方向的理由，也不能把缺口交给P1补证。
