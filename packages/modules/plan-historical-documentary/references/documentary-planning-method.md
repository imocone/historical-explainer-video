# 历史纪录片策划方法

本方法只负责纪录片P0的专业叙事判断，不负责事实接纳、平台发布或P1成稿。

## 纪录片形式

历史纪录片的核心不是“讲得像故事”，而是向观众作出可核对的非虚构承诺，并设计一种持续的观察方法。对无法现场拍摄的历史题材，文献事实、基于证据的合理推论和艺术重构必须保持距离；合成画面只能帮助观看，不能反过来证明事实。

P0可以用“场景—意义”作内部判断：观众要能进入具体时间、空间、物件和过程，也要从同一过程自然看见城市运转、制度边界、群体关系和普通人的生活处境。它不是交给作家的双轨公式；只要成片没有把风景与知识割裂，作家可以自由决定怎样组织。

适合的结构可以按题材选择物候、一天时序、空间移动、物件流转、职业过程、节庆准备或制度触达作为主轴。《舌尖上的中国》可借鉴的是从具体材料、劳动、地方关系和人的生活进入较大意义，以及用感官和过程维持观看；不得把“食物结构”机械套到所有题材。

## 历史内容与故事骨架的主从关系

一季可以由许多个小故事组成，但节目不是为了这些故事本身而存在。P0先确定每集要把基础书及可靠补充材料中的哪一部分历史生活变成观众能够亲历的经验：哪些动作、物件、细节、关系和生活后果必须显出来。再为这部分内容选择一个最小而有方向的故事骨架，让人物任务、物件旅程、地方一日或城市时刻把它们自然带到观众眼前。

当委托明确要把基础书本身呈现给观众时，原书生活仍是内容主体，补充研究只负责校正、解释和搭桥。原书细节可以丰富，但单集取舍服从观众理解和委托时长；优先保留共同说明本集生活门道的动作、物件、处境与关系。同场、同程只说明材料可以连接，不意味着都要入稿；只增加相似气氛、旁支背景或同类名目的内容，可以合并、省略或留给其它集。不固定细节数量，也不为提炼知识而抽空具体生活。

逐集先用`episodeConcept / episodeBenefit`确定这一集必须把基础书及可靠补充材料中的哪部分生活变成可观看经验：观众要亲历哪些动作、物件、细节、关系和生活后果，以及最终能复述什么；`episodeScope`锁定外边界，`storyOutline.meaningReveals`写清承重关系，再以`viewpoint / centralProcess / actionChain / ending`选故事。基础书本身是节目主体时，每集必须先找到能够共同构成一个生活场景或过程的原书细节群，并在`episodeScope`点明对应篇章或内容范围；不得先定一个泛宋代故事，再从书里找三五个名词装饰。细节容量由核心收益、必要解释和委托时长共同决定，不把它们写成要求P1逐条朗读的事实表。删掉历史内容后故事仍可独立成为虚构戏，说明故事反客为主；删掉故事后只剩可任意换序的知识条目，说明骨架没有承载内容，两种情况都要重做。

先把`episodeBenefit`写成零基础观众能用自己的话说明的一项核心认识：某件事怎样做、某种关系如何运转、某种处境为何产生或证据允许判断到哪里。核心集中不限制事实数量，也不要求问答格式；“繁华”“烟火”“普通人托举城市”等气质与价值不能单独代替具体收获。

写动作链之前，按委托时长判断：核心认识需要哪些事实，哪些陌生概念需要解释，哪些场景只重复相似感受；为片头和必要停顿留出空间。时长上限不要求写满；没有明确时长时也按一次可理解的观看容量选择，不自行设定所有节目的统一秒数。把必要内容、可压缩的侧面和留给其它集的主题用简短文字落实到`episodeScope / episodeCreativeBrief`，不另建字段或逐项入稿清单。超量时先缩减旁支和非关键过程；仍须改变用户固定题目、集数或核心范围时交回用户决定，不把超量任务推给P1靠加速完成。

只有上述内容使命成立后，才写`episodeThroughline / episodeCreativeBrief / storyOutline`，为它选择最合适、最小的故事骨架。`storyOutline`明确本集采用的人物任务、物件旅程、地方一日、城市时刻或其它真实故事形态；观众跟随谁或什么；今天必须完成的中心任务／过程、眼前代价与现实限制；按先后发生的动作链；动作途中打开的承重关系；始终在场的环境；最后回到的具体生活后果；承接或传给其他集的人／地／物／时；本集允许的合成人物、合成路线和连接动作边界。`meaningReveals`的1—3项容量只用于概括细节共同显出的较大关系，不是对原书细节的数量限制。

`episodeThroughline`负责一句话说明故事过程怎样让本集历史内容显出意义，`storyOutline`负责把它落实成可写的故事组织，二者不能互相代替。故事只承担呈现，不取得独立主题：不能先编一个完整戏剧，再把史料贴上去；也不能把人物当导游，让他偶尔出现以连接成段知识。合成人物、面车、学徒、路线或必要连接动作不要求文献证明“同一个真实个体完整经历过”；它们是P0授权的艺术串联线。系列只保留少量真正有用的合成人物；它们可以有稳定称呼并自然留下跨集记忆，但人物成长只是一种连接，不得成为整季主要回报或挤占基础书内容；`storyWorld.recurringElements[].function`只说明它怎样帮助观众重新进入这座生活世界，各集在`continuityLinks`记录当前集真实需要的承接。P0必须确保串联线合理、克制并服务当前内容使命；沿途出现的历史事实、制度、数量、时序、关键因果和生活结论仍分别需要证据。艺术重构可以补足合理的天气、气味、身体负担和当下反应，但不得冒充真人传记、虚构关键身份与命运、改变历史因果或编造具体对白。

这些正式字段划定本集主体、必要关系、范围和故事连续性，不规定正文逐段安排。P0只保留推动中心过程或建立核心理解的必要变化，不把每次行走、等待、感官反应和沿途地点分别固化成必经动作。P1原样交接受众、核心收益、范围、创作委托和已有时长，再把观察视点、必要过程、承重关系、引用路径与重构边界忠实提炼成同一份短大纲；具体交接由P1入口负责。AGY可以合并或省略非关键连接动作、选择叙述入口和材料详略，不能改变本集主体、必要关系、真实历史先后或扩大范围。不把节目方法、四项指标、审计规则整包转给作家，也不把业务时长和范围误当作应删去的文风干预。

`actionChain`每一步必须是任务、物件或处境的可观察变化，并且推动中心过程或让此刻必须看见的一项历史内容自然显出。动作数量服从真实过程和现行Schema容量，不为凑数拆动作。“辨认、观察、了解、感受”，以及抽象的“汇合、显出”，若没有人物或物件进入新状态并改变下一步行动，不能单独充当动作。解释服务于眼前过程和观众的理解需要，可以在必要时直接说明用途、限制、差别、因果或证据边界，不必为每次解释另安排人物观察、疑问或反应；解释之后继续推进同一核心内容，不绕入背景百科。推进压力可以来自期限、钱、重量、天气、规则、照护或不确定性，不必强造人物冲突。

`ending`只写这条故事最后发生的具体生活状态或后果，让前面的行动在生活里落地；不能复述`episodeBenefit`，不能写成“观众由此理解／记住／看见什么”的策划结论，也不能用抽象拔高代替故事收口。故事结束后不得再跳到作者追忆、成书动机、后世评价、王朝兴亡或另一时空另开新题；只有整集本来就在讲这个过程时例外。

## 整季脉络与分集

先接通整季的时间、生活过程与必要关系，再决定集数和集界，把推进依据落实到`seriesNarrativeStrategy`。通常沿历史先后或节令向前；同日不同视点、跨日过程与必要回看要交代时间关系，不能因书中篇章相邻就推定同日或先后。节气与农历节日的相对位置须核实；合成年只选择可成立的排列，不说历年如此。没有固定月日的内容可以艺术编排，但不能因此捏造日期或因果。不按目录条数、知识点、人物数或四季均分凑集数。

全季先按实际呈现的生活过程和核心认识分工，再把相邻集、同一人物群、同一节令类型和复用同一原文章节的集数成组反查：各集的主行动、物件流转、承重关系、生活后果与观众收益必须形成不可互换的核心路径，不能只换人物、日期或标题继续讲同一套摊贩、礼单、租赁、香客、等待或仪仗。同一完整过程能在委托容量内讲清时优先合讲，不把议定、筹备、进行和收束各切成薄集；确需连续多集时，每集分别承担有据且足量的不同阶段、系统或生活后果。仅仅同属婚育、娱乐或节庆，不足以合成一集；各有独立过程与收益、合后只剩并列专题时保留分集。固定集数需要替换薄弱题目时，从尚未呈现的可靠内容补位，不把一个薄弱过程硬拆成准备、进行和结果。

合并要重新设计一个能跟随的中心过程，去掉重复开场、背景解释和收尾，保留使原内容成立的关键行动、必要区分与生活后果；不能直接拼旧稿，也不能为减少集数把重要过程压成一句背景。主场景完整展开，支撑侧面简短带入，旁支按容量取舍；各部分不必等量展开，更紧凑不等于加快语速或取消必要停顿。

完整解释或主过程归最能承担它的单集，在各集现有`episodeScope / episodeCreativeBrief`写清本集中心、只需简短交代的背景和留给其它集的展开内容。相同内容再次充分展开，须有当前集需要的新用途、新关系、新处境或必要比较；主线不同不能单独证明重复解释有价值。熟悉的声音、地点、称呼、物件与日常动作可以简短自然重现，不必每次制造新含义；判断看观众是否又经历一遍同一解释与过程，不按关键词重合去重，不靠悬空预告或灾难暗示维持连续性。

以基础书为节目主体时，还要从原书成群的生活场景反查整季：哪些重要且有足够内容的场景尚未进入，哪些题目只凭少量名目却需要大量书外机制或虚构转折撑满。把它与重复、薄弱选题一并修正，已成立的内容保留；不是把全书每条记载均分入集，也不新增覆盖表或去重台账。

修订已有节目时，从现行各集的中心、范围和动作链反查新归属；被合并的重要过程须能在新集任务中找到实际展开，不能只保留原集号、标题或一句提及。按用户冻结范围保留已完成内容，剩余集数由真实内容决定，不把某次压缩比例或集数推广成通用目标。归属与取舍写入既有`episodeScope / episodeCreativeBrief`，不另建映射表。

改变或收窄一集中心后，同步核对`episodeConcept / episodeBenefit / episodeThroughline / episodeCreativeBrief / episodeScope`及`storyOutline`的中心过程、动作、意义、结尾与`continuityLinks`，不能只写排除条款却让故事继续要求旧内容。跨集承接只使用目标集实际保留的经历，不把重构细节写成已证实的历史关系；已发布内容按用户冻结边界处理。

## 四项观众结果

2025年7月抖音创作公开口径把优质内容概括为获得感、惊喜感、表达力、感染力。此后平台公开方向继续强调优质中长视频、系列内容、真实原创与纪录片赛道，但公开资料没有提供可照抄的算法权重。本系统据此采用更严格的内部编辑标准：四项都要成立，但它们是观众结果，不是四个独立段落或机器分数。

- 惊喜感：让观众从真实题材里一件不熟悉却有证据的事进入；新鲜来自联系、过程或视听组织，不来自标题夸大、伪反转和猎奇。
- 表达力：让零基础观众沿一条准确、连续、无需回读的路径跟住；专名和背景只在第一次真正需要时解释，删掉旁白包装后过程仍然清楚。
- 获得感：看完能用自己的话讲出一个以前不知道的生活门道、关系、过程或判断边界。它可以成为观众拿出去讲的谈资，但“讲得出去”是因为真正懂了，不是因为记住一句炫耀性冷知识。
- 感染力：让理解落在具体人物的处境、劳动、身体感受、得失和关系上，使观众产生代入与共情；回味是共情之后可能留下的结果，不用空泛煽情代替事实。

策划时不要分头填四项，而要让它们在现有字段中形成一条完整观看旅程：从哪件有据而陌生的事进入，沿哪条可观察过程跟住，看完能讲出哪个新门道，这份理解又落在谁的什么处境与感受上。再把真实答案分别落实到`viewerBenefit / seriesConcept / artisticApproach / seriesNarrativeStrategy / episodeConcept / episodeThroughline / episodeCreativeBrief / episodeBenefit`，不要增加“获得感字段”等第二合同，也不要把四项变成固定的四段叙事结构。

## 材料充分不是材料数量

`book-led`只用一部基础书确定节目中心，不等于只准使用一本书。历史生活纪录片常把原文中的片段组织成过程、关系和普通人处境；只要这种解释超出基础书直接陈述，就需要独立来源承担。需要什么材料由节目实际承重内容决定，不设置“至少几本书”或“一集一篇论文”的机械门槛。

反查材料时，依次确认：基础文本与必要互校能否支持原始观察；综合研究能否承担城市、制度与时代边界；专题研究能否承担节目真正使用的劳动、供应、家庭、性别、医药、娱乐、宗教、节令或礼仪关系；地图、考古和机构藏品能否承担空间、器物和视觉边界。一个可靠来源可以服务多集，但标题相近、只提供背景或无法进入P1引用的材料不能算作承重来源。

每集只要求存在真实证据路径，不在P0预做逐句事实核查。基础书已经直接说明的过程不必为凑数量另找材料；书外机制、跨条目关系、普遍化判断、普通人生活后果或艺术重构边界没有独立依据时，按下述缺口处置补材料或修订受影响设计。不得让P1用一次Query替P0证明整季骨架本来就成立。

## 材料缺口的处置

- 已识别必要材料但尚未取得、缺页或不可读：保留同一候选，在材料步骤交付具体找书或补齐需求，完成独立工作后等待；不能把“没找到”当成“不存在”。
- 已读材料只支持较弱结论：在原委托内修订受影响的答案、范围或故事安排，不保留无依据的结论。
- 原设计缺乏可靠依据且无法在既有范围成立：提出收窄、合并或替换方案；触及用户明确限定或需要更换基础书、入口、节目形式时等待用户决定。暂时拿不到材料本身不构成删集或换方向的理由，也不能把缺口交给P1补证。
