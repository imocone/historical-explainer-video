# Lemo声音设计

本包由author-beat在所选Template交出可预览的画面与原时序后调用。同一作者理解整章内容、设计听觉推进并制作声音，结果仍按原Beat或template-run交回B2。全画幅联合单一起设计、逐Beat保存；单Beat返工结合所投递的章语境，只改授权单位。未装配时不读取本包、不要求声音交付。

路线：理解本章内容与观看变化 → 设计并制作声音段落 → 对齐原时序，写回同一候选。设计与制作可以相互调整，没有新增工作单、设计表、锁或听审步骤。

## 从内容形成声音

首次配声先完整读取[整章声音设计方法](references/sound-design.md)，结合本单口播、语义与禁造边界、导演观看目标、已成画面和真实时间执行。不要先枚举音效库，也不要把每个画面物件或每次动画当成配声任务。

从当前任务视图的`inputs.featureContexts['sound-effects']`读取实际音乐和同章已接纳声音：`music`交接开关、指定或默认曲目、素材位置与播放规则；`acceptedUnits`交接未由当前单位拥有的已有声音、口播及真实时序。联合单共享顶层这份参考。先判断哪些声仍在延续、重复材质是否承担同一含义、当前修订如何接入；只读参考不取得其它Beat写权，不从磁盘另找旧结果。当前单内尚未接纳的成员仍从唯一候选共同设计。音乐关闭时仍可完成音效设计，不把恢复音乐写成选曲动作。

声音可以建立空间、跟随作用过程、表现阻力与积累、揭示关系、确认结果、衔接前后或主动撤出。短声、持续声、环境声与留白都由本段表达决定，不预设“少量短点缀”、固定声数或每动作必配声。完整留白仍是有效选择，但应来自本章听觉组织，不能因为静图、没有碰撞或库里没有合适声音就交空数组。

具体声音与叙事用途写在原事件的`purpose`，实际形态由配方/源码与资产承担；音乐收放意图写`musicGestures`。它们直接被下一步生成、定位与混音消费，不另交无人消费的分析报告。

## 制作所需声音

制作前完整读取[制声方法与原入口](references/synthesis.md)。简单材质可用基础声音或组合，专用动作可在当前scratch写本段Python函数，通过同一generate入口生成。不要把登记的生成器表当作能力上限，也不把临时音频绕过入口直接塞进候选。

程序返回实测`asset:{file,sha256,durationSeconds,syncSeconds}`，原样替代事件的`soundId`；PCM、实际执行的源码与配方保存于本集原P3音效资产区，scratch清理不使其丢失。基础十声仍可用：plastic-click、table-clack、wood-tap、metal-tap、paper、whoosh、creak、thump、ding、pop。它们是素材，不是本章的创作方案。

声音本身的起势、作用、余韵与空间由作者制作；音乐原件、旁白、TTS、作曲和远端服务不在本包写入范围。使用已有Lemo代码的来源见[SOURCES.md](SOURCES.md)。

## 卡点与音乐收放

已有画面事件时引用`eventId`，与动画共读scene.events。没有事件时，从实际Cue动作与动画/镜头定位`anchor:{target:'AR001',action:'start-frame-motion',offsetSeconds:1.2}`；讲解可用`M001/advance-explainer`。动作实际作用处可能在Cue或moment起点之后，不能只因定位方便就都放在段首。时间来自当前画面代码、正式工具及实测短语，不编造词级时间。

声音文件的`syncSeconds`是其真正作用点：落定声把它对准接触或结果成立，过程声让有效声段跟随实际过程。几秒的变化不能被压成开头一下。准备声可以先于当前段进入已有正文，余韵可以越过Beat；只在正文和节目有效窗口内播放，单段预览裁掉的准备声不能重复补加。需要改变画面才能成立的声音在本包重选，不反向改动画、Cue或相机。

内容需要音乐撤出、让出空间或重新进入时，读取并执行background-music拥有的[音乐收放合同](../background-music/DYNAMICS.md)。本包交表达意图与已有动作锚点，background-music解析当前单曲的播放包络，共享混音执行；不选曲、换曲、重启音乐或写BGM选择。自动旁白让位继续执行，但不能代替作者的内容设计。没有播放音乐时收放意图不产生音乐轨。

## 写回与交付

全画幅联合单按`inputs.authorBatch.members`，逐成员写`result.items[i].featureResults['sound-effects']`；保持成员顺序与beatId，不在result顶层另交整章声音。各Beat的AR001/S001独立定位，不能串用别的Beat锚点。单Beat与讲解章写`result.featureResults['sound-effects']`；讲解不按moment另建交付。

```json
{"events":[{"id":"S001","purpose":"阀门闭合终止流动，接触声在关闭处落定，随后让旁白解释结果","soundId":"wood-tap","eventId":"E001","gain":0.65,"pan":0}]}
```

S编号标身份，不表示顺序；gain默认1、pan默认0。素材已留混音余量，不再习惯性统一压小；先修材质、形态和卡点，再调平衡。需要只有音乐收放的段落可交`events:[]`和实际`musicGestures`；完整无设计变化交`{events:[]}`，省略musicGestures表示音乐维持基础播放。

配声后沿原预演播放已有声音，供用户查看与听。全画幅用原inspect-design的`--clip Beat/AR`（单Beat只给AR），讲解用原preview。预演默认使用当前实际音乐开关与曲目，并接入同章已成声音在当前窗口内的准备声或余韵；`--bgm-source SA编号`只在明确比较其它已登记曲目时覆盖本次播放，`--mute-effects`关闭声音设计（音效及对应音乐收放）作对比，保留实际音乐的基础播放。参数不写回选曲。

作者依据口播文本、实际画面、制声源码／配方、同源时间及测量结果核对声音设计：用途是否对应内容变化，材质与力度设计是否符合表达，过程声时长是否跟随实际过程，收声后的再进入是否承担重点。播放对比供用户使用；AI交付不以试听或听审为前提，不自报听感验收，也不新增听审回执或声数检查。

声音制作或播放失败只回真实声音入口，保留有效画面、相机锁、旁白与Cue。仅音效返工由预览只读复用原画面和cue-sync，不转抄未指定功能。B2仍核对每个已启用单位的合法声音结果；画面制作时尚未配声不构成最终交付。原Feature接纳保存结果并通知实际渲染消费者。被剧情视频替换的图片声音与对应音乐收放不执行；剧情视频内部配声及片头声音由原责任方负责。
