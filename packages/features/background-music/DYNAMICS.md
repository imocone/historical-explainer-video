# 指定单曲的内容收放

在声音设计已经确定哪里需要音乐继续、让开、撤出或恢复时使用。本包拥有从该意图到音乐增益包络的解析；音乐仍由原Feature状态和外部明确选择确定，不从音效事件或文件名推断选曲。

声音作者从任务视图的声音上下文读取实际音乐开关、曲目与播放规则，在同一`sound-effects`结果的可选`musicGestures`中交意图，不改写background-music状态。每个gesture包含G编号、表达用途purpose，以及按实际播放时间递增的至少两个points。每点用原声音合同的eventId或anchor定位，并给相对于既有音乐电平的gain（0至1，0为撤出，1为原电平）。邻点之间线性变化，末点保持至本单位结束；最后正文单位的末点可持续至节目收口。首点之前按原电平，不强制首尾为1：承接上一Beat低电平时，从本Beat起点给出同一电平；需要恢复时在同一gesture继续写到1，不另写一个被前一低电平保持覆盖的回升。多个gesture重叠取较低增益。

```json
{"events":[],"musicGestures":[{
  "id":"G001","purpose":"条件揭晓前收掉伴随声，让否定句独立成立；新方案展开后音乐重新进入",
  "points":[
    {"anchor":{"target":"M003","action":"advance-explainer","offsetSeconds":0.3},"gain":1},
    {"anchor":{"target":"M003","action":"advance-explainer","offsetSeconds":0.7},"gain":0},
    {"anchor":{"target":"M004","action":"advance-explainer","offsetSeconds":0.2},"gain":0},
    {"anchor":{"target":"M004","action":"advance-explainer","offsetSeconds":1.1},"gain":1}
  ]
}]}
```

按本章内容决定收多少、持续多久和如何回归，不要求固定次数。全画幅使用本Beat真实AR/action锚点，讲解可跨本章多个moment；不得引用别的单位的锚点或尚未交付的时间。锚点偏移可覆盖已有正文前文，点位仍须满足原单位有效时窗；更长章节的多单位设计按各单位实际范围衔接，不能凭空修改后章音乐。

音乐点允许精确落在本单位结束边界，用于完整渐变或衔接；普通音效作用点仍位于单位内。需要安静结束时写渐弱到0，末点保持即可；需要跨Beat保持时，下一Beat从同一电平起步。局部返工先读`acceptedUnits`中的原设计，只调整本单位，不能借跨界偏移覆盖未授权单位的独立设计。

收声前先结束或收束自己的环境层、过程声与余韵。只撤音乐而留下密集声音，不等于为内容腾出空间；旁白始终保持正式音频。音乐不会因为撤出而停止计时，恢复时继续同一首曲子的原位置；本能力不承诺回归落在音乐小节上，不改变画面或口播去迎合节拍。

background-music将这些点解析到单曲轨道；共享混音先执行包络，再执行原自动旁白让位。重叠意图取较低增益，保留原首尾淡入淡出，预览裁窗带着原包络位置，不重启收声。没有musicGestures时保持基础播放；音效关闭时不执行其意图；BGM关闭或预览未接音乐时不生成音乐轨。被剧情视频替换的图片单位，其声音意图不执行，片头音乐仍由片头模板拥有。

字段结构随原声音结果合同交付，语义判断回声音作者，锚点错误回该单位作者，音乐包络或播放故障回本包/共享混音。原B2与Feature接纳保存结果，不增加选曲步骤、工作单、独立音乐报告或听审门。
